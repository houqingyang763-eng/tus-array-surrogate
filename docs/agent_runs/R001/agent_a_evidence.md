## 1. 一句话判断

**这篇论文最值得偷的是“预测复数频域全场 + 用离散 Helmholtz 残差约束训练”这一组合，不是它的 2D UNet 本身。** 它直接证明了在固定单源、固定频率、二维速度模型族上，少量随机网格点的 9 点有限差分残差可以改善普通 UNet 的相对 L2 误差、少样本表现和加噪训练表现；但它没有验证 3D、阵列位置/法向变化、多源相干叠加、绝对声压或 pmax，也没有覆盖真实颅骨的剪切、吸收、非线性与固液耦合。

## 2. 按论文顺序的逐节证据索引

### 2.1 摘要与引言：作者到底想解决什么

1. **问题定位**
   - **[作者声明]** 网格数值法成本高、存在离散误差；纯数据方法依赖大训练集；PINN 每次针对同一个模型优化，物理参数改变后往往要重新训练。定位：摘要，PDF p.1；引言，PDF p.1-p.2 / 期刊 p.2257-2258。
   - **[作者声明]** 频域解相对时域在多源场景下可降低计算和存储负担，并可为反演选择少量关键频率。定位：引言后半，PDF p.2 / 期刊 p.2258。
   - **[审计提示]** 本文没有用“多源实验”验证这项频域优势；结论又明确把多激励源列为未来工作。因此“频域适合多源”是背景动机，不是本文的多源实证。

2. **FEUNet 的核心任务**
   - **[作者声明]** 输入为不同的二维脑速度模型，输出对应的复数频域压力波场，实部和虚部分别作为两个通道。定位：引言末段，PDF p.2 / 期刊 p.2258。
   - **[作者声明]** 训练时把最优 9 点有限差分算出的 PDE 误差加入数据误差，以同时使用标签和物理约束。定位：摘要及引言末段，PDF p.1-p.2。
   - **[关键边界]** 输入里没有阵元位置、阵元法向、阵列 mask 或目标位置通道；每组实验的声源位置和频率固定。本文学习的是“速度模型变化 -> 固定激励下的复波场”，不是“阵列几何变化 -> 声场”。

3. **作者对 PINN 的比较口径**
   - **[作者声明]** PINN 输入坐标并针对单个模型求解；FEUNet 输入不同介质模型，训练后一次前向传播可处理同一分布中的新模型。定位：PDF p.2、p.4 / 期刊 p.2258、2260。
   - **[审计提示]** 这里的“不同模型”指速度分布变化，不等于任意声源、频率、边界条件或阵列几何变化。

### 2.2 方法 II.A：频域方程与被省略的物理

4. **方程 (1)：二维标量 Helmholtz 方程**
   - 公式：`∇²p(x,ω) + ω² m p(x,ω) = s(xs,ω)`。
   - 变量：`p` 是复数压力波场，`s` 是声源，`ω` 是角频率，`x={x,y}` 是二维坐标，`xs` 是声源位置，`m=1/v²` 是平方慢度。定位：公式 (1)，PDF p.2-p.3 / 期刊 p.2258-2259。
   - **[作者声明]** 建模“合理忽略”剪切波、非线性和声吸收。定位：公式 (1) 前，PDF p.2。
   - **[计算/解释]** 该方程只显式使用声速 `v`，不是同时以密度、衰减等作为空间场输入；因此它不能直接覆盖项目中完整的 skull acoustic volume。
   - **[项目意义]** 复数 `p` 同时含幅值和相位，原则上比 pmax 更适合作为单阵元响应的可叠加表示。但是否能用于真实阵元叠加，还要验证源模型、边界条件和线性声学近似。

5. **方程 (2)-(4)：PML 边界**
   - 方程 (2) 是加入 perfectly matched layer（完全匹配层，PML）后的二维 Helmholtz 形式；`M=Py/Px`、`N=Px/Py`、`K=PxPy`。定位：PDF p.3 / 期刊 p.2259。
   - 方程 (3) 定义 `Px,y = 1 - i ξx,y / ω`；方程 (4) 令 PML 内阻尼 `ξx,y = 2π a0 f0 (dx,y/DPML)^2`，其中 `a0=1.79`。定位：公式 (3)-(4)，PDF p.3。
   - **[计算/解释]** PML 是数值边界处理，不是颅骨物理。迁移到 3D 时必须把二维 `x,y` 方向扩成三方向，并重新核对离散算子和边界实现。

### 2.3 方法 II.B：UNet 的实际输入、输出和结构

6. **输入输出**
   - **[作者声明]** 输入为二维脑速度模型；输出两个通道，分别是频域波场实部和虚部。定位：II.B，PDF p.3 / 期刊 p.2259。
   - **[实验设置]** 2D 脑实验正文后来明确输入为 `151×151`，输出为 `151×151×2`。定位：PDF p.7 / 期刊 p.2263。
   - **[审计边界]** 图像展示都标注“wavefields have been normalized”，但论文没有清楚说明训练标签是否整体归一化、如何反归一化、是否保留 Pa 单位。因此不能从本文确认绝对声压标定。

7. **图 1：网络结构**
   - 编码器每级两次 `3×3 convolution + LeakyReLU(0.01)`，再 `2×2 max pooling`；解码器以 `2×2 transposed convolution` 上采样，拼接 skip connection 后接两次 `3×3 convolution`。定位：II.B 正文与图 1，PDF p.3 / 期刊 p.2259。
   - 图 1 显示空间尺度约为 `151 -> 76 -> 38 -> 19 -> 10`，通道宽度按 `8 -> 16 -> 32 -> 64 -> 128` 增长，最后恢复到 `151×151` 双通道输出。定位：图 1。
   - **[审计提示]** 正文只说修改了深度和 padding，没有完整列出全部超参数；学习率、训练硬件、随机种子、参数量等在论文正文中未报告。

8. **方程 (5)-(6)：普通 UNet 的训练目标**
   - 方程 (5) 是通用层映射 `qᶦ=fᶦ(Wᶦqᶦ⁻¹+bᶦ)`。定位：PDF p.3-p.4。
   - 方程 (6) 为全网格点上的数据均方误差 `MSEData`，预测与 FD 标签比较；优化器为 Adam。定位：PDF p.4 / 期刊 p.2260。
   - **[审计提示]** 实部和虚部如何缩放、两通道误差是否等权，正文没有进一步说明。

### 2.4 方法 II.C：有限差分物理约束如何嵌入

9. **FEUNet 和 PINN 的本质差别**
   - **[作者声明]** 因为 FEUNet 输入整张速度模型而不是坐标，不能像典型 PINN 那样直接对坐标输入做自动微分；作者改用与标签生成器一致的 9 点有限差分思想计算预测场的 PDE 残差。定位：II.C，PDF p.4 / 期刊 p.2260。

10. **方程 (7)-(11)：最优 9 点离散算子**
    - 方程 (7) 把拉普拉斯写成轴向 5 点模板 `∇²(0)` 与对角 5 点模板 `∇²(45)` 的加权和，`a=0.5`。定位：PDF p.4。
    - 方程 (8)-(9) 分别给出轴向邻点和对角邻点离散式，节点间距为 `Δd`。定位：PDF p.4。
    - 方程 (10) 对质量加速度项中的压力做 9 点加权；系数为 `b=0.6248`、`c=0.09381`、`d=-0.00004`，满足 `b+4c+4d=1`。定位：PDF p.4。
    - 方程 (11) 将这些离散项代入 Helmholtz 方程，形成计算预测波场 PDE 残差的模板。定位：公式 (11)，PDF p.4 / 期刊 p.2260。
    - **[计算/解释]** 物理损失并不是另一个独立高保真求解器；它和监督标签都来自同一 9 点 FD 离散体系。因此实验能证明“加入与标签生成机制一致的离散残差有益”，但不能单独证明结果更接近真实人体声场。

11. **图 2 与方程 (12)：总损失**
    - 图 2 流程：速度图 -> UNet -> 预测实部/虚部 -> 数据误差；同时对预测场施加 9 点 FD 残差 -> 物理误差；二者合成总误差并由 Adam 更新。定位：图 2，PDF p.4。
    - 方程 (12)：`MSEtotal = λData MSEData + λPhy MSEPhy`。定位：PDF p.5 / 期刊 p.2261。
    - **[作者声明]** 权重没有固定答案；通常先让两项同数量级，数据少时可把物理项权重增大约 10 倍，最终靠 trial and error。定位：公式 (12) 后，PDF p.5。
    - **[审计风险]** 不同样本量使用不同权重，且没有完整列出每个实验的权重，会削弱可复现性，也使少样本比较包含额外调参因素。

12. **方程 (13)：唯一统一的定量评价指标**
    - `ℓ2 = ||ppre-pref||2 / ||pref||2`，用于测试集的相对 2 范数误差。定位：公式 (13)，PDF p.5。
    - **[审计边界]** 本文没有报告目标点压力、峰值位置误差、旁瓣比、绝对声压误差或 pmax 指标。

### 2.5 数值实验 III.A：理想颅骨模型

13. **数据和激励**
    - **[实验实证]** 理想颅骨是随机生成的空心凸椭圆壳；单个样本内厚度恒定，不同样本厚度为 5.5-27 mm；颅骨声速固定 2820 m/s，背景固定 1500 m/s。定位：III.A，PDF p.5 / 期刊 p.2261，图 3。
    - 网格为 `1000×1000`，间距 `0.25 mm`；PML 每边 25 个网格。训练 512 个模型，测试 100 个模型。定位：PDF p.5。
    - Ricker 中心频率 500 kHz，固定声源坐标 `(131.25 mm, 248.75 mm)`；点源以方差 3 的各向同性高斯源近似。定位：III 开头和 III.A，PDF p.5。
    - batch size 为 16。定位：PDF p.5。
    - PDE 残差抽样 2000 点，占全部网格点 0.2%。定位：PDF p.6 / 期刊 p.2262。

14. **图 3：几何变化范围**
    - **[实验实证]** 图 3 只显示规则、光滑、单层空心椭圆样式，变化主要是轮廓、倾角和厚度。定位：图 3，PDF p.5。
    - **[项目边界]** 它不是来自真实 CT 的颅骨细结构，也没有骨密度、孔隙、皮质/松质双层或阵元几何变化。

15. **图 4-6：FEUNet 与 UNet**
    - **[实验实证]** 图 4 所述最终训练误差：FEUNet `0.01822`，UNet `0.05260`；作者还指出 FEUNet 到达相同误差所需 epoch 更少。定位：PDF p.6，图 4。
    - **[实验实证]** 图 5 的 100 个测试样本中，FEUNet 相对 L2 曲线整体低于 UNet，但论文没有给均值、标准差或显著性检验。定位：PDF p.6，图 5。
    - **[实验实证]** 图 6 给 4 个测试例，只展示归一化后的实部。FEUNet 差值图在颅骨附近普遍较淡，支持其对速度突变附近细节的改善。定位：PDF p.7 / 期刊 p.2263，图 6。
    - **[审计边界]** 图 6 没展示虚部，且归一化后不能判断绝对幅值误差；视觉改善也不能替代相位误差或焦点指标。

### 2.6 数值实验 III.B：MIDA 单切片脑模型与少样本测试

16. **MIDA 的使用方式**
    - **[实验实证]** MIDA 原本是 3D 头颈解剖模型；作者按 0.5 mm 间隔得到 465 个切片，但只选其中一个切片构造二维脑模型。定位：III.B，PDF p.6 / 期刊 p.2262，图 7(a)-(c)。
    - **[关键边界]** “来源于 3D MIDA”不等于网络或实验是 3D；本文实际只训练一个固定二维解剖切片上的变化。

17. **人为血凝块变化**
    - 在固定脑切片上加入圆形血凝块，半径 8-20 mm；中心位于以中点为圆心、半径 30 mm 的区域内；血凝块声速最小不低于 1600 m/s、最大不高于 1700 m/s，中间按高斯分布生成。定位：PDF p.6。
    - 测试集重新生成位置、尺寸和速度分布，并额外包含恒定 1600、1700 m/s 的情况。定位：PDF p.6。
    - **[计算/解释]** 真正变化的主体是局部圆形异常，不是整体头颅个体差异，也不是阵列或声源变化。

18. **输入输出和实验固定量**
    - 输入 `151×151`，输出 `151×151×2`，网格间距 2 mm。定位：PDF p.7。
    - Ricker 主频 300 kHz，声源固定在 `(150 mm, 256 mm)`，PML 每边 20 网格。定位：PDF p.7。
    - 每次从全域随机取 500 点计算 PDE 残差，约 2%。定位：PDF p.7。
    - 训练集大小分别为 64、128、256、512；共用 100 个测试样本。定位：PDF p.7-p.8。

19. **图 7：二维脑模型和波场**
    - 图 7(a) 是 MIDA 切片；(c) 是二维速度模型；(d) 加入血凝块；(e)-(f) 是无/有血凝块的归一化复波场可视化。定位：图 7，PDF p.8 / 期刊 p.2264。
    - **[审计提示]** 图只展示了单个固定上方声源；没有不同入射位置、法向或目标点。

20. **图 8-9：少样本结论**
    - **[实验实证]** 所有训练集规模下，FEUNet 的训练曲线和测试相对 L2 分布优于 UNet；64 样本时 UNet 误差显著上升，FEUNet 约接近 UNet 使用 128 样本时的水平。定位：PDF p.7-p.9，图 8-9。
    - 作者称进行了独立重复实验以降低随机性影响，但没有给出重复次数、误差条或统计检验。定位：PDF p.7。
    - **[审计风险]** 不同样本量采用不同 `λPhy` 权重，具体值未报告；因此“少一半数据达到同等水平”是图示级观察，不宜当成精确、可移植的样本效率定律。

### 2.7 数值实验 III.C：训练标签加噪

21. **噪声设置**
    - 给训练集复波场加入零均值高斯噪声；训练 256 个样本，测试 100 个样本；SNR 为 10、5、0、-5、-10 dB，另有无噪声条件。定位：PDF p.8-p.10，图 10。
    - **[实验实证]** 随 SNR 降低，两方法误差都增大，但 FEUNet 的中位误差和增长趋势低于 UNet。定位：图 10，PDF p.10 / 期刊 p.2266。

22. **测试集选择风险**
    - **[作者原文事实]** 每个 SNR 条件下两种算法训练多次，并选择“在测试集上最好的结果”比较。定位：III.C，PDF p.8 / 期刊 p.2264。
    - **[计算/解释]** 如果没有独立验证集，这相当于用测试集挑运行，会对最终测试误差产生乐观偏差。论文没有报告单独验证集，因此噪声鲁棒性的方向性结果可以参考，精确数值不应当作无偏泛化估计。

### 2.8 讨论 IV.A：与 PINN 的比较

23. **PINN 对照设置**
    - 使用同一二维脑模型，输入大小 `151×151`、网格 2 mm，输出复波场实部和虚部；标签仍由最优 9 点 FD 生成。定位：PDF p.9 / 期刊 p.2265。
    - PINN 对照使用更低的 150 kHz 固定声源，坐标仍为 `(150 mm, 256 mm)`。定位：PDF p.9。
    - **[实验实证]** 图 11 显示 PINN 在原始速度突变模型上失败，平滑速度模型后成功。定位：PDF p.9-p.11，图 11。

24. **比较能证明与不能证明的内容**
    - **[作者声明]** PINN 难处理速度突变和高频，提高频率需要更深、更宽网络；FEUNet 不受速度模型限制。定位：PDF p.10。
    - **[审计限制]** 这里没有给 FEUNet 与 PINN 在完全相同频率、训练预算、网络容量和误差指标下的定量表；“FEUNet 不受速度模型限制”也只在本文有限模型族中成立，不能理解为任意速度场均可泛化。

### 2.9 讨论 IV.B：作者自己承认的限制

25. **软约束不是逐点严格物理**
    - **[作者声明]** FEUNet 的 PDE 项是 penalty/soft constraint，只保证平均意义上的接近，不能保证每个点都满足方程，仍可能出现明显不物理的局部预测。定位：IV.B，PDF p.10 / 期刊 p.2266。
    - 作者把 hard constraint projection 作为未来方向。定位：同页。

26. **频率与网格/显存压力**
    - **[作者声明]** 二维脑实验采用 300 kHz；若升到 500 kHz，为避免数值频散，FD 网格需要进一步细分，频域场点数会快速增加，网络参数和训练成本也会增大，甚至超出现有计算能力。定位：PDF p.10。
    - **[项目意义]** 这直接支持项目先做低分辨率大区域 baseline 的范围收缩，也说明从本文的二维 151 网格跳到三维 0.5 mm 全域并不现实。

27. **训练额外成本**
    - **[作者声明]** PDE 残差增加训练计算，但作者称只增加了 2.2% collocation points，并以更高精度和更快误差下降补偿。定位：PDF p.10。
    - **[审计疑点]** 前文两个实验分别写 0.2% 和 2%；“2.2%”似乎是二者相加式概括，而不是单个实验统一比例，表述不够严谨。

28. **3D 与复杂物理只是未来方向**
    - **[作者声明]** 扩展到 3D 需要 3D 标签和 3D 波动方程约束；加入固液耦合、孔隙、衰减、吸收则需要更准确的控制方程和物理误差。定位：PDF p.11 / 期刊 p.2267。
    - **[证据等级]** 这是未来工作，不是实验验证。本文不应被引用为“FEUNet 已支持 3D 经颅超声”。

29. **多源仍未解决**
    - 结论明确说，应用到 imaging 前还需扩展到更一般配置，例如多个 excitation sources。定位：PDF p.12 / 期刊 p.2268。

## 4. 对当前 tus-array-surrogate 项目的精准映射

### 4.1 能偷什么

1. **复数频域场作为单阵元响应标签**
   - **[实验事实]** 本文输出实部 + 虚部全场，而不是 pmax。
   - **[项目解释]** 这正好保留相位，具备做相干叠加的数学信息；比“单阵元 pmax 再相加”更合理。
   - **[仍需验证]** 本文没有执行多源叠加，也没有阵元有限孔径、法向或幅相权重输入。

2. **离散物理残差作为辅助训练信号**
   - 直接可借鉴 `数据损失 + Helmholtz/FD 残差`，尤其是在 3D 标签昂贵、样本较少时。
   - 先在低分辨率 2D/小 3D patch 上复现是否比纯数据基线更稳定，再考虑全域。

3. **随机抽取 collocation points 控制额外成本**
   - 本文用 0.2%-2% 的随机点而不是全域计算物理损失，说明可以把物理约束做成稀疏采样。
   - **[审计推测]** 3D 中应考虑重点采样颅骨界面、焦域和高梯度区，而不只均匀随机；这需要新实验。

4. **把速度模型族而非坐标单实例作为网络输入**
   - 相比单个模型一个 PINN，卷积 surrogate 更接近项目的“训练一次、快速评估多个候选方案”。

### 4.2 不能偷什么

1. 不能把“一个 MIDA 切片”写成 3D 经颅实验。
2. 不能把固定点源写成支持阵元位置/法向/阵列形状变化。
3. 不能把复频域场写成 time-maximum pmax；二者不是同一种 label。
4. 不能声称保留绝对声压：图均归一化，正文缺少单位和反归一化证据。
5. 不能声称支持多阵元相干叠加：作者明确把多 excitation sources 留到未来。
6. 不能直接迁移本文 Helmholtz 残差到包含衰减、密度变化、剪切、固液耦合或非线性的高保真标签。
7. 不能把 3.5-4.2 倍速度提升外推到 3D；表 I 没有硬件和训练摊销口径。

### 4.3 与项目问题逐项对照

| 项目问题 | 本文证据结论 |
|---|---|
| 对项目有没有用 | **有用，作为方法核心文献，不是最终系统证据** |
| 输入 | 二维声速/速度模型；源位置、频率在各实验中固定 |
| 输出 | 二维复数频域压力场，实部+虚部两通道 |
| 网络 | 2D UNet encoder-decoder + skip connection |
| 数据 | 最优 9 点 FD 生成的理想颅骨和 MIDA 单切片变体 |
| 是否 3D | **否**；3D 只在 future work 中提出 |
| 阵列位置变化 | **否** |
| 阵列形状变化 | **否** |
| 阵元数量变化 | **否** |
| 大区域/whole-brain pmax | 输出覆盖二维计算域，但不是 pmax，更不是 whole-brain 3D |
| 绝对声压 | 无法确认；可视化明确归一化 |
| 单阵元复响应 + 叠加 | **有表示层启发，未做叠加验证** |

## 5. 最重要的证据分层结论

### 已被本文实验支持

1. 在本文两个二维、固定源、固定频率的模型族中，加入 9 点 FD 残差的 FEUNet 测试相对 L2 优于普通 UNet。
2. 在训练样本减少和训练标签加噪时，FEUNet 的退化幅度小于普通 UNet。
3. 物理残差可仅在少量随机网格点计算，推理结构仍与 UNet 基本相同。
4. 输出复数频域全场是可行的二维任务设定。

### 只是作者声明或未来工作

1. 可较容易扩展到 3D。
2. 可处理更复杂物理系统。
3. hard constraints 会进一步提高精度与抗噪。
4. 可以扩展到多激励源。

### 我们自己的项目假设

1. FEUNet 式复频域输出可能适合作为单阵元响应库。
2. 单阵元复场经幅相加权后可能合成多阵元场。
3. 3D 中稀疏 PDE 点应优先放在界面/焦域/高梯度区域。
4. 低分辨率大区域复场 + 标量绝对压力校准，可能比直接全分辨率 pmax 更适合作为第一轮可行性实验。

这些都需要新的项目实验，不能算论文现成结论。
