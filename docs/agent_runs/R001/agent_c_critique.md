## 0. 先给结论

这篇论文是**方法局部高度相关、直接方案结构性不匹配**的核心辅助论文。

最值得偷的是：用离散 Helmholtz 算子对预测的实部 / 虚部复声场计算物理残差，并把它作为 U-Net 的软正则项。论文实验确实表明，在作者构造的二维、固定源、固定频率、标量声学数据分布内，这个残差项优于纯 U-Net，尤其在训练介质样本较少或标签带噪时。`[论文实证：PDF pp.5-10 / 期刊 pp.2261-2266，Figs.4-10]`

但它不能直接作为当前项目的第一版模型。最强反证不是“它只是 2D”，而是它的**网络输入只有介质声速图，没有源位置、源法向、有限孔径几何或频率条件**。作者每个实验都固定源位置和频率。当前项目第一阶段恰好固定 MIDA，而主要改变阵元位置 / 法向；若照搬该 IO，所有样本的输入几乎相同，却对应不同输出，这不是普通的泛化困难，而是映射定义本身缺少必要条件。`[论文写明：PDF pp.2-3、5、7 / 期刊 pp.2258-2259、2261、2263；项目事实：docs/project_concept_v4.md]`

因此，正确的迁移方式不是“把 FEUNet 从 2D 卷积改成 3D 卷积”，而是：

1. 重新定义输入，使每个样本显式包含源分布或阵元位置、法向、有限尺寸和驱动条件；
2. 保留复数频域输出 `Re[P], Im[P]`，再验证它能否生成标定后的窄带 pmax；
3. 把论文的离散 PDE 残差当作候选训练正则，而不是把论文误读为已经证明 3D、可变阵元几何、绝对 pmax 或多源叠加可行。

## 1. 先准确重建论文实际做了什么

### 1.1 控制方程及被忽略的物理

作者采用二维、标量、频域 Helmholtz 方程：

```text
∇²p(x,ω) + ω² m(x) p(x,ω) = s(x_s,ω)
m(x) = 1 / v(x)²
```

其中 `p` 是复压力波场，`s` 是源，`ω` 是角频率，介质输入只通过声速 `v`（或平方慢度 `m`）进入。作者明确忽略剪切波、非线性和声学吸收。`[论文写明：PDF pp.2-3 / 期刊 pp.2258-2259，Eq.(1)]`

作者随后给出二维 PML（完美匹配层）形式的方程 Eq.(2)-(4)，用来吸收计算边界处的出射波。`[论文写明：PDF p.3 / 期刊 p.2259，Eqs.(2)-(4)]`

这意味着论文的“经颅”物理模型实际上是：二维切片 + 仅声速变化 + 标量压缩波 + 无吸收 / 无密度变化 / 无剪切波 / 无非线性。它不是完整的头骨固液耦合，也没有验证绝对透射幅值。`[论文写明：PDF pp.2-3；Agent 判断：由其方程中的状态量和作者列明的忽略项推出]`

### 1.2 网络的真正输入输出

网络是二维 U-Net：编码器用两层 `3×3` 卷积、LeakyReLU 和 `2×2` 最大池化逐级降采样；解码器用转置卷积上采样，并通过跳跃连接取回局部空间细节。图 1 展示了通道数约为 `8→16→32→64→128` 的编码-解码结构。`[论文写明：PDF p.3 / 期刊 p.2259，Fig.1]`

网络输入：二维声速图。

网络输出：同一网格上的两个通道，分别为指定频率下复压力波场的实部和虚部。脑模型实验中输入为 `151×151`，输出为 `151×151×2`。`[论文写明：PDF pp.2-3、7 / 期刊 pp.2258-2259、2263]`

关键的“没有输入”包括：

- 没有 source mask；
- 没有源坐标输入；
- 没有源法向或孔径面；
- 没有阵元尺寸、曲率、指向性；
- 没有频率条件；
- 没有密度和衰减通道；
- 没有 target 条件。

这些量不是被某种隐式编码方式处理了，而是在每组实验中被固定。`[论文写明：网络输入定义见 PDF pp.2-3；固定源与频率见 PDF pp.5、7、9-10]`

### 1.3 FEUNet 的真正创新

纯 U-Net 的监督损失是所有网格点上的预测场与 FD 标签之间的均方误差 `MSE_Data`。`[论文写明：PDF p.4 / 期刊 p.2260，Eq.(6)]`

FEUNet 额外把网络预测的复波场代入一个优化九点有限差分离散式 Eq.(11)，在随机选取的配点上计算 PDE 残差 `MSE_Phy`：

```text
MSE_total = λ_Data MSE_Data + λ_Phy MSE_Phy
```

`λ_Data` 和 `λ_Phy` 没有固定规则；作者先令两项处于相同数量级，再通过试错调节，样本少时会把物理项权重提高约 10 倍。`[论文写明：PDF pp.4-5 / 期刊 pp.2260-2261，Eqs.(7)-(12)]`

因此 FEUNet 不是无标签 PDE 求解器，也不是硬约束。它仍然需要完整的 FD 波场标签；物理项只是训练期的软正则。作者自己也承认，软约束只能保证平均意义上更接近方程，不能保证每一点严格满足物理规律。`[论文写明：MSE_Data 用所有网格点，PDF p.4；软约束局限，PDF p.10 / 期刊 p.2266]`

### 1.4 两组主要数据和变量覆盖

#### 理想颅骨组

- 二维椭圆状空心壳；每个样本内部厚度恒定，但不同样本厚度为 5.5-27 mm；
- 颅骨声速固定 2820 m/s，背景固定 1500 m/s；
- 源固定于 `(131.25 mm, 248.75 mm)`，Ricker 中心频率固定 500 kHz；
- 训练 512 个模型，测试 100 个模型；
- 文中称原始网格为 `1000×1000`、间距 0.25 mm，PML 厚 25 格；
- 物理残差用 2000 个点，称占总配点 0.2%。

`[论文写明：PDF pp.5-6 / 期刊 pp.2261-2262，Figs.3-6]`

#### MIDA 二维脑切片组

- 从 MIDA 的 465 张、间隔 0.5 mm 的切片中只选一张，构成固定二维头部解剖；
- 在该固定切片内人工加入圆形血块，只改变血块位置、半径和声速分布；
- 输入 `151×151`，网格间距 2 mm；输出 `151×151×2`；
- 源固定于 `(150 mm, 256 mm)`，主频固定 300 kHz；
- 训练集大小依次为 64、128、256、512；测试集 100；
- 物理残差随机用 500 点，称占 2%。

`[论文写明：PDF pp.6-8 / 期刊 pp.2262-2264，Figs.7-9]`

这组实验没有改变 MIDA subject、切片、颅骨位置、源位置、源方向或频率。论文所谓“不同模型泛化”主要是对其训练分布内的理想椭圆变化或同一脑切片内的人工血块变化。`[论文实证：上述数据定义；Agent 判断：对“generalization”适用范围的收窄]`

### 1.5 论文实验证明了什么

1. 理想颅骨组中，FEUNet 的训练误差为 0.01822，低于 U-Net 的 0.05260；100 个测试样本的相对二范数误差整体也更低。`[论文实证：PDF p.6 / 期刊 p.2262，Figs.4-6]`
2. 固定 MIDA 切片的人工血块任务中，训练样本从 512 减到 64 时，FEUNet 的相对二范数误差始终低于纯 U-Net；64 样本时差距尤其明显。`[论文实证：PDF pp.7-9 / 期刊 pp.2263-2265，Figs.8-9]`
3. 给训练标签的复波场加入 10 到 -10 dB 高斯噪声时，FEUNet 的误差低于 U-Net。`[论文实证：PDF pp.8-10 / 期刊 pp.2264-2266，Fig.10]`
4. 表 I 报告 100 个样本的总推理时间：理想颅骨 FEUNet 17.8807 s、FD 74.2894 s，约快 4.15 倍；脑模型 FEUNet 11.0852 s、FD 38.9433 s，约快 3.51 倍。`[论文实证 + 计算推导：PDF p.12 / 期刊 p.2268，Table I]`

这些结果支持“在作者的二维固定源任务中，九点 FD 残差是有用的 U-Net 训练正则”。它们不支持“已经解决 3D 经颅阵列设计”。

## 2. 反方审计：最容易被摘要掩盖的问题

### 2.1 标签和物理损失来自同一个九点 FD 算子

训练集、测试集标签均由 optimal 9-point FD operator 生成；物理损失又用同一九点离散思想计算。`[论文写明：PDF pp.4-5 / 期刊 pp.2260-2261]`

这会形成一种“离散算子闭环”：网络既在数据项中拟合同一 FD 算子的输出，又在物理项中被要求满足同一 FD 离散残差。FEUNet 优于 U-Net，能证明该正则帮助网络逼近**这个离散求解器**；但没有独立证明它更接近连续 Helmholtz 方程、另一种 full-wave solver、经颅 benchmark 或真实实验。`[Agent 判断：由 label 与 residual 的共同来源推出；论文没有独立 solver / 实验对照]`

这不是说结果无效，而是证据边界必须改写为：

> FEUNet 对复现其教师 FD 算子的二维解更有效；论文尚未证明物理项修正了教师算子的离散偏差。

对本项目尤其重要：如果未来标签来自 k-Wave、k-space 或更完整的有吸收 / 密度模型，而物理残差仍用本文的简化九点标量 Helmholtz 算子，两项损失可能不再一致。此时“物理项”甚至可能把预测拉离高保真标签。`[Agent 推测：需要专门做 loss compatibility 实验]`

### 2.2 固定源导致它无法直接学习阵元位置 / 法向变化

理想颅骨实验固定源坐标和 500 kHz；MIDA 脑实验固定另一源坐标和 300 kHz。源函数只进入 PDE 右端，没有作为网络输入。`[论文写明：PDF pp.5、7 / 期刊 pp.2261、2263]`

当前项目第一版固定 MIDA、频率、阵元尺寸、幅值，优先改变 `element_position` 与 `element_normal`。`[项目事实：docs/project_concept_v4.md]`

因此照搬本文 IO 会得到：

```text
同一个固定 MIDA 声速图
-> 源 A 的复场
同一个固定 MIDA 声速图
-> 源 B 的复场
```

同一个输入对应多个正确输出，网络无从知道该预测哪一个。`[Agent 判断：确定性的监督映射缺少条件变量]`

最低限度的改造是为每个样本加入源条件，例如：

- 三维体素化源分布的实 / 虚驱动通道；或
- 阵元中心坐标 + 法向 + 尺寸，再由几何编码器生成源表示；或
- 有限孔径面上的边界速度 / 压力分布。

只加一个“中心点”也未必够，因为当前项目关心有限尺寸阵元及法向；高斯点源没有方向性。`[Agent 推测：需要以真实仿真源定义确认最小充分表示]`

### 2.3 噪声实验存在测试集挑最好结果的问题

作者写明：每种 SNR 下两种算法训练多次，并选择“在测试集上的最好结果”进行比较。`[论文写明：PDF p.8 / 期刊 p.2264]`

这相当于用测试集做模型 / 随机种子选择，会使最终误差偏乐观。正确做法应由独立验证集选择权重、epoch 或随机种子，最后只在测试集评估一次。`[Agent 判断：标准实验设计原则]`

此外，噪声加在训练集的复波场标签上，而网络推理输入仍是干净的声速图。这个实验更准确地叫“对受污染仿真标签的鲁棒性”，不能直接外推为“对真实测量输入噪声的鲁棒性”。`[论文写明：PDF p.8；Agent 判断：由噪声注入位置和网络 IO 推出]`

### 2.4 PML 方程与物理残差的边界处理没有交代清楚

论文先给了含 PML 系数 `M,N,K` 的 Eq.(2)，但九点残差 Eq.(11)明确由无 PML 的 Eq.(1)推导。作者没有说明随机配点是否排除了 PML、外边界和源奇异区。`[论文写明：PDF pp.3-5 / 期刊 pp.2259-2261]`

如果所有物理配点都限制在 PML 内侧且避开源区，这个做法可以成立；如果随机点落进 PML，Eq.(11)并不是该区域真正采用的控制方程。`[Agent 推测：取决于未报告的 collocation mask / 代码实现]`

Figure 12 只显示 500 个随机点训练前后的残差，没有分别报告内部域、PML、源区和边界，也没有给全域残差分布。它不足以排除局部不物理预测；作者自己也在讨论中承认软约束无法逐点保证。`[论文实证：PDF pp.10、12 / 期刊 pp.2266、2268，Fig.12]`

### 2.5 报告存在可复现性缺口和一个尺寸矛盾

文中理想颅骨数据在 PDF p.5 被写为 `1000×1000`、0.25 mm；但 PDF p.10 的运行时间讨论又称理想颅骨“data size”是 `210×210`，脑模型是 `150×150`。论文没有解释从 1000 到 210 的裁剪、降采样或输入预处理。`[论文写明：PDF pp.5、10 / 期刊 pp.2261、2266]`

论文还没有报告足以复算实验的关键项目：硬件、学习率、训练时长、精确 epoch 选择规则、模型参数量、每组 `λ_Data/λ_Phy`、随机种子及独立重复次数。`[论文缺失：阅读全文未见；Agent 判断]`

因此 Table I 的约 3.5-4.2 倍速度提升只能作为该实现的报告值，不能直接外推到 3D 或与当前项目硬件比较。

### 2.6 评价指标对当前项目不够

主要指标只有整个复场的相对二范数误差；若干图只展示实部差值，且图中的波场被归一化。`[论文写明：PDF pp.5-10，Eq.(13)，Figs.6-11 captions]`

全文未给：

- 复数相位误差或相干叠加后的误差；
- 绝对幅值误差；
- `P_target`、`P_peak`、focus error、side-lobe ratio；
- 脑区内危险高压区误差；
- 独立实验或跨 solver 误差。

全场 L2 小不保证焦点或旁瓣准确：大面积低能量区域可能主导平均损失，而项目最关心的小区域峰值和相干相位可能仍错。`[Agent 判断：指标与项目目标的结构性差异]`

## 3. 按项目关键问题逐项判断

### 3.1 2D 到 3D

**判断：只提供方法概念，不提供 3D 可行性实证。**

作者明确把 3D 列为 future work，并说明需要 3D 标签和三维波动方程约束。`[作者声明：PDF pp.11-12 / 期刊 pp.2267-2268]`

将 `151×151×2` 复场粗略改为以下三维复场，仅输出体素数就变为：

```text
128³ / 151² ≈ 92 倍
160³ / 151² ≈ 180 倍
200³ / 151² ≈ 351 倍
```

`[计算推导：只比较单样本空间点数；尚未包含 3D 卷积中间激活、梯度和优化器状态]`

三维 U-Net 的显存通常还会被多尺度特征激活放大，因此“把 2D convolution 换成 3D convolution”不是论文已经解决的工程步骤。论文自己也承认 500 kHz 更细网格会使点数快速增长，可能超过可用计算能力。`[作者声明：PDF p.10 / 期刊 p.2266；Agent 判断]`

**能偷：** 三维 Helmholtz 离散残差作为局部 stencil 卷积的思想。

**不能偷：** 二维网络规模、二维运行时间和样本数结论。

**需验证：** 3D residual 计算的显存 / 时间、低分辨率残差是否仍能约束 500 kHz 波相位、PML 在三维中的实现。

### 3.2 固定源与变化源几何

**判断：原论文不支持阵元位置、法向或形状变化。**

输入只含声速图；每个实验固定点状高斯源及频率。`[论文写明：PDF pp.3、5、7]`

论文所谓不同输入，是不同介质模型，不是不同 source geometry。作者在结论中也把 multiple excitation sources 明确列为进一步工作。`[作者声明：PDF p.12 / 期刊 p.2268]`

**能偷：** 在源条件明确后，预测 `Re[P], Im[P]` 的输出形式。

**不能偷：** “声速图 -> 场”的原始 IO；它对固定 MIDA、变化阵元的项目是欠条件的。

**需验证：** source mask、点坐标 / 法向编码和有限孔径表示三者中哪一种能在未见位置上泛化。

### 3.3 频域复场到绝对 pmax

**判断：复场是有价值的中间量，但论文没有验证项目所需的绝对 pmax。**

对于单频稳态信号，若

```text
p(x,t) = Re{P(x,ω) exp(-iωt)}
```

并且源幅值和压力单位已经标定，则该点的时间峰值幅度是 `|P(x,ω)|`。`[计算推导：窄带 / 单频线性稳态条件]`

但本文用 Ricker 波的某个频率分量生成复场；图 6-11 均注明 wavefields have been normalized，未报告绝对压力单位、源驱动标定或绝对峰值误差。`[论文写明：PDF pp.5、7-11，figure captions]`

因此：

- 若当前项目第一版是固定频率的连续波，本文的 `Re/Im -> |P|` 链路可作为候选；
- 若 pmax 指宽带脉冲的 time-maximum pressure，则单个频率复场不够，必须多频率合成后再取时间最大值。

`[Agent 判断：由频域-时域关系推出]`

进一步地，本文控制方程没有密度和吸收，绝对透射幅值的物理充分性也未被证明。`[论文写明：PDF pp.2-3；Agent 判断]`

**能偷：** 两通道实部 / 虚部表示；它比直接预测 pmax 更适合相干计算。

**不能偷：** 归一化波场图和 L2 指标作为绝对 pmax 证据。

**需验证：** 单频 `|P|` 与当前仿真 pmax label 的数值定义是否一致、绝对幅值误差和峰值 / 旁瓣指标。

### 3.4 单阵元复场与多阵元相干叠加

**判断：方程形式支持这一思路，但论文没有做该实验。**

Eq.(1) 对压力 `p` 和源 `s` 是线性的。在同一介质、频率和边界条件下，若 `s = Σ a_j s_j`，对应解应为 `P = Σ a_j P_j`。`[计算推导：PDF p.2 Eq.(1) 的线性结构]`

这正是本文对项目最重要的理论连接：预测单源复场，而不是单源 pmax，才保留了相位并允许复数权重叠加。

但论文：

- 只使用一个固定高斯点源；
- 未训练可变源；
- 未测试多源直接仿真与单源预测叠加的一致性；
- 未建模有限尺寸、法向和阵元间耦合；
- 结论把多激励源列为 future work。

`[论文写明：PDF pp.5、12]`

所以它只能给“为什么要预测复场”的方法支持，不能给“我们的单阵元叠加已经可行”的实验证据。

**最小验证：** 同一 MIDA、同一频率下选 2-4 个有限尺寸阵元，分别仿真单元复场；按同一驱动幅相复数相加，与一次多阵元 full-wave 仿真的复场、pmax、焦点和旁瓣比较。此实验应先于训练 3D FEUNet。`[Agent 建议]`

### 3.5 颅骨与频率泛化

**判断：没有跨真实颅骨、跨源频率泛化证据。**

理想颅骨实验改变椭圆几何和厚度，但声速固定；MIDA 实验只用一张切片，仅人工血块变化。`[论文写明：PDF pp.5-7]`

500 kHz、300 kHz 和 PINN 对照的 150 kHz 是三组独立实验设置，不是同一条件网络在频率上的泛化。作者还明确说换问题时要修改物理约束表达和权重参数。`[作者声明：PDF pp.9-10 / 期刊 pp.2265-2266]`

当前项目第一版固定 MIDA 和频率，因此“暂不要求跨 skull / frequency”可以接受；但仍不能把本文的泛化结果当成对未见阵元位置 / 法向的证据，因为训练变化轴完全不同。`[项目事实 + Agent 判断]`

**能偷：** 把物理约束限定在第一版固定方程 / 固定频率内，避免一开始做万能模型。

**不能偷：** 作者“can be relatively easily extended”的措辞作为 3D 或多频率实证。

**需验证：** 按空间区域或角度做严格 OOD 切分，而不是随机划分相邻位置；测试未见头皮区域、未见法向角度。

### 3.6 label 成本

**判断：物理项减少了训练所需的介质样本数，但没有消除 dense full-field label 成本。**

`MSE_Data` 对所有网格点计算，训练 / 测试标签全部由 FD 生成。物理残差只在少量配点计算。`[论文写明：PDF pp.4-5]`

因此“64 个样本也能比 U-Net 好”表示：在 64 个**完整复场标签**上物理正则更有效；不是只用 64 个稀疏观测点，也不是无标签学习。`[Agent 判断]`

对当前项目，每增加一个阵元位置 / 法向，仍可能需要一个完整 3D 单元复场 label；输出还包含两个实数通道。三维化会把每个 label 的生成、存储和 I/O 都显著放大。`[项目事实 + 计算判断]`

一个值得继续研究但论文没有验证的方向是：对少量有标签 source geometry 使用 `MSE_Data + MSE_Phy`，再对更多无标签 source geometry 仅使用 PDE、源项和边界约束。但这要求残差、PML、有限孔径源和唯一性条件都实现正确。`[Agent 推测 / 候选研究想法]`

### 3.7 边界条件与裁剪

**判断：论文对完整矩形域 + PML 的设定不能直接搬到项目的大区域脑内裁剪输出。**

本文预测完整计算网格，PML 位于外围。当前项目的输出可能只是上半脑或大区域裁剪；裁剪边缘通常不是物理吸收边界，也不满足简单的零值 / PML 条件。`[论文写明：PDF pp.3、7-8；项目事实：docs/project_concept_v4.md]`

若网络只输出脑内裁剪区，九点 stencil 在裁剪边缘缺少邻点，PDE 残差需要：

- 扩大预测域并只在内部计算 loss；或
- 为裁剪边缘提供来自全域场的 halo / ghost cells；或
- 只在离裁剪边界至少一个 stencil 宽度的内部点计算残差。

`[Agent 推测：离散算子实施要求]`

论文没有验证这种“大区域输出但不是完整仿真域”的物理约束。

### 3.8 证据外推边界

论文可以支持：

> 在二维标量声学、固定源 / 固定频率、由同一九点 FD 算子生成标签和残差的任务中，向 U-Net 加入稀疏 PDE 残差，能改善对该 FD 波场的拟合，尤其在训练介质样本较少或标签带噪时。

论文不可以支持：

> FEUNet 已经能做 3D 经颅阵列设计、任意阵元位置 / 法向、有限孔径阵元、多阵元叠加、绝对 pmax、跨头颅 / 跨频率泛化，或真实实验级预测。

后一串都是作者未来工作、项目设想或尚未验证的外推。`[论文边界：PDF pp.10-12；Agent 判断]`

## 4. 能偷、不能偷、必须额外验证

### 4.1 能偷

1. **复场输出表示**：`Re[P], Im[P]`，它保留相位，适合单阵元相干叠加候选路线。`[论文写明：PDF pp.2-3]`
2. **离散 PDE 残差正则**：无需像坐标 PINN 那样对单一介质逐模型优化，可训练多介质 / 多条件 surrogate。`[论文方法：PDF pp.4-5]`
3. **小比例物理配点**：先尝试少量随机 / 重要区域配点，而非全域计算残差；但比例必须重新实验。`[论文方法：理想颅骨 0.2%，脑模型 2%，PDF pp.6-7]`
4. **物理项权重诊断思路**：先让数据项和物理项同数量级，再监控二者；不能照抄具体权重。`[作者经验：PDF p.5]`
5. **对照实验框架**：相同 U-Net 下比较 data-only 与 data+physics，并做样本数消融。`[论文实验：Figs.4、8、9]`

### 4.2 不能偷

1. 只有声速图的输入；当前项目必须条件化源几何。
2. 二维点源代替有限尺寸有法向阵元。
3. `151×151` 的网络和运行时间直接外推 3D。
4. 归一化图和全场 L2 作为绝对 pmax / 相干相位质量指标。
5. 同一 FD 算子的 label + residual 作为独立物理正确性证据。
6. 一张 MIDA 切片 + 血块变化作为真实 skull 泛化证据。
7. 在测试集上挑最好结果的噪声实验流程。
8. “容易扩展到 3D / 其他频率”这一作者声明当作已经完成的事实。

### 4.3 必须额外验证

优先级从高到低：

1. **先做无网络的复场叠加试验**：单阵元复场和多阵元直接仿真是否一致。
2. **验证源几何编码的充分性**：位置 + 法向是否足够，还是必须输入有限孔径源分布。
3. **验证 PDE loss 与高保真标签是否相容**：对 k-Wave / 目标 solver 标签，九点标量残差会改善还是伤害预测。
4. **验证绝对幅值链路**：源幅值标定、复场单位、`|P|` 与 pmax 定义、焦点 / 旁瓣误差。
5. **验证边界 / PML mask**：物理配点必须明确排除或正确处理 PML、源区和裁剪边界。
6. **再做 3D 小网格 FEUNet smoke test**：先测显存、训练速度和物理残差开销，不直接承诺大区域正式训练。

## 5. 给用户最值得质疑的问题

阅读综合报告时，建议用户重点追问这些，而不是只看“FEUNet 比 U-Net 好”：

1. **如果我固定 MIDA、只改变阵元位置 / 法向，论文的网络到底从哪里知道源变了？**
2. **物理 loss 和 label 都来自同一个九点 FD 算子，提升是不是主要在更好地模仿该离散算子，而不是更接近真实物理？**
3. **Eq.(11)没有 PML 系数，随机物理配点是否进入 PML、边界或源区？代码如何做 mask？**
4. **为什么理想颅骨一处写 `1000×1000`，运行时间讨论又写 `210×210`？真正喂入网络的尺寸是什么？**
5. **噪声实验为什么在测试集上挑最好结果？若改用独立验证集，优势还剩多少？**
6. **图都归一化后，绝对声压是否真的被保存？源幅值和压力单位是什么？**
7. **全场相对 L2 下降，是否意味着焦点、旁瓣和相位也足够准？作者没有给哪些关键指标？**
8. **论文只验证固定点源，为什么能说可扩展到多激励源、有限尺寸阵元和 3D？哪一部分是实证，哪一部分只是 future work？**
9. **一张 MIDA 切片内改变人工血块，究竟是在验证经颅 skull 泛化，还是只验证固定头部内的局部介质扰动？**
10. **对于当前项目，最先做的应该是 3D FEUNet，还是先证明单阵元复场相加能重建多阵元场？**

对第 10 问，本 Agent 的答案是：**先做复场叠加的无网络最小验证**。如果该物理拆分在目标仿真设定下不成立，后续训练单阵元 surrogate 的项目价值会根本改变；如果成立，FEUNet 的复场输出与物理残差才值得进入下一轮模型比较。`[Agent 建议]`

## 6. 最终项目定位

- 是否进入核心文献表：**是，但定位为“二维频域复场 + 离散物理正则”的方法论文，不是 3D 阵列设计已解论文。**
- 是否值得精读：**值得；最值得精读 Eq.(1)、Eq.(11)-(12)、固定源 IO、Fig.8-10 的实验设计和讨论中的 3D / multiple-source 边界。**
- PPT 位置：**物理约束 surrogate 候选 / 频域复场输出 / 为什么不能直接照搬到可变阵元几何。**
- 对当前路线的最具体启发：**输出复场而不是单阵元 pmax，并在源几何显式条件化之后尝试 PDE residual；先验证叠加，再谈 3D 网络。**
- 最强反证：**当前项目固定介质、改变源；本文改变介质、固定源。二者变化轴相反，原始网络 IO 在本项目下会退化为相同输入对应多个输出。**
