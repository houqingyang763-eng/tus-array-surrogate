# 论文导读：Finite difference-embedded UNet

## 1. 值不值得读

值得选择性精读，质量判断为“方法想法有价值，但实验与复现证据中等”。最有价值的是把九点有限差分的 Helmholtz 残差加入 U-Net 训练；最主要的边界是二维、固定单源、关键训练参数缺失。

建议精读方法和讨论，不必逐字读长引言或反复比较相似结果图。

## 2. 论文结构地图

1. **引言，p.2257-2258**：为什么选择频域、为什么不满足于纯 U-Net 或逐模型 PINN。
2. **控制方程，p.2258-2259，式 (1)-(4)**：二维 Helmholtz 方程与 PML 边界。
3. **网络与物理约束，p.2259-2261，图 1-2、式 (7)-(12)**：普通 U-Net 如何预测复数波场，九点有限差分怎样形成额外损失。
4. **数值实验，p.2261-2266，图 3-10**：理想颅骨、MIDA 单切片、少样本和标签噪声实验。
5. **讨论与限制，p.2265-2268**：PINN 对比、软约束、3D 扩展、计算成本和表 I。

## 3. 最重要的 5 个审计问题

### 1. 原任务与当前项目的变化轴相反

论文输入只有介质速度图，声源位置和频率固定；当前项目固定 MIDA，主要改变阵元位置和法向。因此原始网络没有获得决定输出所需的 source geometry。论文中找不到阵元位置泛化的答案，因为作者没有研究这个变量。

### 2. 物理损失并不是独立物理证据

训练标签由最优九点 FD 生成，physics loss 又使用同一九点 FD 离散体系。结果说明该正则帮助网络更好地逼近同一个数值 teacher，但不能证明它修正了 teacher 的离散误差，或更接近实验真实场。

### 3. 关键复现信息缺失且存在尺寸矛盾

论文没有完整报告 `lambda_data / lambda_phy`、学习率、归一化、padding、随机种子、训练硬件和 wall-clock。理想颅骨尺寸还同时出现 `1000x1000` 与 `210x210`，脑模型出现 `151x151` 与 `150x150`。这些问题在正文里没有答案，需代码才能确认。

### 4. 少样本和抗噪结论受实验设计影响

不同样本量使用 trial-and-error 调整的物理损失权重，但具体值未给；噪声实验还从多次训练中选择“测试集最好结果”。因此趋势可以参考，精确优势可能偏乐观，不能直接当成稳定样本效率结论。

### 5. 作者把重要扩展留给了 future work

本文只验证二维标量声学、固定单源和固定频率；3D、多激励源、更完整的吸收 / 密度 / 固液耦合都在讨论中留作未来工作。阅读时不要费力寻找这些实证，论文没有提供。

## 4. 需要学习的理论板块

1. **频域 Helmholtz 方程，式 (1)**：介质和声源怎样决定复数压力场。
2. **PML，式 (2)-(4)**：如何避免计算区域边界反射。
3. **九点有限差分，式 (7)-(11)**：如何把离散波动方程变成可计算的 residual。
4. **数据损失 + 物理损失，式 (12)**：soft constraint 的核心机制与权重问题。
5. **相对二范数误差，式 (13)**：论文主要评价了什么，又遗漏了什么。

这里只需要先建立分块意识；读到具体障碍时再单独讨论公式。

1. 先看图 2，理解 FEUNet 只是在 U-Net 训练旁路加入 physics loss。
2. 再看式 (1)、式 (7)-(12)，抓住论文真正的方法贡献。
3. 看图 8-10，但带着“权重未报告、测试集挑最好结果”的警惕。
