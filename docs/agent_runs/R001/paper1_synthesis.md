## 0. 先给结论

这篇论文值得进入项目核心方法文献表，但定位必须准确：

> 它证明了在二维、固定单源、固定频率、简化标量声学条件下，让 U-Net 预测复数频域全场，并用最优九点有限差分 Helmholtz 残差辅助训练，可以比纯 U-Net 更准确、更耐少样本和标签噪声。

它最值得借鉴的不是 U-Net，而是：

1. 用 `Re[p], Im[p]` 两通道预测复数波场，保留相位；
2. 用固定差分模板检查网络输出是否满足离散波动方程；
3. 只在少量随机配点计算物理残差，降低额外训练成本。

它没有证明：

- 3D 可行；
- 阵元位置、法向、数量或阵列形状可以变化；
- 多阵元复场可以准确叠加；
- 输出保留绝对声压；
- 单频复场可以无条件等同于 time-domain pmax；
- 对真实经颅实验或独立高保真求解器更准确。

对当前项目最重要的结构性冲突是：

```text
论文：改变介质模型，固定声源
本项目第一版：固定 MIDA，改变阵元位置 / 法向
```

原论文网络只输入声速图，没有声源几何。若直接照搬到本项目，就会出现“同一个 MIDA 输入对应多个不同阵元声场”的欠条件映射。因此不能只把 2D U-Net 换成 3D U-Net；必须先重新设计 source / element geometry 条件输入。

## 2. 论文的完整数据流

```text
二维声速模型 v(x,y)
        |
        v
二维 U-Net
        |
        v
复数频域压力场 Re[p(x,y,w)], Im[p(x,y,w)]
        |                         |
        |                         +-> 与九点 FD 标签计算全场数据 MSE
        |
        +-> 在随机配点代入九点离散 Helmholtz 方程
                                  |
                                  v
                             PDE residual MSE

总损失 = lambda_data * 数据 MSE + lambda_phy * PDE residual MSE
```

推理时只运行 U-Net。有限差分残差只在训练期使用，所以 FEUNet 与普通 U-Net 的推理时间基本相同。

## 3. 最值得深入研究的公式链

### 3.1 频域 Helmholtz 方程

论文式 (1)，PDF p.2-3 / JASA p.2258-2259：

```text
Laplacian(p) + w^2 * m * p = s
m = 1 / v^2
```

含义：给定二维介质声速 `v`、固定角频率 `w` 和声源 `s`，求整个区域的复数压力 `p`。

关键量：

| 量 | 含义 | 单位 |
|---|---|---|
| `p(x,w)` | 复数压力场 | 有绝对标定时为 Pa |
| `v(x)` | 声速 | m/s |
| `m=1/v^2` | 平方慢度 | s^2/m^2 |
| `w=2*pi*f` | 角频率 | 1/s |
| `s` | 频域源项 | 与方程左侧同量纲 |

论文明确忽略剪切波、非线性和吸收；方程也没有把空间变化密度写进去。因此“满足物理”只表示满足这套简化标量声学模型。

### 3.2 为什么输出必须包含实部和虚部

若：

```text
p = p_real + i * p_imag
```

则：

```text
amplitude = sqrt(p_real^2 + p_imag^2)
phase = atan2(p_imag, p_real)
```

在线性、同频条件下，第 `n` 个阵元复场为 `p_n`，驱动幅值为 `a_n`、延迟为 `tau_n`：

```text
p_array(x,w) = sum_n a_n * exp(-i*w*tau_n) * p_n(x,w)
```

必须先在复数域叠加，再取幅值。若先把每个单阵元场变成 `pmax` 或 `|p_n|`，相位被删除，相长和相消干涉无法恢复。

这条数学关系是本文对当前“单阵元复场 + 多阵元相干叠加”路线最有价值的启发。但论文没有亲自做多源叠加实验。

### 3.3 九点有限差分怎样变成训练约束

论文式 (7)-(11)，PDF p.4 / JASA p.2260，使用中心点及其八个邻点：

```text
NW  N  NE
 W  C   E
SW  S  SE
```

在 `a=0.5` 时，Laplacian 可写成固定 `3x3` 卷积核：

```text
1/h^2 * [[0.25, 0.50, 0.25],
         [0.50,-3.00, 0.50],
         [0.25, 0.50, 0.25]]
```

质量项也使用九点加权：

```text
[[d, c, d],
 [c, b, c],
 [d, c, d]]

b = 0.6248
c = 0.09381
d = -0.00004
```

对网络输出的实部和虚部分别应用这些固定核，即可得到离散 PDE residual。它不是网络新学出的算子，也不是新的 U-Net 层；真正新增的是训练损失旁路。

### 3.4 软约束的边界

总损失为论文式 (12)：

```text
MSE_total = lambda_data * MSE_data + lambda_phy * MSE_phy
```

它是软约束：只能鼓励随机配点的平均 residual 变小，不能保证每个点严格满足方程。作者也在讨论中明确承认可能出现局部不物理预测。

更严重的复现问题是，作者没有报告各实验实际使用的 `lambda_data / lambda_phy`。样本减少时还会通过 trial-and-error 增大物理权重，因此少样本效果不只是一个固定配方的自然结果。

## 4. 网络和数据到底是什么

### 4.1 网络

- 二维 U-Net；
- 输入：二维速度模型；
- 输出：复波场实部、虚部两个通道；
- 编码通道约 `8 -> 16 -> 32 -> 64 -> 128`；
- `3x3 convolution + LeakyReLU(0.01)`；
- `2x2 max pooling` 下采样；
- 转置卷积上采样 + skip connection；
- Adam；batch size 16。

论文没有完整报告学习率、padding、随机种子、模型参数量、训练硬件、训练 wall-clock、归一化方法和物理损失权重。

### 4.2 理想颅骨实验

- 随机空心椭圆壳；厚度 5.5-27 mm；
- 颅骨声速 2820 m/s，背景 1500 m/s；
- 固定点源 `(131.25 mm, 248.75 mm)`；
- 固定 500 kHz；
- 训练 512，测试 100；
- 原文一处写 `1000x1000, 0.25 mm`；另一处运行时间讨论写 `210x210`，预处理关系未解释；
- 2000 个物理配点，占 0.2%。

### 4.3 MIDA 单切片实验

- MIDA 是 3D 解剖模型，但本文只选一张二维切片；
- 固定这张切片，只随机加入血凝块的位置、半径和声速；
- 输入 `151x151`，输出 `151x151x2`，网格 2 mm；
- 固定点源 `(150 mm, 256 mm)`；
- 固定 300 kHz；
- 训练样本 64 / 128 / 256 / 512，测试 100；
- 500 个物理配点，`500 / 151^2 = 2.19%`。

这不是跨 MIDA subject、跨颅骨、跨声源或跨频率泛化。

## 5. 实验真正证明了什么

### 已被本文支持

1. 同一二维 U-Net 加入九点 FD residual 后，测试复场相对 L2 低于 data-only U-Net。
2. 训练介质样本减少时，FEUNet 比普通 U-Net 退化更慢。
3. 在训练复场标签加入高斯噪声时，FEUNet 的展示结果更稳。
4. 随机抽取少量网格点即可形成有作用的物理正则。
5. 训练完成后，FEUNet 与普通 U-Net 推理成本基本相同。

### 证据不足或存在偏差

1. 标签和物理 residual 都来自同一最优九点 FD 体系，因此只证明更好地逼近同一个离散 teacher，不是独立真实物理验证。
2. 噪声实验多次训练后选择“测试集最好结果”，会产生乐观偏差；噪声也加在训练标签而不是网络输入。
3. “更少 epoch 到达相同误差”不等于总训练时间更短，因为 FEUNet 每步多算 PDE residual。
4. PINN 对照没有统一频率、预算和量化指标，不是严格公平的基准。
5. 全场相对 L2 下降不保证焦点、旁瓣、相位或绝对峰值准确。

### 表 I 的速度结果

100 个测试样本：

| 数据 | FEUNet | U-Net | FD | FD / FEUNet |
|---|---:|---:|---:|---:|
| 理想颅骨 | 17.8807 s | 18.2621 s | 74.2894 s | 4.155x |
| 二维脑 | 11.0852 s | 11.1698 s | 38.9433 s | 3.513x |

论文没有报告硬件、批处理和计时细节，不能把 3.5-4.2 倍外推到本项目 3D 设置。

## 6. 三个 Agent 的一致意见与保留分歧

### 一致意见

1. 核心价值是复数频域全场与离散 PDE residual，不是普通二维 U-Net。
2. 本文不能证明 3D、可变阵元几何、多源叠加、绝对 pmax。
3. 固定源输入结构与当前“固定 MIDA、改变阵元位置 / 法向”任务相反。
4. 同一九点 FD 同时生成标签和 residual，物理正确性证据不独立。
5. 最先应验证的是单阵元复场是否能重建多阵元场，而不是直接训练 3D FEUNet。

### 尚不能裁决的点

1. 训练标签是否保留绝对 Pa：图明确归一化，但正文没有完整说明训练归一化和反归一化。
2. PDE 配点是否避开 PML、源区和边界：论文未写，式 (11) 也没有包含前文 PML 的空间复系数。
3. `1000x1000 -> 210x210`、`151x151 -> 150x150` 的尺寸变化：论文未解释。
4. 物理损失实部 / 虚部如何归一化、具体 lambda、随机配点是否每 epoch 重采样：必须看代码。

这些问题不能靠 Agent 投票解决。

## 7. 对 tus-array-surrogate 能偷什么

### 值得偷

1. 单阵元响应 label 优先保存 `Re[G], Im[G]`，不要只保存单阵元 pmax。
2. 对规则网格复场使用与标签物理模型相容的离散 PDE residual。
3. 物理 residual 可在少量配点计算；三维中可研究界面、焦域、高梯度区重点采样。
4. 采用严格的 `data-only vs data+physics` 同主干消融。
5. 在少样本条件下研究物理正则是否改善未见阵元位置的相位和复场误差。

### 不能照搬

1. 只有声速图的输入；必须加入阵元位置、法向、有限尺寸或显式源分布。
2. 二维九点 stencil；三维和更完整物理需要重新选择离散算子。
3. 归一化复场作为绝对 pmax。
4. 一张 MIDA 切片的血凝块变化作为颅骨或阵列泛化证据。
5. 固定点源作为有限尺寸、有法向阵元。
6. 论文速度、样本数和显存直接外推到 3D。

## 8. 本文之后最值得深入研究的三个部分

### 第一优先：先验证复场叠加，不训练网络

```text
同一 MIDA + 同一频率
-> 分别仿真 2-4 个单阵元复场
-> 按相同驱动幅相做复数叠加
-> 与一次多阵元 full-wave 仿真比较
```

比较：复场相对 L2、幅值误差、相位误差、pmax、焦点位置和旁瓣。

这一步决定“单阵元 surrogate + 相干叠加”的物理拆分是否成立，优先级高于搭建 3D FEUNet。

### 第二优先：source geometry 怎样成为网络条件

需要比较：

- source / element dense mask；
- 阵元中心坐标 + 法向 + 尺寸；
- 有限孔径面上的驱动分布；
- 点 / 面几何编码器。

问题不是哪个编码“更高级”，而是哪个是当前仿真源的最小充分表示。

### 第三优先：PDE residual 与高保真 label 是否相容

如果 label 来自包含密度、吸收、k-space 或更复杂边界的求解器，而 residual 仍用简化标量 Helmholtz 方程，两项 loss 可能冲突。必须用独立实验检查 physics loss 是改善还是拉低高保真预测。

## 9. 你必须真正学会的知识

1. 复数压力的实部、虚部、幅值和相位怎样互相转换。
2. 为什么相干叠加必须在复数场上完成，pmax 不能直接相加。
3. Helmholtz 方程每一项在算什么，以及本文忽略了哪些真实物理。
4. 九点有限差分 stencil 怎样变成固定卷积核。
5. soft physics constraint 为什么不等于逐点严格满足物理。
6. 单频稳态 `|p|`、宽带 time-domain pmax、归一化场和绝对 Pa 的区别。
7. 为什么 label 与 physics loss 使用同一离散算子时，不能声称得到独立物理验证。
8. 为什么固定介质、变化声源的任务必须显式输入 source geometry。
9. 为什么更少 epoch 不等于更短训练时间。
10. 为什么全场相对 L2 小不保证焦点、旁瓣和相位正确。

### 理解检查

1. 如果只保存每个阵元的 `|p|`，为什么无法恢复两个阵元相消的区域？
2. 当前项目固定 MIDA 时，如果网络输入只有 MIDA 声速图，为什么不同阵元位置会造成一对多映射？
3. FEUNet 的 physics loss 与 PINN 自动微分 residual 有什么区别？
4. 为什么式 (11) 在 PML 区域可能不适用？
5. 若单频复场已归一化，为什么不能直接计算绝对 `P_target`？
6. 若高保真 label 包含吸收，而 residual 不含吸收，两个损失可能发生什么？
