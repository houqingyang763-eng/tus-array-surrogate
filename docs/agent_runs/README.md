# Agent Runs

本目录保存自主研究 mission 的中间产物和待审结果，不直接充当稳定项目记忆。

每个 mission 使用独立目录：

```text
docs/agent_runs/<mission-id>/
  report.md
  evidence.md
  experiment_plan.md（如需要）
```

最低交付结构：

1. 做了什么；
2. 使用了哪些来源；
3. 得到哪些有证据的事实；
4. 提出哪些尚未验证的想法；
5. 哪些尝试失败或仍不确定；
6. 建议怎样更新核心记忆；
7. 用户必须学习什么；
8. 哪些事项需要用户批准。

规则：

- 使用子 Agent 时，其结果只写入本 mission 目录；子 Agent 不是默认必选项；
- 只有主 Agent 负责综合；
- 未经用户验收，不把这里的结论升级为稳定共识；
- 大型原文、数据、模型和运行缓存不要复制进本目录。
