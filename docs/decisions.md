## 当前有效共识索引（2026-07-26）

1. 当前源构想为 `docs/project_concept_v7.md`；v6 及更早版本为历史来源。
2. 第一阶段固定 MIDA、频率、点源模型和激励幅值；网络介质输入为单通道三维声速场 `c(x,y,z)`；主要研究理想方向性点源的位置 / 法向变化，具体变化范围未定。
3. 主 U-Net 输出逐样本归一化的相对复声场 `q_Re/q_Im`；A4 输出脑内绝对峰值尺度；二者共同重建绝对 `Re/Im`。
4. target focus 不进入单源网络，只用于网络外的相位 / 延迟、阵列组合和下游评价。
5. 输出网格由固定频率下的最短波长、每波长网格点数、数值频散和收敛结果决定，不能只为降低计算量而过度降采样。
6. 多阵元阵列场在网络外由重建后的单阵元绝对复声场相干叠加；当前线性 k-Wave 设置下，无网络复场叠加已经通过数值验证。
7. 三维离散 Helmholtz 残差仍是核心物理约束候选；训练相对复场时须先用该训练样本已知的绝对尺度重建到绝对量纲，再与绝对源项计算残差。
8. 3D U-Net 是基础架构候选；点源条件固定为 `g=(x,y,z,nx,ny,nz)` 并在瓶颈接入。有限孔径、直径、表面点集和圆盘 source mask 不属于当前项目。
9. GreenONet 的项目适配实现当前冻结；没有作者代码、合格复现或直接任务依据时，不得自行拼接网络并据此评价该路线。

11. 论文精读主体始终是用户；Codex 默认只做一份简洁导读，不默认启动多 Agent 精读或 taste 校准。

## 历史决策记录

## 2026-07-26：冻结单通道声速输入与 target 下游边界

结论：

1. 第一版单源网络的介质输入固定为单通道三维声速场 `c(x,y,z)`；
2. target focus 不进入单源网络，只用于相位 / 延迟、阵列组合和下游评价；
3. `82 mm` 不再视为已知最大源—焦点路径；五层 U-Net 继续作为当前 V0，但其物理充分性须由真实几何范围和有效感受野验证。

依据：用户 2026-07-26 对阶段性交接方案的逐项确认。

边界：

1. 单通道声速只约束网络输入，不表示标签求解器禁止使用密度、吸收或其他物理量；
2. target 下游公式、固定频率延迟周期多解和阵列指标仍未确定；
3. 点源位置 / 法向范围和真实最大传播路径仍未确定。

## 2026-07-25：采用“相对复场 + 绝对尺度”分解

结论：

1. 基础仿真标签仍保存统一 Pa 和相位参考下的绝对 `Re_gt/Im_gt`。
2. 对每个样本，以 `A_gt=max_{brain_eval_mask}|p_gt|` 形成主网络 label：`q_gt=p_gt/A_gt`。
3. A3 使用共享 U-Net 的线性双通道输出头预测 `q_Re/q_Im`；A4 从共享条件化瓶颈独立预测 `A_gt`。
4. 推理时先计算 `m_hat=max_{brain_eval_mask}|q_hat|`，再以 `A_hat/(m_hat+eps)` 同时缩放 `q_Re/q_Im`，恢复绝对复场。
5. A4 是绝对复场重建所必需的尺度分支，不是与主声场无关的冗余标量头。
6. 网络外相干叠加只使用重建后的绝对复场。
7. Helmholtz 损失不得把绝对源项直接作用在无量纲 `q_hat` 上；阶段一须先用训练标签已知的 `A_gt` 恢复绝对量纲。

依据：

- 用户 2026-07-25 明确纠正主网络与 A4 的分工和陌生样本推理逻辑。
- TUSNet 的归一化声场与独立压力尺度设计提供邻近证据；本项目的三维复数重建协议见 `docs/project_concept_v7.md`、`experiments/initial_network_design/A3_reim_output_head_decision.md` 和 `A4_pmax_auxiliary_head_decision.md`。

边界：

1. `A_gt` 当前固定为 `brain_eval_mask` 内严格峰值；更换定义须新建协议版本。
2. 必须分别报告相对复场误差、A4 尺度误差和最终绝对复场误差。
3. 该决定替代“主 U-Net 直接预测绝对 Re/Im、A4 不参与重建”的旧口径，但不否定绝对仿真标签、绝对复场重建和相干叠加主线。

## 2026-07-24：当前声源固定为理想方向性点源

结论：

1. 单阵元按有位置和法向的理想点源处理，不使用有限孔径、直径或发射表面；
2. 点源位置和法向均为变量，变化范围尚未确定；
3. 网络条件为 `g=(x,y,z,nx,ny,nz)`；论文中的有限孔径表示不迁移到本项目。

依据：用户 2026-07-24 明确纠正。

边界：方向性点源在标签求解器和 Helmholtz 源项中的数学定义仍需一致化。

## 2026-07-22：Jang et al. (2025) 只作为特定输入协议下的邻近证据

结论：

1. 保留该论文对“经颅声场可由神经网络实时近似”“颅骨信息和换能器位姿可共同条件化预测”的直接证据。
2. 不把论文的 VAE 最优结果迁移为当前项目的网络选型结论。其六种 ADNet 全部基于同一个 `[315,512]` VGG19颅骨特征矩阵、瓶颈位姿融合和归一化最大压力场 label；VAE 只在该协议下略优于 Pix2pix。
3. 不把逐切片 VGG19 + GAP 定为项目颅骨预处理。论文没有比较它与直接输入 CT、声速或密度三维介质场；“有颅骨特征”对“无颅骨信息”的消融不能回答哪种介质表示更好。
4. 该论文没有证明瓶颈注入对所有任务普遍最优；当前项目后来已单独确认六维方向性点源在瓶颈接入。
5. 当前项目的网络比较必须固定自己的相对复场 label、A4 绝对尺度协议、位置 / 法向划分和最终绝对复场指标后进行；不同输入表示下的网络排名不得直接横向迁移。

依据：

- 论文：Minyeong Jang et al., `Deep learning-based real-time estimation of transcranial focused ultrasound acoustic field`, *Engineering Applications of Artificial Intelligence* 156 (2025) 111157，https://doi.org/10.1016/j.engappai.2025.111157。
- 论文第 3.1 节 / 图 4：CT `[315,400,400]` 被逐切片送入预训练二维 VGG19，经 GAP 得到 `[315,512]`；作者未报告与直接三维介质输入的对照。
- 论文第 3.2 节 / 图 5：六种 ADNet 共享该特征输入；位姿 `[6,1]` 经全连接映射后在瓶颈处融合；融合运算细节未充分说明。
- 论文表 6：VAE 的 `ΔFP=4.17±2.85 mm`、`HD=10.18±6.23 mm`、`DSC=0.64±0.15`，Pix2pix 非常接近；没有给出足以支持普遍架构优越性的统计检验。
- 论文表 7：只比较“VGG颅骨特征 + 位姿”和“只有位姿”，证明颅骨信息有益，但不证明 VGG 表示最优。
- 计算推导：图 5(a) 六层 `k=4,s=3` 编码器的理论感受野为 `4→13→40→121→364→1093`，已覆盖 `[315,512]` 特征矩阵；但 `512` 轴是特征编号而非物理空间，不能换算为规则三维毫米感受野。
- 用户 2026-07-22 精读后确认：该特异输入显著限制后续网络排名对直接介质输入项目的迁移意义，VAE与瓶颈位姿融合均应重新讨论。

边界 / 适用范围：

1. 该判断限制的是具体网络与输入协议的迁移，不否定论文的实时性、实验验证或“加入颅骨信息优于完全不加入”的结果。
2. VAE、低维位姿和 VGG式预训练特征仍可作为对照候选；只有在当前项目的绝对复场任务上通过公平消融，才能升级为方案。
3. 第一阶段固定 MIDA 时，介质体对所有样本不变；是否显式输入介质、缓存固定编码或让介质隐含在模型参数中，仍属于开放设计问题。Helmholtz损失计算仍必须显式使用正确介质。

## 2026-07-21：当前主线改为三维单阵元绝对复声场预测

> 状态补充：本节对绝对复场物理目标与相干叠加的判断继续有效；“有限孔径 / 固定阵元尺寸”已被 2026-07-24 的理想方向性点源决定替代，“主网络直接预测绝对 Re/Im”已被 2026-07-25 的相对复场与绝对尺度分解决定替代。

结论：

1. 删除“低分辨率大区域绝对 pmax baseline”作为当前路线；pmax 降为由复声场计算的下游量或对照量。
2. 当前路线是在固定 MIDA、频率、阵元尺寸和激励幅值下，以阵元位置和法向为主要变化量，预测指定三维域内的单阵元绝对复声压 `Re/Im`。
3. 多阵元场在网络外进行带幅值和相位 / 延迟权重的复数相干叠加。
4. 输出分辨率必须服从固定频率下的波长解析与网格收敛要求，不能把“低分辨率”本身设为目标。
5. 与标签物理模型一致的三维离散 Helmholtz 残差，作为全复声场预测的核心物理损失候选，与监督数据损失联合使用。
6. FEUNet 的二维九点格式不能原封不动搬到三维；三维残差必须采用有来源的 3D Helmholtz-PML 离散格式并独立验证。
7. 配置点分层抽样获准进入调研，候选层包括普通介质内部、介质界面、声源附近、焦点附近和 PML / 外边界；当前尚未确定比例和实现。

依据：

- 用户 2026-07-21 对项目路线、Helmholtz 角色、分辨率和分层抽样的明确确认。
- FEUNet：`Finite-difference-embedded UNet for solving the 2-D heterogeneous Helmholtz equation`，https://doi.org/10.1121/10.0025391；提供二维 `Re/Im` 波场、监督损失和离散 Helmholtz 物理损失联合训练的方法证据，但不直接证明当前三维可变方向性点源任务。
- 3D 离散依据候选：Chen et al., `A 27-point finite-difference scheme for the three-dimensional Helmholtz equation with perfectly matched layer`, https://doi.org/10.1016/j.jcp.2012.07.048；以及 Chen, `An average-derivative optimal scheme for frequency-domain scalar wave equation`, https://doi.org/10.1111/1365-2478.12090。
- 本地叠加验证：`experiments/elementwise_superposition/RESULTS.md`，最差复场相对 L2 为 `5.81e-6`。

边界 / 适用范围：

1. 当前证据证明物理表达、二维方法先例和三维差分工具存在；尚未证明项目所需的“3D MIDA + 可变方向性点源位置 / 法向 -> 绝对复声场”网络已经达到可用精度。
2. 密度是否是声速之外唯一值得加入的介质通道尚未定论；需要先核对标签方程、损失方程和相关消融证据。
3. 固定频率的具体取值、三维网格、边界条件、损失权重与分层抽样比例仍属于开放问题。

## 2026-07-20：冻结 GreenONet 项目适配实验，保留 Green 物理分解

结论：

1. 在当前线性、标量流体声学边界内，固定频率复声压可以使用复数 Green / Helmholtz 表示；“单阵元复响应 + 网络外相干叠加”的物理分解继续保留。
2. 原 GreenONet 到项目任务的迁移不是简单复现：任务从时域初值算子变为固定频率、三维异质介质、有限尺寸阵元、可变位置 / 法向和绝对 `Re/Im` 复声压预测。
3. 当前停止重做自写 Green V2、停止继续设计项目版 Green 网络、停止为该路线生成新的颅骨训练标签。
4. 旧 V2 降级为历史 `custom Fourier-SiLU baseline`；V1 只保留显存 / 吞吐工程证据，V2 结果不能评价 GreenONet、SIREN 或 Green 数学路线。
5. 当时决定把近期资源转回低分辨率大区域绝对 pmax；该去向已被 2026-07-21 的复声场主线替代。GreenONet 实现冻结和 Green 物理分解保留的部分仍有效。

依据：

- 论文：Aldirany et al., `Operator approximation of the wave equation based on deep learning of Green's function`, https://arxiv.org/abs/2307.13902；采用物理残差训练，数值实验只到 1D / 2D，并把 3D 作为未来工作。
- 同组后续：Aldirany et al., `Accurate solution of linear operator approximations using Green's functions by a multi-level neural network approach`, WCCM 2024；实证仍是 1D Poisson，并报告小尺度修正存在过拟合、需要很大的训练函数族。
- 来源审计：`experiments/green_complex_derisk/SOURCE_EVIDENCE.md`；两圈检索未找到原 GreenONet 官方实现、B 级第三方复现或直接覆盖“复数频域 + 3D 异质介质 + 有限孔径 + 可变位置 / 法向”的公开代码。
- 自定义实验：`experiments/green_complex_derisk/RESULTS.md`；V2 训练集复场 L2 仍约 `42%`，但模型、教师与训练流程均为自写，因此只能阻止该配置进入颅骨阶段。
- 物理实验：`experiments/elementwise_superposition/RESULTS.md`；三组 benchmark skull 幅相组合全部通过，最差复场相对 L2 为 `5.81e-6`，证明当前求解器设置下的复场重组成立，但不证明神经网络能预测单阵元复场。
- 用户确认：2026-07-20 要求在缺少原代码、样例数据和可审计复现时停止冒险实现，并将该判断留痕。

边界 / 适用范围：

1. 本决策否决的是“当前证据条件下继续自研 GreenONet 项目适配实验”，不是否决 Green 函数数学、线性叠加或所有可能的阵元级复响应 surrogate。
2. 原 GreenONet 不依赖完整波场 label；但项目若改走监督学习，需要自建标签和任务，若改走物理约束训练，则需要自定义 3D 复数 Helmholtz、有限孔径、吸收和 PML。两者目前都属于新方法研究，不是原样复现。
3. 常规项目适配实验只有同时满足以下条件才解冻：原始或直接邻近作者实现已原样复现；实现至少直接支持固定频率复场与可变源条件；迁移只需环境或数据适配；标签 / 采样协议与资源预算有来源或得到导师明确批准。
4. 若导师明确把它批准为“原创高风险神经算子方法研究”，可以另立 mission；届时必须使用自定义方法名称，并接受失败只评价该改造、不能单独判死 Green 路线。

## 2026-07-02：DeepTFUS / TFUScapes 作为本项目核心参考论文

结论：

1. `A Skull-Adaptive Framework for AI-Based 3D Transcranial Focused Ultrasound Simulation` / DeepTFUS / TFUScapes 应作为本项目核心参考论文之一。
2. 该论文直接证明了 `3D skull / pseudo-CT volume + transducer geometry -> 3D pmax / pressure amplitude field` 的经颅超声 surrogate 路线已有公开工作。
3. 该论文适合用于组会 PPT 中的“3D TUS surrogate 已有工作”“3D IO 设计”“训练数据生成成本”“当前方法缺口”部分。
4. 该论文不能直接作为本项目完整方案，因为它输出 normalized pmax field，不输出绝对声压或复声场；它也不支持多阵元数量变化、任意阵列形状变化或单阵元复声场相干叠加。
5. 该工作有公开 GitHub 仓库和数据入口；用户本轮确认已有复现案例，可作为后续查代码、查复现和做对比实验的重要入口。

依据：

- 论文：Srivastav et al., `A Skull-Adaptive Framework for AI-Based 3D Transcranial Focused Ultrasound Simulation`, arXiv:2505.12998, 2025。
- GitHub/代码：官方仓库 https://github.com/CAMMA-public/TFUScapes 公开 TFUScapes 数据下载入口、样例数据和 `visualize.py`；README 描述 DeepTFUS 从 3D CT volumes 和 transducer position 估计 normalized pressure fields。
- 用户明确确认：需要把 DeepTFUS 作为核心参考写入 decision，并强调其在 GitHub 上有开源代码且已有复现。
- 项目文档：`docs/project_concept_v2.md` 当前主线包括 whole-brain pmax field 和单阵元复声场叠加路线；DeepTFUS 直接对照前者，但不能覆盖后者。

边界/适用范围：

1. 截至本次检查，官方 GitHub README 的 `Models` 部分写为 `coming soon`；因此“开源代码”当前应谨慎理解为公开仓库、数据入口、样例和可视化脚本，完整模型训练代码是否已公开仍需继续核实。
2. “已有复现”来自用户本轮确认，后续应补充具体复现仓库、复现实验或复现报告链接。
3. 该论文可作为 3D pmax surrogate 的主线参考，但不能证明本项目的多阵元阵列、阵元数量变化、阵列形状变化和复声场相干叠加路线已经可行。
