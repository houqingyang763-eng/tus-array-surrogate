# 论文导读规则 v3：AI 预读，人来精读

## 定位

论文精读的主体永远是用户。Codex 可以完整预读论文，但默认只交付读前导览，作用是：

1. 帮用户快速看懂论文结构；
2. 提前指出最值得怀疑的少数问题；
3. 标出需要认真学习的理论板块；
4. 在用户阅读后充当反问者、讨论者和记录者。

Codex 不应代替用户逐段精读，也不应输出比原论文更长的伴读材料。

## 默认执行方式

1. 默认使用单 Agent 完整预读。
2. 不默认启动多 Agent、taste 校准、逐节证据报告或公式逐步教学。
3. 只有用户明确要求对某个窄问题独立复核时，才考虑额外 Agent。
4. 默认只生成一份综合导读；底层证据留在当前推理中，不再重复写成多份文档。
5. 已经写入 `decisions.md`、且用户明确掌握的结论不重复科普，除非本论文提供了新证据或反例。

## 唯一默认交付物：论文导读

### 1. 值不值得读

用几句话回答：

- 论文质量大致如何；
- 是否值得精读、选择性阅读或略读；
- 最有价值的贡献是什么；
- 对当前项目的关系只给一个总判断，不展开重复检查表。

### 2. 论文结构地图

按论文自身顺序列出 4-7 个部分，说明每部分解决什么问题，并给章节、页码、图表或公式入口。

目标是让用户打开 PDF 后知道先看哪里，而不是替用户复述全文。

### 3. 最重要的审计问题

最多 5 个。必须合并同类项并按重要性排序。

优先保留：

- 缺失的关键参数或方法细节；
- 前后矛盾；
- 实验设计偏差；
- 作者结论超出证据；
- 论文没有回答、用户不必在正文中继续寻找的问题。

每个问题需要解释为什么重要、影响哪条结论，并给定位。不要罗列十几个细碎缺口。

### 4. 需要学习的理论板块

只列主要理论 / 公式块及其用途，例如：

- Helmholtz 方程：控制什么物理量；
- 九点有限差分：怎样形成离散物理残差；
- 总损失：数据项与物理项怎样组合。

默认不逐符号教学、不展开长推导。用户读到具体困难后再问。

### 5. 建议阅读路线

告诉用户：

- 建议先读哪些页、图、表、公式；
- 哪些背景或重复实验可以快速看；
- 带着哪几个问题进入正文。

## 去重规则

1. “能偷 / 不能偷”“项目逐项对照”“局限性”只在一个位置表达，不重复成多个章节。
2. 不为每个图表再重复一次总判断。
3. 不重复用户已经掌握的稳定结论。
4. 不同时生成主报告、证据审计、技术深挖和用户批注模板。
5. 默认不超过约 2000 中文字；确有必要时先压缩结构，再增加篇幅。

## 公式与格式

1. 默认用简洁的纯文本 / Unicode 公式，例如 `∇²p + ω²mp = s`。
2. 除非已确认当前 Markdown 渲染器支持，否则不输出大段 LaTeX 源码。
3. 公式只承担“告诉用户这里有哪块理论”的作用，不默认承担完整教学。
4. 表格只在比较关系明显更清楚时使用。

## 用户读后流程

用户精读后，Codex 再根据具体问题：

1. 解释用户点名的公式、图表或术语；
2. 质疑或验证用户的判断；
3. 帮助设计最小实验；
4. 只在用户确认后，把稳定结论写入项目记忆。

## 证据边界

- 论文事实尽量给页码、章节、图表或公式位置；
- 作者声明与实验实证要区分；
- 没有公开代码或关键参数时直接说明“论文没有答案”；
- 不用 Agent 推测补齐缺失方法；
- 不因追求完整而牺牲重点。
