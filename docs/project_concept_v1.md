# 项目初构想 v1：单最小发声单元响应网络 + 阵列相干叠加

## 0. 文件用途

这是“3D 经颅超声阵列快速评估网络”项目的当前源构想文件。

后续 AI 读取本文件时，应优先围绕以下问题工作：

1. 单最小发声单元的 3D 复声场能否被神经网络快速预测；
2. 多个单元响应能否通过相干叠加构成任意阵列声场；
3. 这个路线在 3D 经颅调控、阵列初设计中是否可行；
4. 需要查哪些论文验证该路线的科学依据、误差和适用条件。

---

## 1. 项目目的

搭建一个 **3D 经颅超声阵列快速评估网络**。

当前用途不是精确替代完整 k-Wave 临床仿真，而是服务于 **初代阵列设计迭代**：

> 输入一版阵列设计，快速判断它在给定头颅和目标焦点下的聚焦效果，用于比较不同阵列方案优劣。

目标速度：

```text
训练完成后，1 分钟量级输出一张 3D 聚焦声场图
````

---

## 2. 当前最重要的新主线

### 2.1 不优先学习“整个阵列 → 整个声场”

旧思路容易写成：

```text
输入：整个阵列几何 + 头颅声速图 + 目标焦点
输出：整个阵列聚焦后的 3D 声场
```

但这个问题太大：

1. 阵列位置会变；
2. 阵列形状会变；
3. 阵元数量会变；
4. 阵元间距会变；
5. 填充率会变；
6. 如果直接让网络学“整阵列到声场”，泛化难度很高。

因此 v1 的核心转变是：

> 不先学习整阵列，而是学习一个更基础的物理对象：**单个最小发声单元在不同空间位置和法向朝向下的 3D 复声场响应**。

---

### 2.2 当前核心设想

把阵列问题拆成两步：

```text
Step 1:
单个最小发声单元 → 3D 复声场

Step 2:
多个单元复声场 + 各自延迟 → 相干叠加 → 整个阵列聚焦声场
```

也就是说，真正要优先训练的是：

```text
单最小发声单元响应网络
```

而不是：

```text
整阵列声场网络
```

---

## 3. 单最小发声单元响应网络

### 3.1 最小发声单元是什么

“最小发声单元”暂时不等于 0.5 mm 仿真网格点。

它应该由真实硬件决定，优先理解为：

```text
一个真实可独立控制的阵元 / 电通道
```

原则：

```text
一个真实可独立控制的电通道 = 一个 source = 一个 delay
```

而不是：

```text
一个 0.5 mm mask = 一个 source = 一个 delay
```

原因：

1. PMUT/CMUT 阵列中，一个阵元内部可能包含多个微小单元；
2. 这些微小单元未必能独立接线、独立通电、独立延迟；
3. 网络 delay 输出粒度应等于真实独立通道粒度；
4. 初代阵列设计可能只需要阵元级/通道级，而不需要单元内部微结构级。

---

### 3.2 单元响应网络的输入

网络输入不是整个阵列，而是一个单元的空间状态。

推荐输入：

```text
1. 局部 ROI 声速图
   c(x, y, z)

2. 单个最小发声单元的位置
   source_position = (x_s, y_s, z_s)

3. 单个最小发声单元的法向 / 朝向
   source_normal = (n_x, n_y, n_z)

4. 单元的几何参数，可选
   source_area
   source_size
   source_shape
   fill_factor

5. 固定频率
   f = 500 kHz
```

最关键的新输入：

```text
source_position + source_normal
```

后续论文阅读和网络设计要重点关注：

```text
单个 source 的空间位置、法向朝向、有限尺寸和指向性如何编码进神经网络
```

---

### 3.3 单元响应网络的输出

输出不是该单元的 Pmax 图。

输出应该是该单元在 500 kHz 下的 **3D 复声场**。

推荐输出形式之一：

```text
Re[G_s(x, y, z)]
Im[G_s(x, y, z)]
```

或：

```text
A_s(x, y, z)
sin_phi_s(x, y, z)
cos_phi_s(x, y, z)
```

含义：

```text
A_s：该单元在每个空间点产生的声压幅值
phi_s：该单元在每个空间点产生的相位
G_s：该单元对每个空间点的可叠加复声压贡献
```

禁止误解：

```text
不能只输出 Pmax_s(x, y, z)
```

原因：

```text
单个单元的 Pmax 图已经丢掉了相位/时间信息，不能直接相干叠加。
```

---

## 4. 构造阵列时如何使用

未来一版阵列可以表示成多个最小发声单元：

```text
unit_1: position_1 + normal_1 + delay_1 + amplitude_1
unit_2: position_2 + normal_2 + delay_2 + amplitude_2
unit_3: position_3 + normal_3 + delay_3 + amplitude_3
...
unit_N: position_N + normal_N + delay_N + amplitude_N
```

对每个 active 单元：

```text
用单元响应网络预测它自己的 3D 复声场
```

然后根据每个单元的 delay 做相位修正。

最后把所有单元的复声场相干叠加，得到整个阵列的聚焦声场。

最终输出：

```text
1. 聚焦后的局部 3D 声场图
2. 焦点处声压 P_target
3. ROI 内峰值压力 P_peak
4. 峰值点到目标点距离 focus_error
5. 旁瓣水平 side_lobe_ratio
6. 每个独立通道的 delay_j
```

---

## 5. 为什么这个想法重要

如果“单元响应 + 相干叠加”路线成立，那么阵列设计问题会被大幅简化。

阵列形状不再是网络必须直接学习的复杂对象。

阵列可以被理解为：

```text
若干个最小发声单元的集合
```

于是：

```text
阵列形状变化 = active 单元集合变化
阵元数量变化 = active 单元数量变化
阵元间距变化 = active 单元空间排布变化
填充率变化 = active 单元选择比例变化
阵列位置变化 = 单元位置整体变化
阵列朝向变化 = 单元法向整体变化
```

项目核心难点从：

```text
学习所有可能阵列 → 声场
```

转变为：

```text
学习单个最小发声单元在不同位置和法向下的 3D 复声场
```

这条路线天然更适合阵列初设计，因为它支持阵列几何自由组合。

## 6. 当前总输入输出

### 6.1 训练单元响应网络时的 IO

输入：

```text
1. 局部 ROI 声速图
   c(x, y, z)

2. 单个最小发声单元位置
   source_position = (x_s, y_s, z_s)

3. 单个最小发声单元法向
   source_normal = (n_x, n_y, n_z)

4. 固定频率
   f = 500 kHz
```

输出：

```text
该单元在 ROI 内的 3D 复声场

可选表示：
1. Re[G_s], Im[G_s]
2. A_s, sin_phi_s, cos_phi_s
```

---

### 6.2 构造完整阵列时的 IO

输入：

```text
1. 局部 ROI 声速图
2. 阵列中所有 active 单元的位置
3. 阵列中所有 active 单元的法向
4. 每个 active 单元的 delay
5. 每个 active 单元的 amplitude，可选
6. 目标焦点 target
```

输出：

```text
1. 聚焦后的局部 3D pressure amplitude map
2. P_target
3. P_peak
4. focus_error
5. side_lobe_ratio
6. delay_j
```

## 7. 方法假设

### 7.1 固定频率

当前固定：

```text
500 kHz
```

因此不优先输出完整时域波场。

---

### 7.2 不输出完整时域波场

不直接输出：

```text
p(x, y, z, t)
```

原因：

```text
3D ROI × 200 时间步 数据量过大
```

当前采用：

```text
500 kHz 下的复声场 / 幅相表示
```

即用：

```text
幅值 + 相位
```

替代完整时间序列。

注意：

```text
频域方案不是说物理上没有时间，
而是把固定频率下的时间振荡压缩成幅值和相位。
```

---

### 7.3 叠加前提

单元响应叠加成立的前提：

```text
1. 经颅调控声压范围内，线性声学近似成立
2. 叠加对象是声压或复声压，不是 Pmax 或能量
3. 颅骨传播虽然复杂，但仍然可近似为线性传播系统
4. 阵元之间的硬件耦合可忽略，或误差可接受
5. 单元位置和法向的预测/采样精度足够高
```

---

## 8. 当前最需要查论文验证的问题

后续论文阅读要优先围绕以下问题：

```text
1. 有没有人做 single-source / single-element response prediction？

2. 有没有人用单元响应叠加构造阵列声场？

3. 他们叠加的是：
   - 时域声压？
   - 频域复声压？
   - Green's function？
   - 还是错误地叠加 Pmax？

4. 有没有验证：
   单元响应叠加结果 ≈ 整阵列 full-wave 仿真结果？

5. 在经颅超声或复杂介质中，
   单元响应叠加误差有多大？

6. source_position 和 source_normal 如何编码进网络？

7. 单元位置采样精度与 500 kHz 波长、相位误差之间如何权衡？

8. 是否可以让网络连续预测：
   任意 source_position + source_normal → 3D 复声场？

9. 单元有限尺寸、指向性、法向偏转角如何建模？

10. 阵元之间硬件耦合是否会破坏单元独立响应假设？
```

---

## 9. 当前最大风险

### 9.1 风险 1：单元位置/法向精度不足

500 kHz 下软组织中波长约为 3 mm 量级。
如果 source 位置误差达到 0.5 mm，就可能造成明显相位误差。

因此：

```text
source_position 和 source_normal 的编码、采样和预测精度非常重要。
```

---

### 9.2 风险 2：单元响应输出仍然很大

即使不输出时域，只输出 3D 复声场，单个单元响应也可能较大。

如果对很多候选单元位置都输出完整 3D 复声场，数据量仍然可能很高。

因此后续需要考虑：

```text
1. 局部 ROI
2. patch-based 输出
3. query point 输出
4. 只输出焦点和旁瓣检测点
5. 用神经网络连续表示单元响应，而不是建立巨大查表数据库
```

---

### 9.3 风险 3：阵元不是理想点源

如果最小发声单元尺寸接近波长，例如 3 mm × 3 mm，而 500 kHz 波长约 3 mm，则它不能简单看成理想点源。

需要考虑：

```text
1. 有限尺寸面源
2. 指向性
3. 法向偏转角
4. 有效孔径
5. 单元内部 PMUT/CMUT 小单元的等效影响
```

---

## 10. 暂不优先做的事情

当前 v1 不优先做：

```text
1. 不做全脑输出
2. 不直接输出完整 p(x, y, z, t)
3. 不把 0.5 mm 仿真网格点默认当独立 delay 通道
4. 不优先训练“整阵列 → 整声场”的黑箱网络
5. 不优先建立巨大单元响应数据库
6. 不默认 PMUT/CMUT 单元内部每个小 cell 都独立控制
```

---

## 11. 需要问师兄的问题

### 11.1 问题 1：真实硬件最小独立通道是什么？

需要明确：

```text
1. 阵列总口径是多少？
2. 大约多少个阵元？
3. 每个阵元多大？
4. 阵元间距是多少？
5. 一个阵元内部是否由多个 PMUT/CMUT 单元组成？
6. 如果有，这些单元是否共用一个电通道？
7. 真实可独立施加 delay 的最小单位是什么？
```

这决定“最小发声单元”的定义。

---

### 11.2 问题 2：初代阵列设计到底需要多精细？

需要明确：

```text
1. 是否只需要比较阵列口径、曲率、贴附位置、阵元间距、填充率？
2. 是否需要进入阵元内部微结构？
3. 粗阵列设计中，焦点误差、焦点压力误差、旁瓣误差做到多少算可接受？
```

---

### 11.3 问题 3：单元响应叠加在经颅调控声压范围内是否可接受？

需要明确：

```text
1. 经颅调控声压大约是多少？
2. 线性声学近似是否成立？
3. 阵元之间硬件耦合是否需要考虑？
4. 是否需要非线性 k-Wave 仿真验证？
```

---

## 12. 当前一句话总结

当前 v1 构想是：

> 本项目不优先训练“整阵列到声场”的黑箱网络，而是训练一个“单最小发声单元响应网络”：输入局部头颅声速图、单元空间位置和法向朝向，输出该单元在 500 kHz 下的 3D 复声场；之后任意阵列都由多个单元响应按 delay 相干叠加得到聚焦声场。这个路线能天然支持阵列形状、阵元数量、阵元间距和填充率变化，但必须重点验证线性叠加误差、source 位置/法向精度、有限尺寸单元建模和数据量问题。
