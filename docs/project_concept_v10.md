# V10：颅外单点源的颅内复声场形状

GitHub阅读版更新：2026-10-18。稳定物理边界沿用本地V10合同，当前研究方法以2026-10-16采纳的[任务书](<../experiments/survey&design/exploration 01/MISSION.md>)为准。

`介质与源 → 真实物理残差迭代＋学习校正 → 颅内Re/Im复场形状`

- 固定MIDA、500 kHz，头皮外移10 mm、水耦合、各向同性单网格additive源。法向用于放置，不是有限孔径方向性。
- 完整求解384×480×224 @0.5 mm；临时输出ROI352×352×192，裁切不改变物理域。
- 保持共同相位与相对幅值形状，禁用raw评价，不恢复绝对Pa、阵列拼接或Park加速目标。
- 当前优先固定介质与未见源；多颅骨仍是后续扩展，不自动扩大实验。
- 本轮要求自主方法贡献：关键问题、计算机制、最近先例的差异及可区分验证。McMg是强对照，纯迁移只作为基线。
