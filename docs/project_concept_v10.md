# V10：颅外单点源的颅内复声场形状预测

GitHub阅读版，2026-10-10；提炼自本地同名构想、V10 handoff与架构MISSION。保留稳定目标，阶段性运行记录放在[状态页](CURRENT_STATUS.md)。

`固定介质表示 + 颅外点源XYZ + P0参考复场 → 颅内三维Re/Im复声场形状`

- 固定MIDA、500 kHz、头皮沿局部外法向外移10 mm、水耦合、各向同性单网格additive压力点源。法向用于放置，不表示有限孔径方向性。
- 只研究形状与共同相位；禁用raw评价、不恢复A4、阵列拼接或Park加速目标。
- 完整仿真384×480×224 @0.5 mm；临时网络输入输出ROI352×352×192，XYZ切片[16:368,64:416,32:224]。网络裁切不缩小物理求解域。
- 第一优先级是固定介质的未见源与局部干涉细节；可变颅骨是后续扩展。绝对尺度与点源叠加在本轮暂不展开。
- 当前已有T512-V9BASE；M0是待验证设计。大域/高频/变源是任务条件，方法贡献仍需机制消融与大幅形状改善。
