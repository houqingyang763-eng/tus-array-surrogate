## 1. 项目定位

项目面向 3D 经颅超声阵列早期设计，目标是建立神经网络 surrogate model，快速预测不同阵元几何条件在固定头颅模型中的三维复声场响应，并在网络外完成多阵元相干叠加与阵列指标计算。

```text
MIDA 头颅声学体数据
+ 单阵元位置 / 法向 / 有限孔径几何
+ 固定频率与激励条件
-> 单阵元在指定三维预测域内的绝对复声压场 Re[p], Im[p]
-> 多阵元幅值 / 相位 / 延迟加权相干叠加
-> 阵列复声场、焦点绝对声压、pmax 与阵列设计指标
```

当前目标不是替代临床级 full-wave simulation，而是建立可验证、可加速阵列初筛的预测链路。

---

## 2. 第一阶段范围

### 2.1 固定条件

```text
head model: MIDA
frequency: 固定，具体值待确定
element size: 固定
excitation amplitude: 固定且保留绝对标定
```

固定这些变量，是为了先隔离并研究阵元几何变化，不代表后续无需扩展频率、尺寸和幅值。

### 2.2 主要变化变量

```text
element_position = (x, y, z)
element_normal = (nx, ny, nz)
```

阵元有限孔径如何随位置和法向写入网络输入、标签仿真和 Helmholtz 源项，必须保持一致。目标点是固定、离散变化还是连续条件化，仍待确认。

### 2.3 输入

必需输入：

1. MIDA 三维头颅声学体数据；
2. 单阵元位置；
3. 单阵元法向；
4. 与实际仿真一致的有限孔径 / 源几何表示。

当前候选：

1. 声速是基础介质参数；
2. 用户当前倾向只增加密度，不继续堆叠更多介质通道，但该选择尚无充分依据，需先调研；
3. 阵元几何可采用有限孔径 mask、表面点坐标、位置 / 法向低维条件或其组合；
4. 目标焦点 / 目标区域是否作为输入仍待确定。

### 2.4 输出

主输出：

```text
single-element 3D absolute complex pressure field
= Re[p(x, y, z, omega)] + i Im[p(x, y, z, omega)]
```

要求：

1. 覆盖项目需要观察的整个指定三维预测域，不退化成只预测焦点附近小 ROI；
2. 保留统一的绝对幅值和相位参考，支持不同阵元响应的相干叠加；
3. 输出分辨率由固定频率下的最短波长、每波长网格点数、数值频散和网格收敛共同决定；
4. 不按样本独立归一化到各自最大值，避免破坏阵元之间的绝对幅值关系。

下游量：

```text
P_target
P_peak / pmax
focus_error
side_lobe_ratio
phase / delay settings
脑内非目标高压统计
```

这些量由复声场后处理计算还是由额外网络头预测，尚待学习和确定；Helmholtz 残差约束的是复声场，不直接约束上述标量结果。

## 3. 当前核心路线

```text
MIDA + single-element position / normal / aperture
-> neural network predicts absolute Re/Im field
-> coherent summation outside the network
-> array field and design metrics
```

该路线的必要依据与边界：

1. 当前线性 k-Wave 设置下，无网络的单阵元复场叠加已通过数值验证；
2. FEUNet 提供了“介质模型 -> Re/Im 频域波场 + 数据损失 + 离散 Helmholtz 物理损失”的二维方法证据；
3. 已有文献给出三维 Helmholtz 的 27 点有限差分及 PML 格式，说明三维物理残差不存在九点法无法扩展的数学断层；
4. 现有证据仍未直接证明“3D MIDA + 可变有限阵元位置 / 法向 -> 绝对复声场”的神经网络已经可用，正式实现必须绑定可审计来源或经批准的新方法研究。

---

## 4. 损失函数与物理约束

候选总损失：

```text
L_total = lambda_data * L_data + lambda_phy * L_Helmholtz + optional task losses
```

### 4.1 数据损失

`L_data` 比较预测与仿真标签的绝对 `Re/Im` 复声场。是否加入焦点、颅骨界面、旁瓣或相位加权，需通过指标与消融实验确定。

### 4.2 Helmholtz 物理损失

将网络预测的复声场代入与项目物理模型一致的三维离散 Helmholtz 算子，计算残差：

```text
r = H_3D(p_hat; medium, frequency, PML, source) - s
L_Helmholtz = mean(|r|^2)
```

要求：

1. 标签求解器与物理损失中的介质、源、频率和边界条件必须一致；
2. 三维差分格式必须采用已发表来源，不自行拼接后继续沿用 FEUNet 名称；
3. 损失项在调整权重前应进行量纲 / 数量级归一化；
4. 物理约束是软约束，不能代替独立求解器、网格收敛和实验验证。

### 4.3 配置点抽样

不默认照搬 FEUNet 的全域均匀随机抽样。当前批准研究分层抽样候选：

```text
普通介质内部点
颅骨 / 介质界面附近点
阵元 / 声源附近点
目标焦点附近点
PML / 外边界相关点
```

各层比例、是否动态重采样以及是否对高残差区域自适应加密，均需文献和实验依据后再确定。

## 5. 网络架构边界

3D U-Net 作为当前基础架构，不再作为项目创新点反复论证。后续网络学习应服务于已经冻结的输入、输出和损失定义，重点检查：

1. 三维显存和激活开销；
2. 长距离波传播所需的有效感受野；
3. `Re/Im` 双通道的尺度与相位误差；
4. 阵元位置、法向和有限孔径的条件化方式；
5. 频率匹配分辨率下是否可训练。

---

## 6. 当前优先问题

1. 第一阶段固定频率取值，以及该频率下的最短波长、网格间距和收敛标准；
2. 焦点绝对声压如何由复场计算，阵元相位 / 延迟如何定义和标定；
3. 阵元位置、法向和有限孔径如何同时写入网络输入、仿真源和物理损失；
4. MIDA 输入除声速外是否只增加密度，以及对应的变密度 Helmholtz 方程；
5. 三维 Helmholtz-PML 残差的来源、实现和独立验证；
6. 分层配置点抽样、损失归一化和权重调整；
7. 绝对 `Re/Im` 标签的生成、存储、归一化和评价指标；
8. 按位置 / 法向插值与外推设计训练集、验证集和测试集。

---

## 7. 当前边界

1. 不恢复低分辨率大区域 pmax 作为当前主线；
2. 不为降低计算量而把复声场分辨率降到无法解析固定频率波长；
3. 不把 pmax 或幅值场当成可直接相干叠加的复场；
4. 不把 Helmholtz 残差用于替代焦点绝对声压或延迟的专门计算；
5. 不默认声速、密度、吸收等通道越多越好，额外通道必须有物理和实验依据；
6. 不默认 FEUNet 的二维固定点源设置已经证明三维可变有限阵元任务；
7. 不把相位 / 延迟预测单独带偏成脱离全场预测的主线；
8. 不把 `0.5 mm` 仿真网格点当作独立 delay 通道。

---

## 8. 一句话总结

> 第一阶段在固定 MIDA、频率、阵元尺寸和激励幅值下，以阵元位置和法向为主要变量，按频率决定可接受的三维分辨率，预测整个指定域的绝对单阵元复声场，并以监督数据损失和三维离散 Helmholtz 物理损失联合训练；多阵元阵列场、焦点绝对声压和延迟策略在网络外或后续任务中计算。
