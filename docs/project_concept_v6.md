# 项目构想 v6：方向性点源修订

状态：`superseded_by_v7`

本文件继承 `docs/project_concept_v5.md` 的复声场主线，只修订声源定义。其理想方向性点源定义继续有效；网络输出与绝对尺度协议已由 `docs/project_concept_v7.md` 修订。

## 当前声源定义

- 单阵元按**理想方向性点源**处理，不具有有限孔径、直径或发射表面；
- 输入为 `g=(x,y,z,nx,ny,nz)`；
- 点源位置和法向均为变量，具体变化范围尚未确定；
- 第一阶段仍预测单点源在指定三维域内的绝对复声压 `Re/Im`，并在网络外进行多源相干叠加；
- 论文中的有限孔径、表面点集和三维有限孔径 source mask 不迁移到当前项目。

## 必须继续澄清

方向性点源在标签求解器与 Helmholtz 源项中的数学定义必须一致，并确保法向确实影响标签；该问题不改变已经确认的六维网络条件输入形式。
