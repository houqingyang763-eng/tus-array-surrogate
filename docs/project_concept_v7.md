# 项目构想 v7：相对复声场与绝对尺度分解

状态：`current`

本文件继承 `docs/project_concept_v6.md` 的方向性点源定义，并修订网络输出与绝对声压恢复方式。与旧版本冲突时，以 v7 为准。

## 1. 当前声源与物理标签

- 网络介质输入固定为单通道三维声速场 `c(x,y,z)`；
- 单阵元仍按有位置和法向的理想方向性点源处理；
- 条件输入为 `g=(x,y,z,nx,ny,nz)`，位置与法向均为变量，具体范围未定；
- 不含有限孔径、直径、发射表面或表面点集；
- target focus 不进入单源网络，只用于下游相位 / 延迟、阵列组合和评价；
- 标签求解器仍保存统一幅值、相位参考和 Pa 单位下的绝对复声场 `Re_gt/Im_gt`。

## 2. 主网络与绝对尺度头

对每个训练样本，在 `brain_eval_mask` 内定义：

```text
A_gt = max sqrt(Re_gt^2 + Im_gt^2)
q_Re_gt = Re_gt / A_gt
q_Im_gt = Im_gt / A_gt
```

主 3D U-Net 只预测无量纲相对复声场 `q_Re/q_Im`。A4 绝对尺度头从同一个条件化瓶颈 `Z` 预测该样本的脑内绝对峰值 `A_gt`。

这不是丢弃绝对声压：绝对复场由两个网络输出共同恢复。

## 3. 陌生样本的绝对复场重建

```text
A_hat = P_ref * y_hat
m_hat = max_{brain_eval_mask} sqrt(q_Re_hat^2 + q_Im_hat^2)
s_hat = A_hat / (m_hat + eps_recon)

Re_abs_hat = s_hat * q_Re_hat
Im_abs_hat = s_hat * q_Im_hat
```

其中 `P_ref` 只由训练集计算并写入 checkpoint；推理时不需要真实样本的归一化系数。用同一个正标量同时缩放 `Re/Im`，因此保留主网络预测的相位和相对空间分布。

网络外多阵元相干叠加使用重建后的绝对复场，而不是单独使用 `q` 或 `A_hat`。

## 4. Helmholtz 约束边界

相对复场 `q` 与标签绝对源项不在同一量纲。阶段一训练若使用 Helmholtz 损失，必须先用已知训练标签尺度重建：

```text
p_hat_for_physics = A_gt * (q_Re_hat + i*q_Im_hat)
```

再计算与标签介质、源项、频率和边界一致的物理残差。不得把绝对源项直接作用在无量纲 `q` 上。

## 5. 当前边界

- `A_gt` 当前定义为 `brain_eval_mask` 内的严格复幅值最大值；
- A4 不是可删的附属指标，而是绝对复场重建所必需的尺度分支；
- 主网络与 A4 可共享冻结后的 Encoder/A2 融合特征，但分别学习空间形状和绝对尺度；
- 标签的幅值单位、相位零点、Fourier 符号、源项和脑区标签集合仍须形成统一数据协议；
- 单通道声速只约束网络输入；标签求解器是否使用密度、吸收或其他物理量仍待确定；
- 该分解不改变 v6 的理想方向性点源定义。

依据：用户 2026-07-25 对任务分解与重建关系的明确确认；用户 2026-07-26 确认网络输入为单通道声速场，target focus 仅在网络外下游使用；TUSNet 的“归一化声场 + 独立压力尺度”提供邻近方法证据，但本项目采用三维复场、脑内严格峰值和显式复数重建，不能迁移其二维权重。
