## 2026-07-21：固定频率、预测域与三维网格如何确定

问题：

V0 已固定 `500 kHz`、`144³ mm³`、`0.5 mm` 和 `288³` 网络网格。该决定足以推进第一版网络，但仍需用最终标签求解器做网格收敛验证，确认 0.5 mm 对当前介质、源和指标足够。

需要验证：

1. MIDA 各介质中的最短有效波长是多少，0.5 mm 对应的最小 points per wavelength 是多少？
2. 用哪些更细网格和哪些绝对复场指标完成收敛验证？
3. 未来 MIDA 实际裁剪是否需要对 `144³ mm³` 做小幅扩域？
4. 标签网格、网络输出网格和 Helmholtz 残差网格是否完全一致；若不一致，插值会引入多大相位误差？

当前状态：T2 的 V0 已确认；剩余问题是正式标签前的数值验证，不阻塞 A3/A4。

## 2026-07-26：单通道声速网络输入如何与标签求解器物理量保持一致

问题：

用户已确认第一版网络只输入单通道三维声速场 `c(x,y,z)`。这只冻结网络接口，不代表标签求解器只使用声速。仍需明确标签、Helmholtz 残差和评价所采用的介质方程与物理量，避免网络输入、标签和物理损失之间出现未记录的不一致。

需要验证：

1. 标签求解器实际使用了声速、密度、吸收、剪切性质中的哪些量？
2. 若标签采用变密度、吸收或更复杂物理，三维 Helmholtz 损失应采用哪种一致形式？
3. 固定 MIDA 下，网络是否能仅凭声速场学习标签中由其他固定介质参数造成的效应；该边界怎样在多头颅扩展时重新评估？
4. 吸收或密度存在于标签却不显式进入网络或物理损失时，会造成多大的系统性误差？
5. 数据协议怎样明确区分“网络输入通道”和“标签求解器材料参数”？

依据：用户 2026-07-26 确认网络介质输入固定为单通道声速场。

当前状态：网络接口已确认；标签求解器物理量与一致性处理待确定。

## 2026-07-24：方向性点源如何在标签与 Helmholtz 源项中一致实现

问题：

项目已确定使用位置和法向均可变化的理想方向性点源，不含有限孔径。网络输入已经固定为 `g=(x,y,z,nx,ny,nz)`；仍需确保法向在标签仿真和 Helmholtz 源项中具有同一个数学含义。

需要验证：

1. 标签求解器中“有法向的点源”具体采用哪一种源项或方向性函数？
2. 改变法向时，标签场是否实际发生相应变化，而不是法向只存在于网络输入中？
3. Helmholtz 源项怎样采用同一个位置、法向、幅值和相位参考？
4. 点源允许的位置范围、法向范围以及无效几何如何定义？
5. 训练 / 验证 / 测试如何划分，才能区分位置插值、位置外推和新法向泛化？
6. 实际几何协议中的源—评价点路径分布和最大路径是多少；五层网络的有效感受野是否足够？

当前状态：六维网络条件已确认；`82 mm` 已撤回为未知，源项数学定义、采样范围和真实路径统计待确定。

## 2026-07-21：三维 Helmholtz 损失如何实现和验证

问题：

FEUNet 证明了二维九点离散 Helmholtz 残差可以与监督损失联合训练，但项目需要三维、方向性点源、MIDA 介质和 PML。不能把二维九点公式直接改名为“三维九点法”。

需要验证：

1. 选用哪一种已有来源的 3D 27 点或其他 Helmholtz-PML 离散格式？
2. 该格式是否支持项目最终采用的变密度、吸收和非均匀介质方程？
3. 如何用已知场、独立求解器结果和网格收敛验证残差实现，而不是只看训练 loss 下降？
4. `L_data` 与 `L_Helmholtz` 如何归一化，权重是固定、分阶段调整还是自适应？
5. 源附近奇异性、介质界面不光滑和 PML 区域应如何进入残差计算？

依据候选：

- FEUNet：https://doi.org/10.1121/10.0025391。
- 3D 27 点 Helmholtz-PML：https://doi.org/10.1016/j.jcp.2012.07.048。
- 3D average-derivative optimal scheme：https://doi.org/10.1111/1365-2478.12090。

当前状态：待选型、复现和独立数值验证。

## 2026-07-21：Helmholtz 配置点是否采用分层抽样

问题：

FEUNet 使用全域随机抽点以降低 PDE 损失计算量。项目批准研究分层抽样，但尚未证明它一定优于均匀随机抽样。

需要验证：

1. 是否至少划分普通介质内部、颅骨 / 介质界面、声源附近、焦点附近和 PML / 外边界五类点？
2. 每类抽样比例应由体素占比、局部误差、物理重要性还是文献经验确定？
3. 每个 batch 固定点集还是动态重采样；是否需要对高残差区域自适应加密？
4. 与均匀随机抽样相比，分层抽样是否改善全场相位误差、界面误差和焦点 / 旁瓣指标？
5. 用户接下来阅读的相关论文采用了哪种分层方法，能否直接迁移到三维经颅复场？

当前状态：已批准调研，未批准直接作为最终训练方案。
