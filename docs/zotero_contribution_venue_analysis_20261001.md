# Zotero 论文：贡献质量、发表去向与本项目对标

核查日期：2026-10-01。范围为「第一类_贴近」「解决问题」原有 26 个条目：TUSNet 两条合并、期刊首页排除，共 24 篇独立论文。本报告复用昨天已核对的全文、消融和指标，补查正式发表状态与分区；没有启动训练。

## 先给结论

**你应走“面向声学问题的方法研究”路线。现有 P0＋FiLM＋Fourier＋已有损失的组合，方法新颖性不足，不能作为论文的核心创新。最值得补的是一个针对复场预测失败的明确机制，并用公平对照证明它有效。第一现实对标是 JASA；方法证据提升后再对标 JCP。**

这 24 篇论文给出的具体答案是：

1. **小改动能形成完整论文。**FEUNet 的架构创新弱，但有限差分物理约束确实改善了预测；它是一篇成立的增量方法论文，发表于 JASA。
2. **插件多不代表贡献强。**DeepTFUS 的方法证据弱，最值得肯定的是公开数据集和三维条件任务。FiLM 的整体收益主张不成立，Fourier 收益小；公开检索只核实到预印本，没有正式期刊可供对标。
3. **增量方法＋完整应用验证，已经有中科院一区发表实例。**Jang 和 Zhang 都发表于 EAAI。它们并未重新发明 U-Net，而是完成特定输入、输出、校正或阵列条件下的预测，并提供比较、跨颅骨测试和实物验证。
4. **方法论文的核心是解决失败。**Huang 解决声源信息表达，PINNup 解决高频训练难收敛，Stanziola 解决无 Label 的迭代求解，GreenONet 把 Green 积分结构写进算子；它们都能明确指出“改了哪里，为什么改，带来什么”。
5. **高水平会议也不要求复杂模块。**原始 FiLM、Fourier Features、PCGrad 的操作都很简洁；它们的强贡献来自首次提出或系统解释一个有广泛用途的机制，并用充分实验支持。

下面的“强／中／弱”是本报告对论文内容的评价；发表去向、分区是核查事实。评价回答“论文实际靠什么贡献成立”，不推断编辑的接收动机。

## 1. 怎样分类，怎样判贡献

本轮采用三类：**应用／系统研究、方法研究、理论／机制研究**。允许一篇论文有两种贡献，但给出一个主定位。另把物理基准和临床模拟作为支撑研究单列。

方法研究不要求新定理。设计新输入表示、新损失、新训练方式、新求解过程，都属于方法研究；证明误差、收敛、表达能力或训练病理的机制，才增加理论贡献。“大三维域＋高频复场＋可变源”是研究条件，条件本身不构成网络方法创新。

| 等级 | 方法贡献的判定 | 应用／验证贡献的判定 |
| --- | --- | --- |
| 强 | 提出清晰机制或结构，解决重要失败；有机制分析、直接对照或跨问题验证 | 解决明确工作流程，准确性、速度、泛化和实际验证支撑用途 |
| 中 | 对已有工具作有针对性的修改或组合，收益明确，但方法的普适性或验证范围有限 | 任务完成、主要比较有结果，验证规模或实际闭环仍有限 |
| 弱 | 普通架构／插件组合；关键设计收益小、负向，或贡献缺少直接验证 | 只有演示或局部数值，不能支撑主要应用主张 |

具体使用三种消融结论：**有效、收益弱／有代价、证据不足**。负向结果明确判该项设计在相应指标上失败；没有独立消融则判该项贡献证据不足。不会把整篇论文的其他贡献一并抹掉。

## 6. 你点名的三个例子，明确下结论

### FEUNet：小改动，完整的增量方法论文

**“只加一个损失”对它的创新幅度描述基本正确；“所以文章质量差”不正确。它的方法新颖性是中等，架构新颖性弱，收益证据有效。发表在 JASA，中科院大类三区。**

它围绕的是数据少时纯监督预测难学，而传统 PINN 每换问题需重新优化。作者保留 U-Net，在输出复场上施加与参考求解器一致的离散方程约束，比较同一个网络有无物理项时的测试误差。图 9 的改善明确，不靠网络名称成立。

它的上限也明确：二维理想模型、固定源，缺实物验证，不能支撑大三维变量源下的同等效果。对你最有价值的是论文结构：**明确瓶颈→一个针对性改动→公平对照→在哪些数据条件下有效。**

### DeepTFUS：方法贡献弱，数据贡献强，没有核实到正式发表

**它不是“已经发到一般期刊”的实例。目前能核实的载体是预印本。复杂插件堆叠并没有被消融证明为一个整体更优的设计。**

### Jang：方法创新中等，应用研究强，确实是一区发表样本

**它的发表样本证明：不需要重新发明一个基础网络，也能用扎实的应用贡献发表 EAAI。**

“比较六种网络”只是它证据的一部分。更有价值的是：换能器位置与朝向成为输入；CT 信息有效；场形状与尺度分开预测；补了专门的峰值尺度校正；测试未见颅骨；用水听器做实际测量。它完成了一个可运行的、具有明确用途的三维预测方案。

这里的六种是 AE、atrous AE、pix2pix、CycleGAN、VAE、VQ-VAE；不是六种全新的架构。VAE 被选中本身不是原创基础网络贡献。PPNet 有直接比较，才构成有说服力的具体设计。

**它没有证明完整复波场准确。**输出是局部实值压力场，不是每个体素的 Re/Im。峰压比误差 4.62% 是经颅／自由场峰压比之差，不能换成完整复场相对 L2。

## 8. 最值得走的一条论文路线

**主线：物理结构驱动的三维可变源复场预测方法。**先明确普通网络在相位、高频空间振荡或源位置变化上哪里失败，再提出一个能处理该失败的表示、条件传播或训练机制。

我建议优先研究**波场表示如何降低高频复场的学习难度**，优先级高于再添注意力／FiLM 插件。依据是 Huang 的收益主要来自输入表达，GreenONet 的贡献来自保留物理结构，Fourier Features 则说明表示改变可以得到可解释的方法收益。具体载波／包络变换、散射表示或分解结构仍是待设计候选，这份文献对标不把它们当作已验证有效的方法。

这条路线的论文应建立四份核心证据：

1. **失败证据。**同一测试源位置上，普通 U-Net 和你的现有 P0 模型，在完整有效评价域里的复场形状／相位错误是什么；用空间剖面和误差随位置／传播距离的变化讲清楚。
2. **归因证据。**保持 split、模型选择规则、训练数据和公平资源预算，比较现有 P0 baseline 与单一新设计。更大参数量时增加匹配容量对照；关键比较重复独立训练，报告离散程度。
3. **难度证据。**在当前合同内先测试源位置泛化、训练样本量及实际推理／显存成本。要写跨介质或跨频率方法主张，就必须另有相应数据验证；扩展实验应另行批准。
4. **范围证据。**报告平均表现、失败位置、不同区域的相位误差和代价。只在几个位置成功，不能写成普遍解决三维高频预测。

主指标沿用当前科学目标，先定义逐例归一化场：q=p/‖p‖₂、q̂=p̂/‖p̂‖₂，再比较 **E_shape=‖q̂−q‖₂**。相位采用包裹角误差 **dφ=|atan2(sin(φ̂−φ),cos(φ̂−φ))|**，按现有合同在颅外合法非零评价域等权平均，先逐例再跨源平均；不增加高声压阈值，不做全局相位对齐。绝对压力精度与当前形状目标不同。

这是一条**方法论文路线**；有机制推导和诊断就能有分析深度，不需要把论文改叫“理论创新”。实物实验不作为本轮启动项，也不能从纯数值结果直接写出临床或治疗价值。
