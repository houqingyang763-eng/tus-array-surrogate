# A1：U-Net 深度与宽度

## 当前决定（2026-07-25）

V0 固定采用：

```text
5 次下采样
通道数：8 -> 16 -> 32 -> 64 -> 128 -> 128
声速输入 c(x,y,z)：[B,1,288,288,288]
输出：[B,2,288,288,288]（Re/Im）
空间层级：288 -> 144 -> 72 -> 36 -> 18 -> 9
参数量：3,807,426
```

第五级将通道封顶在 128，不继续增至 256：扩大感受野来自新增下采样层，而不是增加宽度；当前没有误差证据支持额外宽度。

## 感受野审计

计算对象为当前候选块：每级两次 `3×3×3` 卷积、`2×2×2` 池化、`2×2×2` 转置卷积和 skip concat，最后使用 `3×3×3` 输出卷积。感受野只指介质体输入；六维点源条件在瓶颈广播，不受该空间感受野限制。

逐层依赖计算给出：

| 结构 | 每轴理论感受野 | 对应物理长度 | 从输出点向单侧可覆盖 |
|---|---:|---:|---:|
| 旧四次下采样 | `188–204` 体素 | `94–102 mm` | `47–51 mm` |
| 当前五次下采样 | `380–412` 体素 | `190–206 mm` | `95–103 mm` |

转置卷积的输出相位会使精确支持宽度略有变化，因此给出范围。五次下采样的理论范围大于 `288` 体素输入边长，实际由输入边界截断。

判断：

1. 旧四次下采样的理论感受野只能覆盖当前输入的一部分；五次下采样将每轴理论支持扩大到超过 `288` 体素输入边长，同时最低层仍保留 `9³` 空间点。
2. 因此五层继续作为当前 V0，目标是在不把瓶颈压成单点的前提下获得更大的全域上下文；这是一项已确认的工程选择，不是网络最优性的实验结论。
3. 项目真实的源—评价点路径分布和最大路径尚未确定；此前使用的 `82 mm` 不再作为已知边界或五层充分性的证明。
4. 理论感受野不等于训练后的有效感受野；第一轮训练后应通过输入梯度/遮挡探针检查实际利用范围，并结合正式几何范围重新评估五层是否充分。

## 显存复核

当前五层网络已完成 8 个小尺寸整步探针。按 peak reserved 显存拟合并加入 15% 余量：

```text
288³ 规划峰值 = 18.474 GiB
20 GiB 上限内余量 = 1.526 GiB
```

该结果仍是从最大 `10.49 M` 体素向 `23.89 M` 体素外推，不是 24 GB GPU 实测。直接证据见 `t2_memory_probe.py`、`t2_current_memory_analysis.py` 和 T2 决策。

## 依据与边界

- 3D U-Net 支持体数据上的多尺度编码—解码和跳跃连接：[Çiçek et al., 2016](https://doi.org/10.1007/978-3-319-46723-8_49)。
- nnU-Net 支持根据输入 patch、体素间距和显存联合配置网络拓扑，而不是固定照抄深度：[Isensee et al., 2021](https://doi.org/10.1038/s41592-020-01008-z)。
- 理论感受野会高估实际主要贡献区域：[Luo et al., NeurIPS 2016](https://papers.neurips.cc/paper_files/paper/2016/hash/c8067ad1937f728f51288b3eb986afaa-Abstract.html)。
- 本项目决定只适用于当前 `144 mm` 域、`0.5 mm` 网格和 A2b 卷积块；真实路径范围与有效感受野仍待验证，若物理域、网格或几何范围改变，需重算。
