# 第一版网络：待确定问题清单

## A. 网络架构

### A1. U-Net 深度与宽度

从以下四档中选一档，并说明感受野、显存和参数量：

1. 3 次下采样，`16 -> 32 -> 64 -> 128`；
2. 4 次下采样，`8 -> 16 -> 32 -> 64 -> 128`；
3. 4 次下采样，`16 -> 32 -> 64 -> 128 -> 256`；
4. tFUSNet 风格宽网络，约 `64 -> ... -> 512`。

【A1 已确认，2026-07-26 更新】：V0 采用 5 次下采样、`8 -> 16 -> 32 -> 64 -> 128 -> 128`。输入层级为 `288→144→72→36→18→9`；理论感受野约 `190–206 mm`，比旧四层更适合作为当前全域上下文 V0。此前使用的 `82 mm` 最大路径已撤回为未知；后续须结合真实几何范围和有效感受野验证五层充分性。详细依据见 `A1_depth_width.md`。

### A2. 每层采用什么卷积块

【A2a 已确认】：当前项目使用位置和法向均可变化的理想方向性点源，不含孔径、直径、表面点集或有限孔径 source mask。条件信息在瓶颈接入。

从以下四种中选一：

1. 双卷积 + LeakyReLU，不做归一化（FEUNet 风格）；
2. 双卷积 + BatchNorm + LeakyReLU + CBAM（tFUSNet 风格）；
3. 双卷积 + GroupNorm + LeakyReLU；
4. 双卷积 + GroupNorm + LeakyReLU + CBAM。

【A2a 已确认】：方向性点源使用六维条件 `g=(x,y,z,nx,ny,nz)`，经全局归一化、全连接投影、空间广播、通道拼接和 `1×1×1 Conv + GroupNorm + ReLU` 在瓶颈融合。位置和法向的变化范围尚未确定。

【A2 已确认，2026-07-25 更新】：每级两次普通 `3×3×3 Conv`，每次均按 `Conv3d -> GroupNorm -> LeakyReLU(0.01)` 排列；GroupNorm 固定每组 8 个通道。下采样采用 `MaxPool3d(2,2)`；Decoder 按 `ConvTranspose3d(2,2) -> concat -> 双卷积块` 融合。普通卷积及转置卷积均 `bias=false`，使用匹配 LeakyReLU 的 Kaiming normal 初始化。V0 不使用 CBAM、Dropout、残差块或深监督；完整参数见 `A2b_layer_design.md`。

### A3. `Re/Im` 输出头如何组织

从以下三种中选一：

1. 一个共享 U-Net，最后直接输出两个通道；
2. 共享主干，末端分为 `Re`、`Im` 两个小输出头；
3. 两套完全独立的 U-Net。

【A3 已确认，2026-07-25】：选择第 1 档。共享 U-Net 末层采用线性 `Conv3d(8,2,kernel=3,stride=1,padding=1,bias=true)`，输出逐样本归一化的 `q_Re/q_Im`；末层不加归一化或 activation，使用 Xavier normal 权重初始化和零偏置。A4 另行预测绝对尺度并重建绝对 `Re/Im`。完整参数见 `A3_reim_output_head_decision.md`。

## L. 损失函数

### L1. 基础数据损失

从以下四种中选一：

1. `Re/Im MSE`；
2. `Re/Im MAE`；
3. 相对复数 `L2`；
4. `MSE + 相对复数 L2`。

### L2. Helmholtz 物理损失如何取点

先确认三维算子、变密度/常密度形式、源项和 PML/边界与标签求解器一致，再从以下四种中选一：

1. 第一版只用数据损失，作为对照；
2. 对全部有效体素计算；
3. 在有效域内均匀随机抽点；
4. 按源附近、颅骨界面、脑内和边界分层抽点。

### L3. 是否需要第三种结构损失

从以下四种中选一：

1. 不加；
2. 空间梯度损失；
3. 频谱损失；
4. 目标区/界面等区域加权损失。

### L4. 多损失权重如何确定

从以下四种中选一：

1. 先把各损失归一到相近数值，再固定权重；
2. 小范围网格搜索；
3. 先数据损失、后逐渐增加物理损失；
4. 按梯度大小自适应平衡。

每增加一个损失必须回答：它针对哪种已观察错误；是否保留绝对幅值和相位；是否与现有损失重复或冲突；在哪些区域物理上有效；最终改善哪个声场指标。

## T. 训练策略

### T1. 优化器与学习率

从以下三种路线中选一：

1. Adam，初始学习率 `1e-3`；
2. AdamW，明确 weight decay；
3. 用少量 epoch 比较 2--3 个对数间隔学习率，再确定优化器和初始学习率。

### T2. 数值精度、原生 batch 与梯度累积

从以下三种路线中选一：

1. FP32，原生 batch `1/2`；
2. BF16/AMP，使用显存允许的最大原生 batch；
3. BF16/AMP，小原生 batch + 梯度累积得到较大的有效 batch。

必须先确定：物理范围、网格间距、各轴体素数、输入/输出通道、网络基宽和 Helmholtz 实现的额外显存。

【批注】：确定这个之前，还要确定
（1）0.5mm的grid对于500khz到底准不准——去看Finite difference-embedded UNet for solving transcranial ultrasound frequency-domain wavefield这篇论文。它就是用复声场跑的，虽然是相对声场大小，没有出绝对，但是也可以借用。去看它的频率和grid，推算出ppw。如果比我们的还小，那我觉得0.5mm能用。暂时不考虑绝对声压能否测准。不成到时候再改。重要的是先赶紧把一些东西定了，后面才方便计算。
（2）整个脑区到底多大？我觉得可以先不根据mida模型测量，看论文就行。我惊讶于：tfusnet 2026那篇：那篇输入进网络中的区域实际大小只有108 x 108 x 40 mm^3，这很扯淡。厚度只有4厘米，根本就不是半脑，但是最后结果出奇的好？你再去看这两篇：Deep learning-based real-time estimation of transcranial focused ultrasound acoustic field和A Skull-Adaptive Framework for AI-Based 3D Transcranial Focused Ultrasound Simulation，看他们裁剪大脑的区域是多少。我偏向于第一版就先按那个108 x 108 x 40 mm^3的裁剪。毕竟第一版是实验版。可以先降低实用性。

【T2 已确认，2026-07-26 更新】：V0 使用单通道声速输入、`144³ mm³` 物理域、`0.5 mm` 网格和 `288³` 网络体素；输入 `[B,1,288,288,288]`，输出 `[B,2,288,288,288]`，native batch 1，BF16 网络前向、FP32 损失。五层 A1 候选的显存规划值为 `18.474 GiB`；该值来自 8 GB GPU 小尺寸探针外推，并非 24 GB GPU 实测。详细依据见 `T2_grid_memory_batch.md`。

### T3. 学习率日程与停止条件

从以下三种路线中选一：

1. 从头联合训练 + 固定里程碑衰减；
2. 从头联合训练 + validation plateau 降学习率/早停；
3. 先训练数据损失，再逐步增加物理权重，同时使用 cosine 或 plateau 调度。

## 探索顺序

1. `T2`：先判断三维网格在本机是否可训练，以及合理的原生/effective batch；
2. `A1`：已确认 5 次下采样、`8 -> 16 -> 32 -> 64 -> 128 -> 128`；
3. `A2`：先确定阵元几何表示/条件化，再根据小 batch 决定普通卷积块、归一化和是否加注意力；
4. `A3`：已确认最简相对 `Re/Im` 双通道输出头；
5. `L1`：先建立可靠的数据损失 baseline；
6. `L2`：实现并验证三维 Helmholtz；
7. `L4`：再确定数据/物理损失权重；
8. `L3`：只有观察到明确结构性错误才加入第三损失；
9. `T1`：在结构和损失固定后筛学习率；
10. `T3`：最后确定完整训练日程和停止条件。
