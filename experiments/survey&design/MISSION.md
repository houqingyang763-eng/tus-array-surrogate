# 网络架构调研与设计任务书

版本：v1.0；用户采纳日期：2026-10-09。基线事实快照：截至2026-10-08已记录结果。

本文件约定本专题的研究目标、优先级、调研边界与产出。当前阶段为论文调研和网络设计；具体实验另行落实。本任务书不直接改变已有实验配置或启动训练。具体期刊暂不纳入任务。

## 1. 研究目标与论文故事

探索适合**大规模三维、复杂介质、可变点源条件下的振荡复声场预测**的新型神经网络架构，形成一套具有明确机制、实际效果和可复用价值的解决方案。

预期故事线：

> 经颅声场传统仿真计算成本高。已有深度学习代理方法在声源设置、预测范围、输出对象及幅相表达上各有边界。针对大范围三维复声场中复杂干涉纹理难以准确预测的问题，我们提出新的网络计算机制，并通过实验展示其相较现有基线的精度优势与计算可行性。

拟形成两项主要贡献：

- 提供能够预测大范围脑区三维振荡复声场的神经网络，支持颅外点源位置变化。
- 提出针对这一类问题的结构设计与信息处理机制，解释其为何有效，并以L2、局部幅相细节和消融结果支撑贡献。

后续可增加一项应用展示：在恢复点源响应的相对尺度、保持共同相位约定后，通过加权相干叠加构造不同形状的声源。

“已有方法都预测绝对声压、换能器都固定、预测范围都小”暂不写成统一结论。调研应逐篇确认这些边界，再形成准确的研究缺口。

## 2. 任务定义与优先级

### 第一优先级：固定颅骨条件下的准确预测

- 固定当前MIDA介质和500 kHz源设置。
- 输入包含介质信息、可变颅外点源位置，以及方案需要的参考场或其他物理表示。
- 输出三维颅内Re/Im复声场形状，保留相对幅值分布与相位关系。
- 首先解决当前基线的复杂局部纹理和未见源位置预测问题。

### 第二优先级：可变颅骨介质

调研需要重视颅骨及颅内介质信息的提取，以及介质与声源之间的相互作用。可以先在固定介质上验证，但架构应保留通过介质输入适应不同颅骨的途径。

“更好的介质提取有益于固定颅骨预测”作为值得探索的假设，通过结果判断其贡献。

### 第三优先级：绝对声压与点源拼接

后续研究幅值尺度恢复，再验证点源响应叠加。当前架构调研以复场形状精度为首要目标，暂不展开这两项任务。

## 3. 核心困难

- **源位置变化：**需要从有限训练源学习对未见源位置的映射，同时保留不同源之间明显的场差异。
- **复杂介质传播：**折射、反射、衍射与干涉共同形成局部幅相结构，网络需要利用介质和源信息预测这些结构。
- **三维规模大：**当前网络域为352×352×192 @ 0.5 mm，共**23,789,568个体素**；Re/Im两通道输出合计**47,579,136个实数**。其中当前有效颅内评价区域为5,101,889个体素，约510万；网络ROI物理尺寸为176×176×96 mm³。
- **域内振荡多：**重点是整个预测域内存在大量波纹及复杂叠加，必须同时保持局部细节和跨区域的相位关系。
- **样本差异大：**不同源产生的形状和局部纹理差异明显，视觉上呈现复杂、难以直接归纳的空间变化；调研应寻找其中可利用的传播结构。

体素总数由网络尺寸相乘得到；有效颅内体素数来自[基线结果中的裁剪核验](../../docs/evidence/v10_baseline.md#results)。当前ROI不等同于完整脑区，完整仿真域仍为384×480×224。

## 4. 现有基线、性能与瓶颈

采用**V10 T512-V9BASE**作为主要对照。

| 项目 | 基线情况 |
|---|---|
| 主体结构 | 六级3D U-Net，通道为[8,16,32,64,128,128]，五次下采样及跳接 |
| 输入 | 介质体数据、P0的Re/Im、点源XYZ坐标 |
| 条件处理 | 瓶颈坐标融合、粗层FiLM、细层空间Fourier/FiLM |
| 输出与训练 | 两通道Re/Im；纯形状损失，Lgrad与Helmholtz关闭 |
| 数据 | 512 train／32 val／64 test |
| 已有主要结果 | e280：train平均unit-shape L2＝0.348609，val＝0.461938 |
| 图像观察 | 主要能量区和波前已重现；局部幅值纹理、干涉结构及Re细节明显平滑 |

这些是截至2026-10-08已记录的结果；任务书暂不填写未经核实的test数值。[结构协议](../../docs/evidence/v10_baseline.md#protocol)、[基线结果](../../docs/evidence/v10_baseline.md#results)。任务书被采纳不自动改变这些来源文件的科学结论状态。

已尝试方法提供以下研究依据：

- **P0：**历史观察中收益较明显，是继续研究源、参考场与介质如何结合的重要线索；已有比较包含配置差异，具体贡献幅度仍需匹配对照。[历史结果](../../docs/evidence/historical_controls.md#p0)
- **Fourier/FiLM重写：**V10两轮在e180时，V9BASE的val L2为0.470479，新版为0.521369；新版未带来预期提升。该比较同时涉及整套条件结构、初始化、硬件与batch差异。[对比结果](../../docs/evidence/v10_baseline.md#results)
- **GDL、FFL：**部分指标有改善，但复杂纹理缺失仍明显。FFL在共同训练范围内相较GDL的最佳val L2改善约0.16%；历史分频诊断还提示，主要纹理错误涉及主频带内部的幅相组合。[GDL结果](../../docs/evidence/historical_controls.md#gdl)、[FFL结果](../../docs/evidence/historical_controls.md#ffl)
- **Helmholtz损失：**V9历史比较的test平均L2改善约2.18%，收益有限；其监督区域和物理适用条件与V10不同。[历史结果](../../docs/evidence/historical_controls.md#helmholtz)

**本轮研究判断：将主要精力转向架构、表示与传播信息处理机制。**单纯改损失、调权重或常规调参不再作为主要探索路线。

局部平滑是已观察到的问题；其主因可能涉及表示、信息传递、条件映射或泛化，调研和设计需要进一步区分。V9结果提供历史线索，不直接替代V10架构证据。

## 5. 调研边界与工作要求

检索、读论文和自主设计的具体判断统一按本目录[审查模块](REVIEW.md)执行，调用时机见[专题工作规则](AGENTS.md)。

纳入范围：

- 能改变网络计算方式的结构设计，包括空间状态传递、递归记忆、物理迭代、多尺度信息交换、源与介质交互，以及复场表示与解码。
- 经颅超声、地震波、电磁波、光学传播、Helmholtz和其他相关PDE学习工作。
- 具有迁移价值的三维介质编码、几何表示和大规模输出方法。
- 一次前向预测或有限次迭代预测；均需核算完整输出的实际成本。

当前降低优先级：

- 单纯调整训练流程、损失函数或损失权重。
- 单纯扩大U-Net、堆叠常规模块。
- 缺少具体机制依据的串联或重复运行网络。
- 直接替换成标准通用架构，却没有针对本任务困难的设计和收益依据。

这些属于优先级安排。某个已有方法若提供明显收益和清楚的适用机制，可以重新提高优先级。

每篇保留的论文必须回答：

> 它解决什么问题？输入输出是什么？关键计算机制是什么？收益由哪项实验支持？与本任务差在哪里？能够借鉴哪一部分？

每个自主设计必须回答：

> 针对哪个具体错误？采用什么表示和信息传递？介质与源如何参与？为什么可能有效？三维成本多大？哪项最小实验能判断是否值得继续？

检索前查[已有论文与方向索引](../../docs/literature_seen_index.md)。已知论文、已有方向延伸明确标记；入库、精读、已实验和已否定分别记录。用户提供的空间序列、物理迭代和专用传播网络作为方向示例，允许调研形成其他方向。

## 6. 成功标准与计算约束

最终目标是在固定test上相较基线取得**大幅复场L2改善**。例如从0.4降到0.2，代表约50%的相对改善；这只是目标量级，比较起点以实际基线test结果为准。

同时要求：

- 局部幅值和相位细节有对应改善，避免只有平均指标变好。
- 报告逐样本分布及较差样本，检查收益是否具有一致性。
- 用关键结构消融说明收益来自哪些设计。
- 架构筛选和参数选择使用train／val；选定版本后进行固定test评价。
- 各模型采用相同数据、评价mask、归一化和checkpoint选择规则；正式比较尽量匹配训练预算与设置。

资源为**5张V100**。

“网络更新时间不超过4 s”采用以下计时口径：**五卡、global batch＝5时，一次完整参数更新的稳定耗时不超过4 s**，包含前向、反向、通信和优化器更新，不含周期评价。完整三维复场的推理耗时另行报告，迭代架构计入全部迭代步骤。

## 7. 预期产出与方向目录

以“解决机制”为单位组织方向。每个方向包含以下内容：

```text
方向名称/
├─ README.md       方向要解决的问题、当前判断、下一步
├─ papers/         论文清单、来源链接及必要阅读笔记
├─ DESIGN.md       候选网络、数据流、理论依据与三维成本
└─ VALIDATION.md   核心假设、最小验证及取舍标准
```

初期可以从用户给出的三个方向建起：空间状态传递、物理迭代、介质与源交互；后续按调研结果增加、合并或降级。

每轮产出应包括：**值得保留的机制、候选设计、取舍理由，以及下一项最有区分力的验证。**

理论依据中分别标明已有理论、论文证据和本项目假设。当前阶段完成调研与设计，具体实验另行落实。
