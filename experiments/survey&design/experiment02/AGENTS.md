# experiment02：比较调研工作规则

固定入口：本文件 → [MISSION.md](MISSION.md) → [REVIEW.md](REVIEW.md)。默认中文、单 Agent；只沿当前问题的证据链接读取，不预载全仓材料。

## 本轮定位

- 先比较主要传统求解路线，再深入强迭代基底及神经网络接入位置；不预设残差迭代已经胜出。
- 用户已确认工程输出为 B：临时指定多个源共同作用，交付一份总复场形状。同次配置最多几千个源，可选位置数量不限于几千个。
- 介质可更换：希望较快完成一次介质相关预处理，随后复用于不同源配置。不要默认逐颅骨长时间重训已被接受。
- 本轮交付比较分析、观点和文献依据，不要求立即提出原创网络；不沿用 exploration 01 的连续自主设计授权或其候选。

## 检索与证据

- 搜索论文或新方向前，先查[统一文献索引](../../../docs/literature_seen_index.md)的题名、标识和方法家族；命中标明已知内容与本次新增证据。
- 既有核心论文事实优先复用现存卡片；入口缺失时沿索引和旧轮来源定位，不恢复已删除文件。只对缺失信息定向回查原文。
- 重要判断依据原论文、补充材料、作者代码或官方文档，并给章节、图表、公式或代码定位。区分来源事实、用户判断和本轮分析。
- 近几年工作优先；经典强基底及其近年实现保留。发表平台辅助筛选，不代替性能与适用性比较。
- 不把不同分类层级混排；不堆十几个方法名称；少数候选深入比较并给去留理由，不强求唯一冠军。
- 普通 U-Net 及“先预测再修正”不默认保留；仅当找到足够快、准、贴合任务的具体证据时进入候选。

## 操作与保存

- 当前设置阶段只建立任务框架；正式调研按 MISSION 推进，不把框架建立记为调研完成。
- 允许公开文献研究和 Markdown 交付；不访问服务器、不运行实验、不改训练/求解代码、不安装环境、不操作 Zotero。
- 保持当前形状评价；不开展 raw/绝对 Pa 验收，不擅自变更物理设置或裁小求解域，不展开额外物理模型审计。
- 本轮多源总场与介质可更换是用户最新确认的调研目标；不据此修改既有 V10 接口、Label 或已运行实验。
- 修改前查 git status；只暂存本轮明确文件或修改块，完成阶段最小检查后本地 commit。最终报告按用户要求上传现有 GitHub 仓库；不夹带其他改动，不新建分支、Worktree 或 PR。
- 文件职责与完成条件见 MISSION；不预建大量空报告，不把同一证据复制到多个文件。
