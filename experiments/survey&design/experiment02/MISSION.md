# experiment02：复声场求解路线、强基底与神经网络接入位置比较

日期：2026-10-18。状态：本轮文献比较与[综合报告](REPORT.md)已完成；推荐属于文献分析，尚无本任务新增计算实测。以下保留已确认的任务范围与验收要求。

依据：用户本轮原问题、逐条批注与最后的“B”确认。用户最新要求优先于旧轮任务书；本文件记录调研范围，不宣布任何方法已胜出。

## 1. 要回答什么

用户从 U-Net 直接预测转向神经网络加速方程求解较快，希望补齐选择依据。主方向是求解加速；本轮通过比较找到值得深入的传统路线、性能强且适合学习加速的基底，以及网络最有价值的接入位置。

最终要让用户理解：为什么推荐这些方案，其他方案为何未优先，神经网络具体加速什么，以及关键判断来自哪些文献。不要求本轮立即发明或实现原创网络。

## 2. 已确认的工程任务

| 项目 | 本轮要求 |
| --- | --- |
| 介质 | 系统带有可更换介质的模块；换颅骨后，希望较快完成一次介质相关预处理，随后复用。 |
| 源配置 | 在项目允许位置内临时指定；同一次配置最多几千个源，可放位置不止几千个。 |
| 输出 B | 多个源共同作用后的**一份总复场形状**；不要求逐源输出几千份独立场或建立响应库。 |
| 精度与速度 | 很快且形状足够准，或稍慢但误差极小，均可作为有竞争力的方案；不先强设唯一速度或误差阈值。 |
| 学习加速 | 传统基底本身应强，且有值得用神经网络加速的环节；单纯追求纯数值计算极限不构成本轮全部目标。 |
| 路线数量 | 可以保留多个经过比较的候选，不要求唯一最优，不交付未经筛选的十几个类别。 |

沿用项目当前同频、线性传播背景，源配置可记为 `b = Σ_j a_j b(s_j)`，总场满足 `A_m u = b`。`m` 是介质，`s_j` 是位置，`a_j` 表示配置中给定的源权重；不新增源权重优化任务。比较针对一次这样的配置求一份总场，区分构造源项的成本与逐源独立求解的成本。

内部计算保留各源贡献的相对幅度与相位，最后对总场做形状评价；不能先把每个单源场独立归一化再当作正确总场相加。

当前任务背景是完整 `384×480×224 @ 0.5 mm` 计算域及颅内 Re/Im 复场形状，网络临时 ROI 为 `352×352×192`。物理设置按[V10 handoff](../../../docs/project_design_handoff_v10.md)理解；本轮新增工程目标停留在比较研究层面，不修改现有单源 Label、接口、源生成器或实验。

## 3. 三个主要调查问题

### Q1：哪些传统大路线最适合完成上述任务？

先调查能够求出目标复场的主要计算路线，包括用户提到的时域传播、频域求解及其他可能有竞争力的路线；按实际方程、求解过程和信息复用关系整理层级。McMg 是学习加速方法对照，不与时域/频域并列为一个传统大分类。

分别判断：传统方法本身的适用性与性能，以及作为神经网络加速基底的研究价值。重点考虑大三维域、振荡与相位、复杂介质传播、可更换介质、任意临时多源配置和总场输出。先广覆盖筛选，再深入少数强候选。

### Q2：如果选择迭代求解，哪些完整基底组合值得优先理解和采用？

比较完整方案中各部件的作用，而非仅排列名称。找近期可靠实现与适用证据，保留必要的经典方法。回答：本身是否强、主要计算困难是什么、哪些工作能按介质预处理、哪些必须每个新源配置重做、何处适合学习加速。

迭代路线按用户关注的目标研究：更快把真实方程残差降至足够低。记录原文采用的停止条件、完整耗时及场精度证据；不另外扩展为独立的残差与场误差审计专题。

### Q3：神经网络具体接在哪里最值得？

按“传统方法的具体瓶颈 → 可利用的规律 → 网络参与的计算步骤”比较。每个优先位置说清输入输出、替代/改善哪一步、训练与推理分别做什么、为何可能节省总时间，以及已有证据和迁移条件。

不止罗列网络名称；不预设“少迭代”是唯一收益，也不把已有方法的直接迁移当作本项目原创贡献。McMg 是强参考，不为新方案虚构它的弱点。

## 4. 必须纳入比较的成本与能力

- **介质更换**：哪些预处理、缓存或学习参数需要更新，更新多快；有无逐介质训练及其数据成本。通用离线训练和每介质预处理分开。
- **一次总场求解**：从给定多源配置到输出总复场形状的完整耗时，包括源项处理、全部迭代、网络、数据移动和后处理。
- **多次配置复用**：同一介质下，多次临时改变位置或给定权重时可以复用什么；不混成逐源响应库任务。
- **三维可行性**：计算域、内存/显存、硬件、精度和停止条件是否支持论文中的速度结论；论文数字与项目实测分开。
- **速度与精度取舍**：同时允许快速近似与稍慢高精度，不比较只有网络前向的时间与另一方法的完整求解时间。

用户对普通 U-Net 的当前判断是缺少针对振荡波场的物理结构，且约一秒的直接推理缺乏吸引力；这些是本轮选题动机，不写成已完成的全面方法比较。只有发现具体且确实快、准的直接预测或混合方案时才深入保留。

物理模型沿现有要求使用；文献差异只在会改变适用性或性能比较时简要说明，不主动开展吸收、边界等设置审计。
