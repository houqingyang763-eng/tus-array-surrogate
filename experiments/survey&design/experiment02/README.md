## 本轮问题

1. 哪些主要传统求解路线最适合大三维经颅复场，并值得用神经网络加速？
2. 其中哪些完整迭代基底本身足够强、最贴合任务？
3. 网络接入哪些具体计算步骤最有价值，已有证据与取舍是什么？

工程目标：介质可更换；一次介质相关预处理后，快速处理临时多源配置。每次最多几千个源，输出它们共同作用后的**一份总复场形状**，不是逐源场库；候选位置不限定为几千个。

本轮先比较和补齐选择依据，不预设残差迭代胜出，不要求立即原创网络；未运行实验。交付中文 Markdown 报告、关键文献与明确推荐，提交并上传现有 GitHub 仓库。
