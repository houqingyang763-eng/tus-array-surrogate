# exploration 01：以方法创新为目标的学习迭代求解探索

版本：v1.0；用户批准：2026-10-16。权威顺序：用户最新指令 → 本任务书 → [REVIEW](REVIEW.md)。[上一轮](../exploration00/README.md)是历史研究，不自动定义本轮目标。

## 1. 目标与创新尺度

核心目的是发论文。本轮寻找并自主设计：**在真实 Helmholtz 类物理残差迭代中，以神经网络/神经算子加速大规模三维经颅复声场求解的计算机制。**

创新定义：针对重要的具体困难，提出最接近的已有方法尚未提供的计算机制，并通过分析和实验说明其价值。逻辑链固定为：

> 核心问题 → 原因假设 → 针对性计算机制 → 相对最近先例的新增贡献 → 可区分的验证。

“完全创新”指核心贡献可清楚归属于本项目，不要求重造所有基础工具。目标深度参照 McMg 这类问题驱动的方法设计；无需发明 PINN 那样的基础范式。新颖性由实质差异判断，贡献强度由问题价值、机制依据和实际收益判断，不按模块数量判断。

| 做法 | 本轮定位 |
| --- | --- |
| 原样迁移 McMg，仅更换颅骨数据或补齐物理输入 | 基线/必要工程，典型创新反例 |
| 直接用标准 PINN、FNO、U-Net 等替换校正器 | 基线，不作为我们的创新候选 |
| 借鉴经典思想，针对具体困难重新设计表示、算子及与数值迭代的配合 | 本轮目标；必须继续做机制查重和贡献论证 |
| 单纯换成3D、换数据集、加宽、调损失或训练策略 | 不作为主要方法贡献 |
| 发明全新的基础神经网络范式 | 无此要求 |

## 2. 任务对象与边界

- 当前优先固定 MIDA、500 kHz、头皮附近颅外各向同性单网格点源；保持当前源定义、水耦合及物理设置。
- 内部求解完整 `384×480×224 @ 0.5 mm` 系统；完成后按当前合同裁 `352×352×192` ROI，交付颅内 Re/Im 复场形状。ROI不成为物理求解边界。
- 主评价为现有 unit-shape L2；禁用 raw 场评价、绝对 Pa 验收及其模型选择用途。方程相对残差是数值收敛诊断，与形状误差分别报告。
- 研究时允许分析不同介质适用性；不自动增加多颅骨数据、阵列拼接、源叠加实验或绝对声压目标。
- 本轮为文献研究、分析和设计：不改训练/求解代码、不启动实验、不访问服务器、不改变环境。

稳定物理边界见[V10 handoff](../../../docs/project_design_handoff_v10.md)。其中历史运行状态不作为当前进程证据。

## 3. 计算主线

以 `A_m u = b_s` 表示由介质m及源s确定的线性频域系统。外层真实残差为 `r = b_s − A_m u`；学习模块参与残差到校正、预条件、传播或更新的计算，再由真实A检查更新后的残差。

不能把网络隐空间中的差值自动称为真实物理残差；不能把“训练损失包含PDE”自动归为推理中的物理迭代。U-Net等名称不是排除标准，直接预测与迭代校正按实际计算作用区分。

内部状态、源项和残差保持一致的尺度与相位约定，最终再做形状归一化。不得用逐步归一化替代原系统的求解。正确实现密度、吸收和边界属于必要基础，单独补齐这些项不构成方法创新。

## 4. McMg与其他基线

McMg是**强方法对照、设计思想来源和创新深度参照**。它把多通道粗空间、介质相关算子及准备/迭代分离联系起来，本轮不反复降低其研究价值。

- 用户判断：McMg具备约10 s量级求出多个点源叠加复场的强能力预期，支持继续走物理迭代学习加速路线。
- 论文事实：P27 v2表2的224³地质模型，在论文条件下，McMg/CBS分别0.608/4.128 s达到相对残差1e−6。[原文](https://arxiv.org/html/2606.30495v2)。此表与上述用户能力预期分别记录，约10 s不是原文表2数字或本项目计时。
- 线性系统可以把已知源的线性组合写成一个组合右端项，一次求其总场；这与分别计算每个点源响应库是不同成本问题。这里只用于解释能力，不扩大当前单点源项目目标。

传统 Born/CBS及适用的经典预条件方法是数值基线；McMg与最近的学习求解器是方法对照。旧 T512-V9BASE及[上一轮任务书](../exploration00/MISSION.md)保留作历史背景，不再是唯一创新对照。不因直接代理预测不佳就推断其全部架构无用。

## 5. 检索与自主设计要求

同时走两条路线：①相关困难的解决机制；②经典、权威、通用架构中的设计思想。发表平台帮助定位代表作，不代替机制判断。二维、小网格或其他领域差异须分析，不直接排除。

先查[统一索引](../../../docs/literature_seen_index.md)，再检索和读原文。已知论文、已有方向延伸、本次新增证据分别标记。查重范围覆盖相关领域；“此前未用于经颅”不能掩盖核心机制已存在。

每条候选必须回答：核心问题是什么；已有方法如何处理；新增的具体计算是什么；为什么可能有效；三维成本多少；哪项对照/消融能区分其贡献。未核实的问题原因标为假设，不为了创新虚构McMg失效。

## 6. 成功标准、成本与停止条件

本轮完成标准：形成少量经过精准判断的候选机制、跨领域机制查重、可检查的数据流/算子、三维成本及最小验证。**首轮最多三个，不凑数。**零条通过时明确停止理由及剩余问题。

最终方法需同时满足形状精度与有意义的求解收益；贡献可体现在完整耗时、显存、稳健性或其他明确能力，不要求所有指标都胜过McMg。报告全部迭代、真实A作用、检查、数据移动及后处理；准备/编译、离线训练与固定介质重复源摊销单列。

旧“5张V100、global batch5、完整更新≤4 s”仅是上一轮直接代理训练约束，不自动套为本轮求解器推理门槛。本轮不新增硬性时间阈值，不分配GPU或实验预算。

覆盖主要检索路径和关键引文链后，连续两轮定向扩展均未出现会改变候选或取舍的新机制/先例，即收束首轮。关键原文缺失具体记录；不以无限检索替代判断。
