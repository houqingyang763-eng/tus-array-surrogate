来源事实统一存于[公共论文笔记](../../papers/README.md)，本页只指出借鉴关系：

- P66：Schur/近似块LU/界面传播的共同经典基础。
- P62：学习界面条件的最近神经方法；其学习对象为局部Robin附加矩阵，不是本候选的双面耦合校正分工。
- P67：非局部DtN可通过稀疏辅助状态表达；可分离单外域的拟合不等于复杂骨层的双面网络。
- P61/P27：介质准备与残差作用分离、固定介质重复迭代。
- P65：图层次和双向传递已存在，不作为新增贡献。
- P71：双端口与散射组合是已有材料，不能单独承担创新。
- P72/W02：神经Schur消元/细节映射已存在，必须按实际消去的未知量及网络任务比较。
