# 首轮来源与机制事实

日期：2026-10-16。P编号沿用[统一索引](../../../../docs/literature_seen_index.md)。下列新增仅指此前索引未登记，均属于已有学习求解/算子方向的延伸，不宣称全项目首次发现。来源事实与本项目构想分开；本页为唯一公共文献笔记，各候选只链接引用。

## 优先读取的经典设计思想

| **P62 MLORAS，NeurIPS2022**：[正文](https://papers.nips.cc/paper_files/paper/2022/file/2f8928efe957139e9c0efc98f173f4be-Paper-Conference.pdf) | §2式1为`η−Δ`、η>0的正定问题；§3学习Robin附加矩阵L_i，采用误差传播幂作用的目标；§4有非结构二维网格和FGMRES。 | 学习界面条件已有强先例；该文的“Helmholtz”不能误读成高频不定声学系统。 |

| **P67 Learned infinite elements，2020预印本/2021 SISC**：[v2正文](https://arxiv.org/html/2010.15479v2) | §2式2.1及§3–4：用少量辅助自由度的稀疏系统Schur补近似可分离外域的DtN，预处理时做拟合；§6测试。这里的learned不是预训练神经网络。 | 非局部界面作用可由稀疏辅助状态表示；“学习DtN/Schur”并非空白。 |

## 决定取舍的近邻

| 编号与来源 | 原文事实与定位 | 对本轮的影响 |
| --- | --- | --- |
| **P63 NGO粗校正比较，2026**：[v1](https://arxiv.org/html/2605.19867v1) | §2–3比较采样/积分及源线性两条设计轴；§4.3分别指出学习粗逆退化与固定基容量上限；§4.5明确二维范围。 | 同基积分、源线性和粗空间容量都须考虑；并非只要换成DeepONet就能校正高频场。 |
| **P64 NeuraLSP，2026**：[v1](https://arxiv.org/html/2601.20174v1) | §3.3–4：学习**近零空间样本矩阵S**的主左奇异子空间，用于低秩延拓；§5为扩散、各向异性和screened-Poisson/PCG验证。不是直接学习A的最小奇异向量。 | 学近零子空间已有先例；其PCG理论条件不能直接搬给复数不定系统。 |
| **P65 GMP，2026**：[v1](https://arxiv.org/html/2607.28456v1) | §3：AMG层次上用双部图cross-attention，限制与插值分别参数化；§4/结论含867个非SPD矩阵和约4倍单次应用开销的局限。 | “双空间/双向权重”已有先例，跨层收益须抵得过每步开销。 |
| **P68 HINTS散射扩展，2024**：[v1](https://arxiv.org/html/2405.12380v1) | §3分开体强迫与入射边界的DeepONet并结合传统迭代；§4有2D/3D障碍散射，包含非散射训练向散射几何部署。 | P43家族延伸；界面/边界网络与物理迭代结合已有先例。 |
| **P69 Hybrid scattering，2026**：[v1](https://arxiv.org/html/2602.11197v1) | §3–5：FNO背景映射后接ViT散射校正；实验固定近自由边界Gaussian源。其“residual”是场分解，不是外层反复检查的原系统残差。 | “背景传播＋强散射网络”不能直接作为新机制。 |
| **P70 学习算子增强PCG，2025**：[v1](https://arxiv.org/html/2508.00101v1) | §2起的对象为SPD系统；§3用算子学习得到的基函数构造deflation空间，含稀疏化策略。 | 学基后做投影/消去已有明确方法，不能仅换成Helmholtz就归为原创。 |
| **P71 光子散射矩阵设计，2026**：[出版社正文](https://onlinelibrary.wiley.com/doi/full/10.1002/nap2.70302) | §2.1：复数无增益矩阵、互易性、双向散射块及Redheffer组合已有明确表述；对象为光学分类器逆设计。 | 双端口/反射透射块/被动性本身不新，且该文不是数值求解预条件器。 |
| **P72 ELM-DD，2024预印本/2025正式版**：[v1](https://arxiv.org/html/2406.15959v1) | §2–3：固定隐藏层基的局部ELM，消去输出层参数形成界面Schur系统；数值段含椭圆问题。 | “神经网络＋Schur消元”已有先例，但它在求局部网络系数，计算角色不同于固定权重残差预条件。 |
| **P73 de Rham兼容DNN-FEM，2023**：[出版社摘要](https://www.sciencedirect.com/science/article/pii/S0893608023003088)，DOI10.1016/j.neunet.2023.06.008 | 仅核摘要：精确神经表示最低阶离散de Rham空间，包含RT及Nédélec元。未读正文/数值。 | 结构相容网络属于已有思想；不据此作声学加速性能判断。 |

**W02 NSO作者仓库线索**：[README](https://github.com/ansschh/NSO)。截至本次读取，作者README把对象描述为SPD有限体积粗到细迁移，学习`ker R`中的细节并保持粗预测。未核实独立论文与正式发表信息，不算已读论文或性能实证；但足以要求放弃笼统的“神经Schur就是新颖”表述。
