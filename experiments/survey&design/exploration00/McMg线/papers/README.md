## P27 McMg：已知论文，值得精读核心方法

Jia、Liu、Wang、Xu，arXiv:2606.30495；v1为2026-06-29，用户指定v2为2026-07-02。[版本页](https://arxiv.org/abs/2606.30495v2)、[v2正文](https://arxiv.org/html/2606.30495v2)。预印本；本轮读取正文与相关附录，未复现。

**来源事实摘要：**原方程为声速变化的标量Helmholtz。网络接收残差并输出校正；介质生成的系数在求解时缓存，多通道V-cycle对残差线性。训练用随机残差及方程损失，不要求预计算解标签。v2表2的三维224³算例在A6000上，CBS/McMg平均用时4.128/0.608 s，容差10⁻⁶；训练/推理约45/6 GB。附录A.1表5中FDM+sponge优于FDM+PML，GMRES+McMg在表2中步数更少却更慢。以上均为原论文任务。

### 结构地图与建议顺序

1. **§2.1、式1–5：**先看实际物理方程及离散系统，辨认当前经颅任务还需要哪些项。
2. **§3.1–3.2、算法1/2：**看介质准备与残差校正的两条数据流，多通道限制/延拓如何组织。
3. **§3.3、式15–17：**看迭代和随机残差训练；先理解“学解”与“学逆作用”的差别。
4. **§3.4、§4.4：**看粗空间与谱诊断，检视相空间解释的证据。
5. **§4.1、表2；附录A.1–A.3：**核对三维成本、边界、离散方式和基线。不要只读加速倍数。
6. **§4.2–4.3、附录A.4–A.7：**再读跨尺度、LLPF和消融，区分哪些结果仍是二维。

### 最重要的审计问题

- **精度含义：**小残差衡量对该离散方程的满足程度，尚需另测当前k-Wave形状误差；预条件器无法消除细网格算子本身的物理/离散偏差。
- **迁移物理：**骨界面变密度、组织吸收和当前PML会改变算子；需先建立参考系统，再评估迁移收敛。
- **收敛边界：**随机残差上的平均损失不等于最坏模式收缩；原文数值表现不替代当前任务的失败率和残差历史。
- **成本口径：**准备、编译、数据移动及重复源摊销需在复现中明确；3D原训练显存也不等于五卡DDP可直接容纳。
- **贡献拆分：**多通道谱/基诊断有解释价值，仍应为本次界面改造做等成本结构消融。正文/abs未给出可确认的作者实现地址，本轮定向检索未定位，不能把同名仓库当实现。

需要学习的理论依次为：线性系统残差 → 预条件与迭代 → 多重网格限制/延拓 → 波的振荡误差 → Born背景算子。遇到具体公式再逐项解释，不要求先掌握整个数值分析体系。

## 泛化证据补查

用户问题：是否支持变化颅骨和点源位置？本轮仍为调研，未测试。

- **P27 McMg：**[v2 §3.3](https://arxiv.org/html/2606.30495v2#S3.SS3)使用重新采样的随机残差训练；[§4.1–4.3](https://arxiv.org/html/2606.30495v2#S4.SS1)包含介质样本变化和二维小块到大域/尺度迁移。三维Kimberlina按不同年份介质划分，属于地质模型。点源被用于§4.3的Green响应分析，未给出当前项目式颅外源holdout与跨患者三维颅骨测试。
- **P26 Xiang：**[v1 §4.2.1–4.2.2、表8](https://arxiv.org/html/2607.16906v1#S4.SS2)核查：理想颅骨测试介质不同于训练样本，真实应用包含四个512²成人CT切片案例，训练网格64²；不同训练数据方案出现明显收敛差异。它提供二维训练外颅骨先例，缺少三维变密度/吸收物理验证。
- **P45变密度Born：**已沿源码确认三维源与介质输入，详见[三项能力及证据边界](born_density_2025.md#判断保留为核心频域基线值得精读)。无网络训练；新输入需要重新求解，原文经颅示例不替代多颅骨/多源位置统计。

区别：经典方法的适用性要检查数值收敛和物理精度；学习方法还要检查新介质/新源下是否保持加速。各自准确满足离散系统后，与k-Wave的形状差异仍由物理、离散、边界、源约定和稳态时窗共同决定。
