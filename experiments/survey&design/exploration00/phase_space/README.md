# 相位与多分量表示

- **判断：继续，作为主候选的信息保留机制；单载波全域解调降级。**
- **依据：**500 kHz、水中声速1480 m/s时波长2.96 mm。粗采样会混叠，多股方向/相位不同的波还会互相抵消。McMg提供多通道粗层思路，Wave-ADR展示相位与幅度分工；项目R002单载波试验仅1.82%改善，尚处于欠拟合状态。
- **缺口：**基线丢细节究竟发生在压缩、跨尺度传输还是源泛化；多通道粗表示在实际颅骨场中的压缩误差。
- **下一步：**先做相同容量的表示往返与源轴诊断，再把保留子网格信息的限制/延拓接入[介质条件骨架](../medium_source/DESIGN.md)。

入口：[论文](papers/README.md)｜[设计](DESIGN.md)｜[验证](VALIDATION.md)。本方向为已有相位/幅度与多尺度方向延伸，新增的是多分量保留、三维成本和可分辨验证。
