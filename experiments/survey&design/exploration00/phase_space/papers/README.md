# 保留相位与方向的表示：论文判断

索引ID统一来自[项目索引](../../../../../docs/literature_seen_index.md)。本轮日期2026-10-09。论文实证、本项目假设分开；候选运算写在方向DESIGN。

## P27 McMg — 已知论文，补正文证据

- **判断：继续。**借鉴多通道粗层和介质/场分离，不直接复制预条件器。
- **依据：**[v1 §3、式6–7、§4.1、表2](https://arxiv.org/html/2606.30495v1)：介质非线性生成空间权重，固定介质时残差→校正保持线性；多个粗层通道承载波信息。三维`224³`，20通道，训练batch3约45 GB、推理约6 GB；A6000上CBS/McMg平均求解时间`4.128/0.608 s`，相同残差容差。表述“相空间”是机制解释，不能视为每个通道已被验证为独立方向。
- **缺口：**求解残差容差与V10形状L2不同；其模型未验证k-Wave含密度/吸收Label，原三维训练内存不适合直接套用。正文缺少把“多通道保相位”单独拆出的V10式直接预测证据。
- **下一步：**提取粗层多通道运算与setup思想，设计直接预测版本；先测压缩重建，再做等成本对照。

## P34 Wave-ADR-NS — 索引外，多重网格方向延伸

- **判断：继续。**重点读相位搬移后的复杂幅值校正。
- **依据：**[v1 §3/4、表2、§5](https://arxiv.org/html/2404.02493v1)：二维点源复场残差分成远离/接近波数的误差；前者局部平滑，后者变成粗层ADR问题。`N=1024, ω=160π`，Wave-ADR求解`54`步、`34.98 s`，CSL `2242`步、`463.55 s`。§4.2的多次ADR修正到4次后收益趋缓；并非已推断四条独立射线。
- **缺口：**走时只代表有限传播结构；作者指出单走时及插值仍限制高频扩展。它是二维求解器，不能据34.98 s外推V10更新时间。
- **下一步：**借鉴“搬移后传递系数、调回后评价”，保留多方向和细残差；不采用单走时覆盖所有反射的假设。

## P37 WIRE — 已有方向，重访局部振荡基函数

- **判断：降级为解码组件。**
- **依据：**[CVPR2023 §3、式2–3](https://openaccess.thecvf.com/content/CVPR2023/papers/Saragadam_WIRE_Wavelet_Implicit_Neural_Representations_CVPR_2023_paper.pdf)：坐标→复Gabor激活MLP→信号。复指数承担振荡、Gaussian窗承担局部性；实证主要为图像拟合/逆成像/NeRF。原实值任务最终取实部，不能照搬为复压力输出。
- **缺口：**没有跨源三维经颅复场证据；逐体素深MLP的完整输出成本很高。
- **下一步：**只考虑浅局部波包或小解码头，对比同成本Re/Im头；不以单场拟合代表条件映射成功。

## P38 Multiplicative Filter Networks — 索引外，通用计算机制

- **判断：继续提取乘性展开；降级完整MLP骨架。**
- **依据：**[ICLR2021正文§3](https://openreview.net/pdf?id=OmtmcPkkhT)、[作者代码](https://github.com/boschresearch/multiplicative-filter-networks)：每层将线性变换后的状态与坐标Fourier/Gabor滤波器相乘，形成可分析的频率组合；不是只在输入拼接一次位置编码。原文实证以函数/图像/视频和PDE表示为主。
- **缺口：**没有本任务源泛化及三维体输出对照；高频乘积可以增加表示能力，也可能增加源记忆。
- **下一步：**让滤波器依赖局部空间相位，源条件通过传播状态进入；单独检查源方向变化和全域吞吐。

## P39 PhaseDNN — 已知先例，避免重复宣称创新

- **判断：继续作理论背景。**
- **依据：**[原论文](https://arxiv.org/abs/1909.11759)：将高频分量相移到较低频后学习；项目已有[相位设计](../../../../../docs/literature/known_direction_notes.md#phase)。V10 [R002](../../../../../docs/evidence/v10_representation.md#r002)仅目标旋转得到1.82%探索收益，临时网络拟合不足。
- **缺口：**源几何载波能否同时降低`x`和`g`两方向的复杂度；多径下单载波并非完整表示。
- **下一步：**先做源变化与多通道压缩诊断；新增价值应落在传播通道、跨层信息保留和未见源收益。
