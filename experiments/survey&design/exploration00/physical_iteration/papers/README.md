# 有限传播更新与数值残差校正：论文判断

## P28 LBS — 已有Born方向，补运算证据

- **判断：继续提取分离的介质/传播计算；完整网络降级。**
- **依据：**[原论文pp.2–4](https://arxiv.org/pdf/2212.04948)、[作者代码](https://github.com/ucl-bug/lbs)：二维`128²`、2000个MNIST速度介质、随机点源→复压力。将CBS的传播、局部散射和更新学成有限层，图1比较同迭代数误差及等误差所需迭代，LBS优于CBS。核查的是有限层计算机制，没有从图线虚构固定百分比。
- **缺口：**数据几何简化；learned非线性更新没有继承CBS严格收敛性；3D FFT和总展开成本。
- **下一步：**参考场+介质×状态作为显式数据流，只保留少量共享更新；和单次等计算骨架比较。

## P29 NBSO — 索引外，已有背景/Born方向延伸

- **判断：继续交互机制；背景乘性表示单项降级。**
- **依据：**[v1 §4、表1/5](https://arxiv.org/html/2312.15575v1)：二维介质+源→复场，更新含介质latent与场latent乘积及傅里叶传播，输出`(1+a)u0`。表1脑单源NBSO-star/普通`19.7/19.2`（表列RRMSE值，相对改善2.54%）；多源NBSO/FNO `19.0/19.6`（3.06%），多源U-Net `23.1`。不要混用单源FNO `20.8`与多源NBSO `19.0`计算增益。多源模型144M参数、表列内存35.5G。
- **缺口：**形状合同与场RRMSE不同；幅值乘性目标与单位模解调不同，背景小值易使系数困难；没有本项目大幅收益证据。
- **下一步：**借鉴乘性介质交互，目标保持Re/Im形状；不将2.54%表示收益升级为主路线优势。

## P30 NSNO — 已有迭代方向重访，索引补录

- **判断：继续。**
- **依据：**[v1 §4/5、表1/3/4](https://arxiv.org/html/2401.13494v1)：二维`256²`，介质扰动q与源f→复解；Neumann式`G(q·状态)`反复生成贡献。`k=20`随机圆/GRF源，UNO/NS-UNO L2 `11.27/1.54`（×10⁻²）。但主训练含物理损失；NS-UNO同数据关物理项后测试`8.85`，不能把全部收益归因骨架。3项到4项收益趋缓，学到的块不是精确级数的一项。
- **缺口：**波数/对比范围、物理项与架构贡献纠缠；表2“Iters/sec”与正文成本解释方向不一致，暂不引用为速度证据。
- **下一步：**在V10纯形状损失下测试少量传播状态更新；不照搬q或物理残差定义。

## P09 Helmnet / P26 Xiang — 已知论文，区分迭代总成本

- **判断：P09降级完整求解器；P26继续残差分布思想。**
- **依据：**[P09已有原文核查A9](../../../../../docs/zotero_cross_paper_comparison_20260930.md)：当前复场/残差/状态→场增量；真实CT例约3000次。P26 [v1 §4.2.2表8](https://arxiv.org/html/2607.16906v1)：`64²`训练的预条件器用于`512²` CT/490 kHz弧源；CNN-FGMRES D0四例在10⁻³容差`191/159/166/162`步，总CPU耗时737.70 s；D5虽小训练validation loss最好，却有一个CT例到5120步未收敛。
- **缺口：**残差小与形状准确不是同一指标；P26重点改善残差数据分布，当前快筛不需要数百次迭代。两者算子与Label匹配还未建立。
- **下一步：**只保留“纠错输入应覆盖真实误差分布”；真实物理校正先过算子与边界门。

## P43 HINTS — 索引外，定向补正文后保留混合思想

- **判断：继续互补校正思想，完整求解流程降级。**
- **依据：**[正文§2.3–2.5、附录S1.4/S1.6](https://arxiv.org/html/2208.13273)：介质k与当前残差→DeepONet修正，和Jacobi/GS交替。1D Helmholtz一次网络配14次Jacobi约300步收敛，单Jacobi或仅网络初始化后Jacobi发散；2D 64² HINTS-MG约3个V-cycle，普通MG发散。3D有16³及环柱FEM大系统，74,712/570,960/4,462,368自由度，用HINTS-MG预条件FGMRES。作者明确小系统(<0.5百万)较贵，大系统才体现优势。
- **缺口：**这些低波数/GRF源、Dirichlet等算例未覆盖当前点源、多波长颅骨复场；正文低频模态互补与高频Helmholtz近特征壳需具体算子分析。附录网络训练尺寸出现12³/14³/31³不同描述，暂不作精确训练规模主张。未从图估造速度倍数。
- **下一步：**若I1过物理门，再用“轻局部校正与少量重网络交替”比较全重网络；当前优先有限学习更新。

## P44 OpenWaves / S²NO — 索引外，强散射骨组织；核查v4

- **判断：继续，有用的负向消融也要继承。**
- **依据：**[2026-08-06 v4 §II-B、补充S9/S12、§IV-B](https://arxiv.org/html/2508.12226v4)：源背景场、介质、CBS式预条件latent→二维Re/Im；500 kHz S9中S²NO/BFNO val RRMSE `0.083/0.112`，共享参数后`0.111`，7层减5层`0.121`。表S12为367M参数；主网络是2D，3D应用由轴向切片堆叠，完整3D对照用CBS。
- **缺口：**含骨的高对比证据相关，但当前前向省略衰减与面外传播；表中共享层恶化，与P33的正向共享结果条件不同。不能按标题归为3D neural solver。
- **下一步：**把学习预条件/介质×状态作为候选；共享和独立层保持替代臂，不预设共享更好。严控3D频域参数量。
