# 源到场的结构：先诊断，再决定是否走生成器

- **判断：定向补源轴与局部秩证据；密集全场低秩基底、全域深查询降级/停止。**
- **依据：**固定介质可利用源响应结构，Green/FIO/butterfly提供相关思想；但固定介质不保证少量全局基底可覆盖全部振荡场，完整重建费用也不能忽略。
- **缺口：**当前源分布下的可预测系数维度、未见源插值难度、分块互补低秩结构。
- **下一步：**先用train基底和val oracle投影/可用条件预测分开测，定位压缩与源映射；不立刻建巨型参数基底。
