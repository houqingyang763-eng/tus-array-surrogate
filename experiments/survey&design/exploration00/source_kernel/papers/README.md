# 固定介质的核分解与传播几何：论文判断

## P12 GreenONet — 已知论文，核结构的背景依据

- **判断：继续思想，降级直接骨架。**
- **依据：**[项目已有索引P12](../../../../../docs/literature_seen_index.md)、[原论文](https://arxiv.org/abs/2307.13902)：学习查询点/初值采样点间Green核，再线性积分初始位移；一/二维实位移任务。说明核学习是一条成熟方向。
- **缺口：**三维颅骨复压力核不是初始位移核；形状归一化后对源振幅的线性结构改变。
- **下一步：**用训练源空间响应建立压缩诊断，不把线性叠加或互易当本轮贡献。

## P41 FIONet — 索引外，重要通用传播思想

- **判断：继续提取方向波包与位置路由。**
- **依据：**[NeurIPS2020正文§2/3](https://proceedings.neurips.cc/paper/2020/file/5e98d23afe19a774d1b2dcbefd5103eb-Paper.pdf)、[作者仓库](https://github.com/kkothari93/fionet)：波成像逆问题，方向滤波把信号分到相空间，再学习介质造成的空间几何路由。用几何变换承担传播路径，有不同分布图像测试；并非直接从点源预测复压力。
- **缺口：**局部几何传播模型遇反射、焦散、多路径需要分支；全场输出的训练/解码成本与原逆成像不同。
- **下一步：**在有限局部方向通道间学习介质依赖路由；优先离散邻域传递，延后全域可微射线追踪。

## P42 Butterfly-Net2 — 已有压缩方向，补论文入口

- **判断：降级为核压缩工具；复杂度思想继续。**
- **依据：**[MSML2020正文/官方入口](https://proceedings.mlr.press/v107/xu20b.html)：结构稀疏CNN近似傅里叶及一维PDE/信号任务，傅里叶初始化；同初始化时BNet2可用更少参数取得类似CNN精度。层级互补低秩是工具，不能据此断言颅骨源到体素映射全局低秩。
- **缺口：**局部块秩、近场/多径与源曲面采样；高频Green核的全局低秩可能很差。
- **下一步：**先用train-only基和validation投影诊断源空间维数；只有低秩/分块秩有实测支持后才考虑层级核网络。
