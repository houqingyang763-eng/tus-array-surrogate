# 空间状态传递：论文判断

## P03 TUSNet — 已知论文，保留直接扫描消融

- **判断：继续提取多方向聚合；完整结构降级。**
- **依据：**[已有核查A3/附录表A2](../../../../../docs/zotero_cross_paper_comparison_20260930.md)、[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12754752/)：二维CT/阵列/目标画布→实值压力包络及阵元校正。四方向LSTM-Conv的焦域IoU `86.95%`，同参数卷积U-Net `79.40%`，同方向LSTM `83.90%`；这是空间聚合的正向消融。
- **缺口：**包络IoU不是逐体素复相位精度；三维逐切片LSTM存在串行和状态内存成本。
- **下一步：**在较粗但保相位的状态上测试六方向传递，保留细输出；不把四方向二维原样扩大成全分辨率3D循环。

## P35 Mamba — 索引外，通用状态计算思想

- **判断：继续提取选择性状态与并行scan；语言骨架降级。**
- **依据：**[v2 §3、§3.6](https://arxiv.org/html/2312.00752v2)：序列→输入依赖的状态更新→序列输出；通过关联scan计算长程递归，线性复杂度。作者默认使用实状态，§3.6明确讨论复状态对于连续模态的价值；语言收益不是波场收益。
- **缺口：**三维空间不是天然序列；默认衰减状态如何保留多次相位旋转未被本任务验证。
- **下一步：**使用成对实数的旋转/衰减状态；检查这种更新能否写成并行scan，避免隐藏状态依赖导致退回串行。

## P36 VMamba — 索引外，扫描拓扑的可核查例子

- **判断：继续借鉴路径审查；完整视觉骨架降级。**
- **依据：**[NeurIPS2024原文](https://proceedings.neurips.cc/paper_files/paper/2024/hash/baa2da9ae4bfed26520bb61d259a3653-Abstract.html)、[所读v2 §3.2/表5](https://arxiv.org/html/2401.10166v2)：四个展开方向经选择性scan后合并。等参数/FLOPs的分类消融：单向82.2、CSM82.5；双向配置发生NaN，级联扫描吞吐较差。借鉴的是保持二维邻接、核查实际吞吐，不是0.3百分点能支持大幅波场增益。
- **缺口：**三维六方向的内存、跨行伪邻接、复状态kernel及反射传播。
- **下一步：**沿真实轴线重置状态并交换方向信息；先验证同预算局部相位和耗时，再考虑主干替换。
