# exploration04：简单传统底座与集中学习改进

固定入口：本文件 → [MISSION.md](MISSION.md) → [REVIEW.md](REVIEW.md)。用户最新要求优先。默认中文、单 Agent；解释从用户熟悉的向量、矩阵和基础微积分出发。

## 研究责任

- 目标是服务经颅超声应用论文：底座易理解、易复现，新增改动集中，项目可用精度下有显著收益。先选底座，再研究一个改进；不继承旧轮排序或候选。
- 已复现的 Born 是优先核查的现有资产，尚未锁定。比较具体方法与代码版本，不再用 C1/C2/C3 等简称代替判断。
- Codex 主动承担论文精读、源码理解、推导、反驳与取舍；不能把关键分析交给用户逐篇补做，也不能只搬运摘要、结论或仓库 README。
- 工作投入指导比例：约45%检索与原文/代码取证、45%推理与比较、10%简洁记录。调研和推理约一比一，不伪造精确计时，不用篇数或记录量代替研究质量。

## 读透，再判断

1. 先查[统一文献索引](../../../docs/literature_seen_index.md)，复用事实卡片；已知论文和已有方向延伸明确标记，仅对关键缺失或矛盾回查。
2. 对决定去留的论文，读实验结果及对应方法、补充材料；把规模、介质、源、误差/停止、硬件、准备与在线时间放回同一个真实算例，保留代表性结果及反例。
3. 对关键代码固定版本，跟踪输入 → 介质准备 → 一次迭代 → 停止检查 → 输出；辨认真方程、近似/预条件作用、缓存依赖、主要数组和重复工作。关键判断给函数/行号，不以找到仓库代替理解实现。
4. 对结果及代码作自己的解释：为何快/慢；哪些能力可继承；哪些步骤需要项目适配；适配怎样影响精度、时间、内存和复现难度。论文事实、代码事实、计算推导、迁移假设、项目实测分开。
5. 学习位置必须对应具体昂贵工作，估算可替代工作、网络自身和保留工作的净成本；检查简单非学习替代，不为制造加速故意弱化传统基线。
6. 推荐必须说明选什么、相对谁、为什么、把握及改判条件。缺口定向补齐；不以“以后实测”替代已能完成的推理，不无限扩展检索。

## 创新与收束

- 允许明确引用并借鉴、组合已有工具；新增贡献须有具体计算差异及可区分收益，不靠隐藏来源或换名制造创新。
- 构思、查重、成本和证伪同步做；先在内部筛除重复、收益小或工程过重的想法，每轮只向用户交付一个经过推敲的候选，允许零候选。
- 用户已有基础和每日理解预算有限，结果先给判断与简明理由，必要原理就地解释；不输出大批候选或要求用户逐个实验。
