# exploration04：简单底座上的有效学习加速

日期：2026-10-19。状态：**S1文献与源码调研完成；推荐现有变密度Born/Universal Split底座，见[REPORT](REPORT.md)。尚未设计学习方案或开展项目求解/训练。**

依据：用户本次讨论及归档重开任务的明确要求。用户的首要目的是形成一篇经颅超声应用论文；约一个半月，每天最多两小时高强度理解与决策。Codex承担主要检索、精读、推导和实现准备，不能把大量候选的学习与试验成本转给用户。该人力时间窗口不是 GPU/实验预算。

## 1. 目标与选择原则

选一个容易理解、容易复现、完整开源的传统算法，在其上寻找小而集中的学习改进，在项目可用精度下显著缩短完整求解时间。

- 基础方法应有经典/权威文献、可核的引用影响及被用作 baseline 的实际记录；分别评价经典原理与具体实现，不把较新实现直接称为已广泛采用。
- 必须有覆盖关键流程的代码与示例，查明版本、依赖、数据缺口和项目适配工作量。工程重建成本与数学复杂度同样影响排序。
- 已复现 Born/Universal Split 是默认核查起点；最多补查两个简单替代者，只有实质更合适才更换。C2/C3 等复杂组合不继承优先地位，不为迁就旧推荐重建庞大系统。
- 创新幅度可以小，新增部分、理由和收益必须清楚。允许借鉴与组合并明确引用；直接迁移现成学习方法不自动成为贡献，不为新颖包装增加模块。
- McMg可作来源和方法参考，不要求超过其创新深度、性能或必做直接对比。关键对照是选定传统底座的合理强实现，以及最接近新增机制的已有办法。

## 2. 应用对象与评价

- 沿用完整384×480×224 @0.5 mm传播介质及当前V10物理约定；颅内Re/Im复场形状评价，ROI仅用于输出/评价，禁用raw验收。
- 本轮研究仍面向可更换介质和临时同频多点源配置：先合成 `b = Σ_j a_j b(s_j)`，求一次 `A_m u = b`，交付一份总复场；内部保留相干幅相，不默认建立逐源场库。
- 换介质要查明哪些准备、缓存或权重需更新；通用训练、逐介质适配和在线求解分列。有限适配成本可以权衡，不擅设必须零适配、秒级编码或接受逐头模长重训。
- **1%误差只是用户举例，1–10秒是实用速度的讨论示例，均未冻结为验收阈值。**精度以项目可用性判断；不强制残差达到10⁻⁶。残差保留作诊断，影响计算正确性的问题具体处理。
- 对比同精度下完整耗时，或同耗时下形状精度；传统方法同样允许提前停止。离线参考误差用于评估，不能把推理时不可取得的标签当停止条件。
- 用户回忆的“约一分钟已有很好结果”是选题动机；定量引用以[既有Born记录](../../../docs/evidence/exploration04_born.md#results)为准，不写成已达到1%或本轮新结果。
- 以上是研究需求，不自动改变现有V10单源接口、Label、科学配置和实验。稳定合同见[V10 handoff](../../../docs/project_design_handoff_v10.md)。

## 3. 分阶段推进

| 阶段 | 核心工作 | 简洁交付与收束条件 |
| --- | --- | --- |
| S1 选底座 | 有限核查原理、作者完整代码、引用/基线使用、项目适配与复现负担 | 推荐一个具体方法及代码版本；至多一个备用；其余一句话淘汰。明确给出选择依据，未锁定底座时不扩展网络设计 |
| S2 定问题 | 读透一次迭代和原文成果，解释慢因及可复用关系，比较简单非学习加速 | 一个清楚的计算流程和最值得改善的问题；已知成本与待测占比分开 |
| S3 构思并查重 | 针对该问题推导新增计算，同时核最接近先例、净收益、实现成本及反证 | 每轮只交付一个候选，写清借鉴、实质差异及最低成本证伪；零条合格也如实交付 |
| S4 最小验证 | 围绕同一个想法设计必要传统/简单替代对照，先判断净收益及贡献来源 | 当前只设计；实验另行批准。只有明确失败原因和可检验修改才继续，不无限调参或并行试多个候选 |
| S5 固定方法 | 有效后冻结核心改动，补应用范围内的稳定性、关键对照和消融，写作同步整理 | 汇报支撑论文的事实、收益和适用边界；不在有效后持续扩模块或自动扩大范围 |

阶段顺序用于减少反复选型；正式启动后按已批准范围连续工作，不逐篇请求确认。不能因尚无原创点无限重启路线综述；明确实现过重、近先例覆盖或无净收益时及时淘汰。

## 4. 工作重心与交付

投入以**取证精读 : 推理比较约1:1，记录约占总精力10%**为指导，即约45%/45%/10%。取证包括读实验、补充材料和关键源码；推理包括数学解释、成本估计、迁移分析、反驳和路线取舍。比例用于约束浅阅读与过度记录，不要求计时打卡。

沿用experiment02的轻量架构：AGENTS定义工作规则，本文件定义任务，REVIEW供推荐前一次自检，README只导航。正式研究后按需创建REPORT（唯一分析正文）、REFERENCES（关键页码/图表/代码定位）、SEARCH_LOG（改变判断的检索与修正）；不预建大量空文件。

旧0–3轮均[归档](../README.md)，只按需复用证据，不继承其结论、完成声明、候选、预算或执行授权。用户已启动S1，授权公开文献、只读源码、推导比较与文档，不限调研时间，按能否给出有依据的明确推荐收束；不访问服务器、不运行实验、不改求解/训练代码、不安装环境、不操作Zotero、不push。实验需独立合同。
