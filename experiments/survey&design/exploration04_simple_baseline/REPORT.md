# S1：传统算法底座选择

2026-10-19。**S1文献与源码调研完成。明确推荐保留现有变密度 Born / Universal Split 固定点迭代作为底座。**这是研究选型建议；本轮没有运行求解、训练或性能实验，没有修改求解程序。既有B1结果的科学状态仍按原文件 `PENDING_REVIEW`。

## 1. 推荐什么，为什么现在可以收束

具体底座是 **Stanziola等的变声速、变密度一阶声学 Born 求解器**，作者代码固定在 `ucl-bug/born-density-matlab@2b59c72acf8637a8f314157a28d00380e19b0084`，继续使用本地[PyTorch移植](../../../docs/evidence/exploration04_born.md#code)的同一迭代。不是未经预条件、可能发散的普通 Born 展开，也不泛指所有叫Born的方法。[R01–R03](REFERENCES.md#r01)

选择它的主要依据是：**现有实现已经覆盖项目的声速、密度、吸收和完整三维域；主要计算是一个反复执行的固定点修正循环；作者核心代码、本地逐步对照和真实头模记录均已存在。**学习改进尚未确定，但进入机制研究前不需要再重建一套三维求解系统。

这个判断对“六周内适合承载一个集中改进”的把握较高；对“学习一定显著加速、最后一定成文”保持开放。底座选得合适，只解决复现和工程起点问题，原创性与净收益还要在S2/S3检验。

必须正面说明一个取舍：**经典CBS家族有引用影响和实际baseline使用；2025/2026年的这篇变密度实现本身还不是广泛使用的老牌baseline。**因此推荐理由是“成熟家族＋适合项目的公开实现＋已经积累的复现资产”，不能把三个层次合并写成“此具体算法早已被大量工作采用”。

本轮有限比较两个替代者后，不建议更换。普通CSLP多重网格＋Krylov仅留作条件备用；标量CBS只作原理与实现参考。C2/C3的复杂组合不再进入本轮建设清单。

## 4. 现有Born的一次迭代究竟是什么

将四个网格复场 `ux、uy、uz、p` 看作拼在一起的长向量。它们分别记录三个方向的粒子速度和压力。作者先作固定缩放，使它们适合在同一个线性系统中计算；这里用 `x` 表示缩放后的向量，`y` 表示缩放后的源。

把方程写成 `A x = y`，再拆为 `A=L+V`：`L`含可快速求逆的常系数微分部分，`V`含介质变化。令 `B=I−V`、`R=(L+I)⁻¹`，实际循环就是：

```text
z = B x + y
w = R z
d = B (w − x)
x ← x + ν d
```

其中B是每个格点的简单乘法；R负责主要的全域计算。FFT可先理解为一次“换基”：把空间格点组成的向量换成一组波形的系数，常系数微分在那套坐标里更容易计算。此处R在四个分量上各变换一次、再变回，共**八次三维FFT**，中间只有逐点代数，没有内层迭代、网格层级或粗层分解。

直接代入 `R⁻¹=L+I` 可得：

```text
d = B R (y − A x)
e_next = (I − ν B R A) e
```

这里 `e=x−x_exact`。这说明它确实是在修正方程残差，只是通过代数重排，避免每步另外计算完整的 `A x`。`B R`就是预条件修正：先把难处理的残差变成较容易消除的更新量。**把网络加在这里会改变哪些计算，之后必须逐项说清；S1还不作选择。**[R02](REFERENCES.md#r02)

原论文及Universal Split理论给出满足条件时的收敛依据，关键涉及系统缩放、`‖V‖<1`与步长。它不自动覆盖日后任意网络替换，也不保证每一步的k-Wave形状误差单调下降。

### 4.1 源码逐段核查及对项目的含义

| 流程 | 本地函数/作者代码 | 读出的实际行为 |
| --- | --- | --- |
| 输入与准备 | `Context.__init__`；作者主函数的padding、交错密度、gamma、shift/scaling | 接收物理c、rho、alpha。加外部吸收层，建立介质系数及频域逆的分母；不是读取网络归一化介质 |
| 一次更新 | `step` → `inverse_split`；`singleIteration` → `B` → `L_I_inv` → `B` | 上述四行流程；没有在每一步调用真实残差函数。局部乘法、8次FFT及全域数组读写反复发生 |
| 诊断与停止 | `relative_residual`、`solve`；作者 `residualMagnitude` | 本地以未缩放一阶系统的RHS范数归一；每次检查另有8次FFT。默认每20步检查，输出callback时间单列 |
| 输出 | `pressure`；作者主函数末段 | 把内部缩放还原并裁掉外部吸收层；本地求解器内部保留完整复数幅相，形状归一发生在评价端 |

原版与本地实现有三处影响理解的差别：

1. 作者在第一次更新后才记录归一化残差；本地用真正的 `‖b0‖`。作者打印行还把绝对/相对数值位置倒置，因此不能仅对比日志上同名的“relative residual”。
2. 论文讨论最小包围圆选shift；固定源码 `findShifts` 实际用复平面包围矩形中心，`approx_scaling`参数没有改变这条路径。本地复制的是源码，不声称实现了论文中所有优化建议。
3. 论文的复声速表达与固定代码分支并不相同；本地采用代码中的二次幂吸收映射，源相位和缩放已有[PHYSICS_MAPPING](../../../docs/evidence/exploration04_born.md#physics)推导及小域对照。不能重新按论文一个公式替换它，再把物理变化当算法加速。

作者BM7脚本的边界是内部48格、强度2，本地是外部50格、0.6；脚本设置1000步上限不等于论文实际停止在1000步。这些差别足以阻止直接复用其容差或计时结论，但不增加当前底座的重建工作。

### 4.2 换介质、多点源与训练接口

经典求解器换头模需重建B、缩放、吸收及频域系数，**不需要神经训练**。同介质、频率、网格和边界下，这些系数可复用；改变其中任一条件则须重算对应准备。

同频多源在数学上可先合成复源 `b=Σ a_j b_j`，一次求总场，作者接口也接收完整复源数组。本地 `point_rhs/solve` 目前只接单点，不能说已经支持用户要求的任意多点配置；需要一个明确的源接口适配，迭代原理无需因此改成逐源场库。本轮未修改接口，也未验证多点总场。

本地核心使用 `torch.no_grad` 和原位更新。可以复用其数值算子，不代表训练反向传播已经准备完成。后续学习方案是否要穿过这些算子求导，会影响建设量，须在选方案时计入。

## 5. 为什么两个“看起来更传统”的替代者不更省事

### 5.1 标量CBS更简洁，但少掉的密度项需要付出代价

原始标量CBS针对 `Δp+k²(x)p=s`，一轮核心可用两次FFT。项目的变密度压力方程还包含一阶导数项。在物理域内部、略去吸收边界项的写法，对光滑密度令 `l=lnρ`，消去速度得到：

```text
Δp − ∇l·∇p + k²p = s
p = √ρ ψ
⇒ Δψ + [k² + ½Δl − ¼|∇l|²] ψ = s/√ρ
```

这是对连续光滑系数的直接代换推导。它解释了为什么不能只给WaveSim多传一个rho图：新增的密度导数在颅骨跳变和体素采样下需处理界面/离散一致性，还可能增大等效势的变化范围。另一种从离散四分量系统精确消元的做法，会保留“梯度→变系数乘法→散度”，也不自动变成现成的两次FFT核。

所以“物理可否化成标量”值得以后专门研究，但本轮没有依据把它当作零成本替换。为获得更短的数学简介而重新解决物理接口，违背这次降低复现门槛的目的。

WaveSim Python代码质量并非淘汰原因：有介质域对象、源接口、算子测试和三维示例。但固定版0.2.0a1与网上旧PyTorch文档已发生技术栈变化；还含边界wrap校正，不能只按裸两次FFT估计全成本。其停止量是**预条件残差的平方范数**，也不同于本地真残差。[R03](REFERENCES.md#r03)

### 5.2 普通CSLP不是复杂deflation，但仍有一套需要建设的系统

它先给原Helmholtz增加复移位，让一个近似问题更容易被多重网格处理；用该近似解帮助外层Krylov修正。移位太弱，内层难解；太强，对原问题的帮助变小。原2006方案已体现这个取舍，不能把“给方程加一点吸收”理解为全部实现。

实读三维Julia代码确认：先组装稀疏 `H/H_s`，构造限制/延拓与 `Ac=RAP`，最后一层默认LU；一次外更新调用完整MGcycle。三层在已展示算例中快，不意味着本项目也可轻松保留三层：90M级工作域的最粗问题仍可能很大，增加层数又改变收敛与工作量。

还发现两处复现口径问题：表6脚本的网格标签是扩展前的尺寸，`getOverthrustAcoustic`随后在底部补12–16层，所以 `256×256×80` 对应论文 `256×256×96`；仓库CSV的计时与论文表不同，且该脚本没有显式的六次重复取平均循环。网格差异可以由代码解释，计时差异缺少运行元数据，不能以CSV较小秒数替代论文成果。再加上缺失模型数据、密度和项目吸收接口、Julia到GPU适配，它不是当前更容易落地的起点。[R05](REFERENCES.md#r05)

### 5.3 为什么不直接说“套GMRES就行”

GMRES、BiCGSTAB和Anderson首先是可配合底座的迭代工具，不应与完整的物理求解器混作三个同级候选。它们可能成为后续简单非学习对照，但也有向量存储、正交化或稳定性代价。

本地物理域41,287,680格，加外部50格后实际FFT域为 **484×580×324=90,953,280格**。按complex64计算，一个标量场0.678 GiB，四分量状态2.711 GiB。GMRES(5)的6个基向量仅存储就约16.26 GiB；若FGMRES还存5个预条件后向量，共约29.82 GiB，尚未计介质系数、FFT工作区、当前解及残差。这里是从数组大小推导的下界，不是显存实测；也不排除短历史或低存储算法。

这足以说明，在当前四分量大域上，不能因为一个二维论文的Krylov外层好用，就把它叫作免费的简单改动。Universal Split原文自身也比较过这些迭代器；其所测问题中GMRES并未最快。[R02](REFERENCES.md#r02)

### 6.1 残差约9，应该怎样影响决定

原五源均到步数上限，未缩放一阶残差为9.18–9.50；作者MATLAB与本地CPU逐步压力/速度差异约10⁻¹⁵，小域残差计算也一致。这使“移植明显改错了迭代核心”不成为当前首选解释，但不能由形状接近标签就认定方程已经充分满足。

更具体地说，该残差把动量与连续性方程的不同尺度直接拼接。作者算法内部用 `C=diag(λu,λu,λu,λp)` 平衡它们。对于只有压力源的情况，令 `r=(ru,rp)=A0φ−b0`，缩放系统对应的残差范数满足：

```text
ηscaled² = [(λp/λu) Σi ‖ru_i‖² + ‖rp‖²] / ‖bp‖²
```

这是由 `x=C½φ`、`y=C⁻½b0` 直接得到的关系；它说明两种诊断量不能横比。本地小域参考文件中 `λu≈1.385×10⁹、λp≈5.478×10⁻⁴`，比值相差约2.53×10¹²。这个例子说明尺度问题很大，**不是MIDA残差已经被解释完毕**：未保存分量残差，尚不能回推出其缩放值；FP32抵消也只是待检原因，不能归因为已确认的舍入平台。

因此仍推荐该底座，同时把“残差尺度、算法自身稳定状态和k-Wave形状差异如何对应”列为S2必须理清的具体问题。按项目应用精度评价，不强加10⁻⁶；也不删除或重命名旧诊断，让结果看起来达标。

## 7. 从成果和代码推到后续研究的边界

代码与原文相符的慢因解释是：这是一种低历史存储的固定点传播，强声速/密度反差通常要求更保守的拆分与缩放，单位更新消除误差的能力变弱；每一步又要在约91M格上作全域变换。变密度论文图4确实显示对比度增大时迭代拖长。标量CBS的波包分析给出过 `2k0/ε` 的伪传播距离，但这个定量式不能直接代入四分量密度系统计算本项目迭代数。

这让后续问题可以收束成一句话：**在保持当前物理和形状评价的前提下，怎样以小额附加计算，减少达到应用所需形状质量前的昂贵修正？**究竟是初期传播、某类误差分量、保守缩放还是其他因素主导，不能只靠一条总耗时曲线认定。

S2应先完成一张可解释的成本/误差演变图，并比较最相关的简单非学习改动；不把一万步后的尾部、输出频率调整或缓存工程充作学习贡献。已有LBS学习迭代系数和Green核参数，NPBS也已有Born预条件的学习修正，均为已知先例；“在Born里放神经网络”本身不是新机制。[R06](REFERENCES.md#r06)

净收益的最低算术约束也已清楚。若传统每步耗时t，学习每步额外耗时q且保留原工作，暂不计共同准备成本，则必须有：

```text
n_learn / n_base < t / (t+q)
```

才能得到在线净加速。若只在开始使用一次网络，或替代而非追加某项工作，成本式要相应重写。比较分母是合理提前停止、同等形状质量的传统底座，而不是被故意跑长的基线。**本轮没有据此选择网络、许诺加速倍数或冻结误差阈值。**

## 8. 最终取舍及改判条件

**选现有变密度Born/Universal Split。现在结束底座扩展搜索。**它的优势是研究建设量少、项目物理已经接通、一次更新集中；弱点是具体论文较新、四场FFT成本大，残差诊断与标签差异还需解释。它适合承载六周的小改进研究，是否支持合格论文取决于后续一个机制的结果与先例差异。

只有出现以下实质证据，才重开底座选择：同一物理与评价下，现有离散/边界误差使应用质量始终达不到需求且修复成本很高；或所有合理的小改进已被近先例覆盖/没有净收益，而一个有完整项目适配路径的简单替代者明显更省建设。单纯查到更少迭代、更好看的论文秒数，或暂时没有灵感，不构成重开理由。
