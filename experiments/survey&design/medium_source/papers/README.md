# 介质与源交互：论文判断

## P07 背景场条件 — 已知论文，拆开输入与输出证据

- **判断：继续，作为当前P0的机制依据。**
- **依据：**[已有原文核查A7/表3](../../../../docs/zotero_cross_paper_comparison_20260930.md)；[原文](https://doi.org/10.1093/gji/ggaf113)：二维声速与背景复场→复波场。同一U-Net，常规输入→全场Re/Im L2 `0.3050/0.3074`，背景输入→全场`0.1963/0.1957`；只有输出改散射则`0.4120/0.4160`。输入提供空间传播条件有证据；散射输出本身没有普遍收益。
- **缺口：**V10已含P0，下一轮需要改善利用过程，不能再次用“加P0”作为新骨架贡献。
- **下一步：**将介质生成的局部算子作用于源场状态，与单纯拼接/FiLM作对照。

## P31 原始MgNO — 索引外，已知多尺度算子方向延伸

- **判断：继续骨架思想；其Helmholtz精度仅作旁证。**
- **依据：**[ICLR2024论文/v2 §4、附录D.3](https://arxiv.org/html/2310.19809v2)：将网络通道间的线性算子参数化为多重网格V-cycle。原Helmholtz例为`100²`、实值激励场、Neumann边界、变化声速、固定边界激励，和外部点源复场不同；原模型不是OpenBreastUS动态改造版。
- **缺口：**相位、变源与介质门控的独立贡献。
- **下一步：**用V-cycle实现跨尺度状态交换，保留细尺度复场通路；按P32/P33核实改造。

## P32 OpenBreastUS — 索引外，完整复场重要对照

- **判断：继续，高优先级；大幅收益值得迁移测试。**
- **依据：**[v1 表II、VII、附录B](https://arxiv.org/html/2507.15035v1)：`480²`二维声速与源条件→频域复场。500 kHz，U-Net/FNO/BFNO/MgNO的RRMSE为`0.1798/0.0490/0.0209/0.0049`；训练64源、评价256源（192未见）的对应值`0.1877/0.0632/0.0212/0.0183`。最佳模型有动态改造和多级计算，不是只换名字。
- **缺口：**二维软组织、数据量与本任务不同；未见源表包含已见源，不当作192源纯OOD均值。结果对比不足以单独归因到动态卷积。
- **下一步：**结合P33拆解其骨架和自组合；三维版本先减小细层成本，不复制`[24,32,64,128,256]`通道表。

## P33 SC-NO / MgNO-self — 索引外，核查新版新增消融

- **判断：继续；共享迭代限于机制明确的骨架。**
- **依据：**[2026-08-02 v2 §3–4、表2–3](https://arxiv.org/html/2508.20650v2)：介质卷积+MLP生成空间权重，再乘场卷积特征；共享V-cycle重复更新状态。表2与P32为同组结果。新版25%子集400 kHz、1790训练速度样本/100验证、30 epoch：表3 MgNO regular/self `0.0194/0.0151`，相对下降22.16%；FNO `0.0902/0.0966`、U-Net `0.2559/0.2610`均恶化。§3又将同一数值描述为目标深度5的直接训练/T&U对比：三种初始化`0.0194±0.0015/0.0151±0.0012`；T&U为深度3→4→5各10 epoch，单A6000，batch10。
- **缺口：**同一数值有“骨架regular/self”和“训练流程direct/T&U”两种描述，当前材料没有拆净共享结构、深度和训练策略的独立收益；22.16%按该组合条件报告。三维成本待测。理论近似定理不保证任意训练后网络继续迭代会收敛。
- **下一步：**对本项目先比较1/2/3次共享更新，匹配总计算；外部证据支持开展测试，不预设重复越多越好。

## P40 MIFNO — 已有方向，源支路不是新颖性本身

- **判断：继续，作为源交互强对照。**
- **依据：**[原论文](https://doi.org/10.1016/j.jcp.2025.113813)、[作者代码](https://github.com/lehmannfa/MIFNO)、[历史定向代码核查](../../../../docs/literature/known_direction_notes.md#mifno)：三维介质体与源位置/方向向量分支，在latent通过和、差、乘积融合，再走F-FNO。输出是地表时空弹性速度，并非整块三维体复压力；论文报告小尺度包络仍难。
- **缺口：**源支路膨胀为三维latent的显存；三种融合同时加入难分收益。
- **下一步：**将空间P0注入状态、介质生成局部权重；源向量只补几何全局条件。MIFNO式单乘积融合作为比较臂。
