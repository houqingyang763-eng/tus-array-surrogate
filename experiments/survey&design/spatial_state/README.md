# 空间状态传递

- **判断：继续物理相位参与的粗层轴向状态；直接换VMamba降级。**
- **依据：**TUSNet方向序列在二维幅值任务有直接消融；Mamba提供输入条件的线性状态与并行scan，VMamba提供多方向合并。它们提示信息传递方式，但没有当前全体素复相位证据。
- **缺口：**扫描路径的人工邻接、顺序偏置与大状态内存；仅六条独立方向之和不构成所有体素互相访问。
- **下一步：**S0在2 mm粗层依次作x/y/z双向线扫描，以复相位转移为候选；先和同成本轴向混合比较，再决定是否替换M0全域通路。

入口：[论文](papers/README.md)｜[设计](DESIGN.md)｜[验证](VALIDATION.md)。本轮新增的是三维路径与复状态的具体改造；不将通用Mamba重新检索写成新发现。
