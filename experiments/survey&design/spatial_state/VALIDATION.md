# S0验证：扫描的优势必须超过同成本混合

- **判断：继续小粗层对照；大规模替换降级。**
- **依据：**TUSNet幅值输出和VMamba分类消融仅支持方向传递线索；不能当复场精度结果。
- **缺口：**三维复scan尚无吞吐和可分辨收益。
- **下一步：**按共同合同，先实施S1，再按结果选S2/S3；没有启动授权。

| 比较 | 保持一致 | 结果怎样改变判断 |
|---|---|---|
| S1：轴向低秩混合、静态线性scan、介质条件复scan | M0表示/局部块/输出，2 mm工作尺度，近似MAC与参数 | 复scan较简单通路无>5%幅相收益则降级；若只train改善，查源泛化 |
| S2：连续x/y/z、独立六方向和、连续反序 | 状态数与训练预算 | 连续阶段胜出支持跨轴传递；顺序差异大则增加顺序鲁棒性设计，不直接归因声学传播 |
| S3：相位参数参考初始化、随机/零相位初始化、普通实转移 | 参数与输入信息相同 | 参考相位必须带来稳定val优势；失败则去掉相位先验，保留介质scan候选 |
| S4：一次、两次跨轴轮次；同成本局部块/混合 | 总计算明确 | 重复无收益即停止加轮次；4 s不满足先缩状态 |

诊断同时看源距分层、骨面附近、相消纹理、Re/Im与高幅区域相位，不用只幅值图判断。关联前后相位不能替代全场复L2。保持不旋转GT/预测的相位规则。

工程先验检查只覆盖会污染结论的点：每条线边界重置、双向反转恢复坐标、padding排除、不因展平创造跨行邻接、所有方向看到同一物理坐标/源。峰值显存和完整参数更新时间必须含scan反向。
